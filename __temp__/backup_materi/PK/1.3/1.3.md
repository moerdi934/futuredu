## **Materi 1.3.1: Pengenalan Persamaan Kuadrat** *(GRATIS)*

### **Halo, Kenalan Dulu dengan Si "Kuadrat"!**

Pernahkah kamu melempar bola ke atas dan memperhatikan lintasannya? Atau melihat air mancur yang menyembur membentuk lengkungan indah? Nah, bentuk lengkungan itu ternyata bisa dijelaskan dengan persamaan kuadrat, lho! 

Persamaan kuadrat itu seperti "kakak tingkat"-nya persamaan linear. Kalau persamaan linear itu lurus-lurus aja (y = mx + c), persamaan kuadrat punya "tikungan" yang bikin hidup lebih menarik! 🎢

### **Bentuk Umum: Si Cantik yang Terstruktur**

Persamaan kuadrat punya bentuk standar yang kece:

**ax² + bx + c = 0**

Di mana:
- **a** ≠ 0 (ini koefisien x², dan HARUS ada! Kalau a = 0, bukan persamaan kuadrat namanya)
- **b** adalah koefisien x (boleh positif, negatif, atau bahkan 0)
- **c** adalah konstanta (si pemain bebas yang bisa jadi apa aja)
- **x** adalah variabel yang kita cari

**Contoh-contoh yang Sering Muncul:**
- x² - 5x + 6 = 0 (a=1, b=-5, c=6)
- 2x² + 3x - 5 = 0 (a=2, b=3, c=-5)
- x² - 9 = 0 (a=1, b=0, c=-9) ← Lihat! b boleh nol
- 3x² + 12x = 0 (a=3, b=12, c=0) ← c juga boleh nol

**⚠️ JEBAKAN BATMAN!**
- 3x + 5 = 0 → Ini bukan persamaan kuadrat! (nggak ada x²-nya)
- 0x² + 2x + 1 = 0 → Ini juga BUKAN! (a = 0, jadi cuma persamaan linear biasa)

### **Akar Persamaan: Si Penyelamat Masalah**

Akar persamaan kuadrat adalah nilai x yang membuat persamaan menjadi **benar** (bernilai nol). Bayangin kayak kamu lagi main tebak angka, dan akar itu adalah jawaban yang tepat!

**Karakteristik Akar:**
- Persamaan kuadrat bisa punya **2 akar berbeda** (x₁ dan x₂)
- Bisa punya **2 akar kembar** (x₁ = x₂)
- Atau bahkan **tidak punya akar real** (akar imajiner, tapi ini nanti kita bahas)

**Ilustrasi Simpel:**

Misalkan: x² - 5x + 6 = 0

Kalau kita coba x = 2:
- (2)² - 5(2) + 6 = 4 - 10 + 6 = 0 ✅ **Betul!**

Kalau kita coba x = 3:
- (3)² - 5(3) + 6 = 9 - 15 + 6 = 0 ✅ **Betul juga!**

Jadi x = 2 dan x = 3 adalah akar-akarnya!

### **Cara Pemfaktoran: Teknik Ninja Level Dasar**

Pemfaktoran itu kayak membongkar puzzle menjadi potongan-potongan yang lebih sederhana. Ini adalah cara paling "elegan" kalau persamaannya kooperatif!

**Langkah-langkah Pemfaktoran:**

**1. Pastikan bentuknya sudah standar (ax² + bx + c = 0)**

**2. Cari dua bilangan yang:**
   - **Jika dikalikan** = a × c
   - **Jika dijumlahkan** = b

**3. Pecah bentuk bx menjadi dua suku**

**4. Faktorkan per kelompok**

**5. Keluarkan faktor persekutuan**

**Contoh Kece:**

Selesaikan: x² + 7x + 12 = 0

**Step by step:**
- a = 1, b = 7, c = 12
- Cari dua angka yang dikalikan = 12 dan dijumlahkan = 7
- Angka magic-nya: **3 dan 4** (karena 3×4=12 dan 3+4=7)
- Maka: x² + 7x + 12 = (x + 3)(x + 4) = 0

Sekarang kita punya:
- (x + 3)(x + 4) = 0

Ingat! Kalau A × B = 0, maka A = 0 atau B = 0

Jadi:
- x + 3 = 0 → **x = -3**
- x + 4 = 0 → **x = -4**

**Akar-akarnya: x = -3 atau x = -4** 🎉

**Contoh Level Medium:**

Selesaikan: 2x² + 5x + 3 = 0

- a = 2, b = 5, c = 3
- a × c = 6, cari dua angka yang kalikan = 6 dan jumlahkan = 5
- Angkanya: **2 dan 3**
- Pecah: 2x² + 2x + 3x + 3 = 0
- Kelompokkan: (2x² + 2x) + (3x + 3) = 0
- Faktorkan: 2x(x + 1) + 3(x + 1) = 0
- Keluarkan (x + 1): (2x + 3)(x + 1) = 0

Sehingga:
- 2x + 3 = 0 → **x = -3/2**
- x + 1 = 0 → **x = -1**

### **Akar Kembar: Si Kembar Siam**

Kadang-kadang, persamaan kuadrat punya akar yang sama (kembar). Ini terjadi ketika bentuknya adalah **kuadrat sempurna**.

**Bentuk kuadrat sempurna:**
- (x + p)² = x² + 2px + p²
- (x - p)² = x² - 2px + p²

**Contoh:**

x² - 6x + 9 = 0

Perhatikan! Ini bisa difaktorkan menjadi:
- (x - 3)(x - 3) = 0
- (x - 3)² = 0

Jadi akarnya: **x = 3** (akar kembar)

**Ciri-ciri akar kembar:**
- Bentuknya kuadrat sempurna
- Bisa ditulis sebagai (x ± p)²
- Punya nilai diskriminan = 0 (ini nanti kita bahas di materi berikutnya)

### **Hubungan Koefisien dengan Grafik Parabola**

Nah, ini yang bikin persamaan kuadrat makin seru! Setiap persamaan kuadrat punya "wajah" visual yang disebut **parabola** (bentuk U atau terbalik).

**Pengaruh Koefisien a:**

- **a > 0** → Parabola membuka ke **ATAS** (kayak mangkok) 🌙
  - Contoh: x² - 4x + 3 = 0 → bentuk U
  
- **a < 0** → Parabola membuka ke **BAWAH** (kayak gunung) 🏔️
  - Contoh: -x² + 2x + 3 = 0 → bentuk terbalik

- **|a| besar** → Parabola "lancip" (sempit)
  - Contoh: 5x² + x + 1 = 0
  
- **|a| kecil** → Parabola "tumpul" (lebar)
  - Contoh: 0.2x² + x + 1 = 0

**Pengaruh Koefisien c:**

- **c** adalah titik potong parabola dengan **sumbu y**
- Kalau c = 3, maka grafik memotong sumbu y di (0, 3)
- Kalau c = -2, maka grafik memotong sumbu y di (0, -2)

**Akar dan Grafik:**

- **Dua akar berbeda** → Grafik memotong sumbu x di dua titik
- **Akar kembar** → Grafik menyentuh sumbu x di satu titik (puncak)
- **Tidak ada akar real** → Grafik tidak memotong sumbu x sama sekali!

### **🎯 TIPS JITU UTBK:**

1. **Selalu pastikan a ≠ 0!** Ini jebakan klasik yang sering muncul.

2. **Lihat polanya!** Kalau koefisien a dan c bertanda sama, coba cari faktor dengan tanda yang sama semua.

3. **Cek dengan substitusi!** Setelah dapat akar, selalu cek kembali dengan memasukkan ke persamaan asli.

4. **Jangan panik kalau ketemu pecahan!** Akar persamaan kuadrat boleh berbentuk pecahan.

5. **Perhatikan instruksi soal!** Kadang soal minta "jumlah akar", "hasil kali akar", atau "akar yang lebih besar". Baca teliti!

### **⚠️ JEBAKAN UMUM di UTBK:**

**Jebakan 1: Lupa Nol di Ruas Kanan**
- ❌ Salah: x² + 5x = -6, langsung difaktorkan
- ✅ Benar: x² + 5x + 6 = 0, baru difaktorkan

**Jebakan 2: Salah Tanda**
- Hati-hati dengan tanda negatif saat memfaktorkan!
- x² - 5x + 6 = (x - 2)(x - 3) bukan (x + 2)(x + 3)

**Jebakan 3: Buru-buru Pilih Jawaban**
- Soal kadang minta "nilai x yang lebih kecil" atau "jumlah kedua akar"
- Jangan langsung pilih akar pertama yang ketemu!

**Jebakan 4: Terkecoh Bentuk**
- 2x² = 8 → jangan lupa bagi dua sisi dengan 2 dulu!
- x² = 4 → ingat, x = ±2 (ada dua kemungkinan!)

## **Materi 1.3.2: Menyelesaikan Persamaan Kuadrat dengan Melengkapkan Kuadrat**

### **Welcome to the Next Level!**

Oke, di materi sebelumnya kita udah belajar pemfaktoran. Tapi gimana kalau ketemu persamaan kuadrat yang "bandel"—susah difaktorkan? Atau malah angkanya aneh-aneh kayak desimal atau pecahan?

Di sinilah **Melengkapkan Kuadrat** jadi penyelamat! Teknik ini lebih universal dan SELALU berhasil, mau persamaannya seberat apapun. Plus, teknik ini adalah fondasi untuk memahami rumus ABC yang bakal kita pelajari selanjutnya!

### **Konsep Kuadrat Sempurna: Fondasi yang Harus Dikuasai**

Sebelum masuk ke teknik melengkapkan kuadrat, kita harus paham dulu apa itu **kuadrat sempurna**.

**Kuadrat sempurna** adalah hasil dari pengkuadratan suatu ekspresi. Bentuknya cantik dan rapi!

**Rumus Dasar:**
- (x + p)² = x² + 2px + p²
- (x - p)² = x² - 2px + p²

**Perhatikan polanya:**
- Koefisien x (yang ditengah) = 2p
- Konstanta (yang terakhir) = p²

**Contoh-contoh Kuadrat Sempurna:**

1. (x + 3)² = x² + 6x + 9
   - Koefisien x: 6 = 2(3)
   - Konstanta: 9 = 3²

2. (x - 5)² = x² - 10x + 25
   - Koefisien x: -10 = 2(-5)
   - Konstanta: 25 = (-5)²

3. (x + ½)² = x² + x + ¼
   - Koefisien x: 1 = 2(½)
   - Konstanta: ¼ = (½)²

**✨ Rumus Magic:**

Kalau punya x² + bx, maka bilangan yang harus ditambahkan untuk jadi kuadrat sempurna adalah **(b/2)²**

Contoh:
- x² + 8x + ??? → tambahkan (8/2)² = 16 → jadi (x + 4)²
- x² - 6x + ??? → tambahkan (-6/2)² = 9 → jadi (x - 3)²

### **Teknik Melengkapkan Kuadrat: Step by Step**

Sekarang kita masuk ke inti materinya! Ini adalah langkah-langkah sistematis yang WAJIB kamu kuasai:

**LANGKAH 1: Pastikan Koefisien x² = 1**

Kalau a ≠ 1, bagi seluruh persamaan dengan a terlebih dahulu.

**LANGKAH 2: Pindahkan Konstanta ke Ruas Kanan**

Pisahkan suku-suku yang ada x dengan konstanta.

**LANGKAH 3: Lengkapkan Kuadrat di Ruas Kiri**

Tambahkan (b/2)² di KEDUA ruas (kiri dan kanan).

**LANGKAH 4: Faktorkan Ruas Kiri Jadi Bentuk (x ± p)²**

**LANGKAH 5: Akarkan Kedua Ruas**

**LANGKAH 6: Selesaikan untuk x**

### **Contoh Penerapan Level 1: Basic**

**Soal:** Selesaikan x² + 6x + 5 = 0

**Penyelesaian:**

**Step 1:** Koefisien x² sudah 1 ✓

**Step 2:** Pindahkan konstanta
- x² + 6x = -5

**Step 3:** Lengkapkan kuadrat
- Hitung (b/2)² = (6/2)² = 9
- Tambahkan 9 ke kedua ruas:
- x² + 6x + 9 = -5 + 9
- x² + 6x + 9 = 4

**Step 4:** Faktorkan ruas kiri
- (x + 3)² = 4

**Step 5:** Akarkan kedua ruas
- x + 3 = ±√4
- x + 3 = ±2

**Step 6:** Selesaikan untuk x
- x + 3 = 2 → **x = -1**
- x + 3 = -2 → **x = -5**

**Jawaban: x = -1 atau x = -5** ✅

### **Contoh Penerapan Level 2: Medium**

**Soal:** Selesaikan 2x² - 8x + 6 = 0

**Penyelesaian:**

**Step 1:** Koefisien x² bukan 1, jadi bagi semua dengan 2
- x² - 4x + 3 = 0

**Step 2:** Pindahkan konstanta
- x² - 4x = -3

**Step 3:** Lengkapkan kuadrat
- (b/2)² = (-4/2)² = 4
- x² - 4x + 4 = -3 + 4
- x² - 4x + 4 = 1

**Step 4:** Faktorkan
- (x - 2)² = 1

**Step 5:** Akarkan
- x - 2 = ±1

**Step 6:** Selesaikan
- x - 2 = 1 → **x = 3**
- x - 2 = -1 → **x = 1**

**Jawaban: x = 1 atau x = 3** ✅

### **Contoh Penerapan Level 3: Advanced**

**Soal:** Selesaikan 3x² + 12x - 9 = 0

**Penyelesaian:**

**Step 1:** Bagi dengan 3
- x² + 4x - 3 = 0

**Step 2:** Pindahkan konstanta
- x² + 4x = 3

**Step 3:** Lengkapkan kuadrat
- (4/2)² = 4
- x² + 4x + 4 = 3 + 4
- x² + 4x + 4 = 7

**Step 4:** Faktorkan
- (x + 2)² = 7

**Step 5:** Akarkan
- x + 2 = ±√7

**Step 6:** Selesaikan
- x = -2 + √7 atau x = -2 - √7

**Jawaban: x = -2 ± √7** ✅

Perhatikan! Akarnya berbentuk irasional (ada akar). Ini normal dan sah!

### **Menentukan Nilai Maksimum atau Minimum**

Nah, ini aplikasi KEREN dari melengkapkan kuadrat! Kita bisa langsung tahu nilai maksimum atau minimum dari fungsi kuadrat.

**Prinsip Dasar:**
- Bentuk **(x - p)²** selalu **≥ 0** (tidak pernah negatif)
- Nilai minimum (x - p)² adalah **0** (saat x = p)

**Contoh Kasus:**

**Soal:** Tentukan nilai minimum dari f(x) = x² - 6x + 11

**Penyelesaian:**

Lengkapkan kuadrat:
- f(x) = x² - 6x + 11
- f(x) = (x² - 6x + 9) - 9 + 11
- f(x) = (x - 3)² + 2

**Analisis:**
- Bentuk (x - 3)² ≥ 0
- Nilai minimum (x - 3)² = 0, terjadi saat x = 3
- Jadi nilai minimum f(x) = 0 + 2 = **2** (saat x = 3)

**Koordinat titik minimum: (3, 2)**

**Contoh Maksimum:**

**Soal:** Tentukan nilai maksimum dari g(x) = -x² + 4x + 1

**Penyelesaian:**

- g(x) = -(x² - 4x) + 1
- g(x) = -(x² - 4x + 4 - 4) + 1
- g(x) = -[(x - 2)² - 4] + 1
- g(x) = -(x - 2)² + 4 + 1
- g(x) = -(x - 2)² + 5

**Analisis:**
- Bentuk -(x - 2)² ≤ 0 (selalu negatif atau nol)
- Nilai maksimum -(x - 2)² = 0, terjadi saat x = 2
- Jadi nilai maksimum g(x) = 0 + 5 = **5** (saat x = 2)

**Koordinat titik maksimum: (2, 5)**

### **Aplikasi dalam Masalah Optimasi Sederhana**

Teknik melengkapkan kuadrat sering dipakai untuk menyelesaikan masalah optimasi dalam kehidupan nyata!

**Contoh Real-Life:**

**Situasi:** Seorang petani punya 100 meter pagar untuk membuat kandang berbentuk persegi panjang. Salah satu sisinya menggunakan tembok yang sudah ada (jadi tidak perlu pagar). Berapa dimensi kandang agar luasnya maksimum?

**Penyelesaian:**

Misalkan:
- Lebar kandang = x meter
- Maka panjang kandang = (100 - 2x) meter

Luas kandang:
- L(x) = x(100 - 2x)
- L(x) = 100x - 2x²
- L(x) = -2x² + 100x

Lengkapkan kuadrat:
- L(x) = -2(x² - 50x)
- L(x) = -2(x² - 50x + 625 - 625)
- L(x) = -2[(x - 25)² - 625]
- L(x) = -2(x - 25)² + 1250

**Luas maksimum = 1250 m²** (saat x = 25 meter)

Dimensi optimal:
- Lebar = 25 meter
- Panjang = 100 - 2(25) = 50 meter

## **Materi 1.3.3: Rumus ABC (Kuadratik)**

### **The Ultimate Weapon: Rumus ABC!**

Oke gengs, sekarang kita masuk ke senjata PAMUNGKAS dalam menyelesaikan persamaan kuadrat: **RUMUS ABC** atau sering disebut **Rumus Kuadratik**! 

Ini adalah rumus legendaris yang bisa menyelesaikan SEMUA persamaan kuadrat, mau sesusah apapun, mau sekompleks apapun. Udah gitu, rumus ini juga kasih info bonus tentang jenis akar-akarnya. Keren banget kan?

Tapi sebelum kita pakai rumusnya, kita harus paham dulu dari mana rumus ini datang. Trust me, ini penting biar kamu nggak cuma hafal doang!

### **Penurunan Rumus ABC dari Melengkapkan Kuadrat**

Nah, ini adalah "behind the scenes" dari rumus ABC. Kita akan buktikan rumus ini dari teknik melengkapkan kuadrat yang udah kita pelajari!

**Mulai dari bentuk umum:**

ax² + bx + c = 0 (a ≠ 0)

**Step 1: Bagi semua dengan a**

x² + (b/a)x + (c/a) = 0

**Step 2: Pindahkan konstanta**

x² + (b/a)x = -c/a

**Step 3: Lengkapkan kuadrat**

Tambahkan (b/2a)² ke kedua ruas:

x² + (b/a)x + (b/2a)² = -c/a + (b/2a)²

**Step 4: Sederhanakan ruas kanan**

x² + (b/a)x + (b/2a)² = -c/a + b²/4a²

Samakan penyebut:

= (-4ac + b²)/4a²

= (b² - 4ac)/4a²

**Step 5: Faktorkan ruas kiri**

(x + b/2a)² = (b² - 4ac)/4a²

**Step 6: Akarkan kedua ruas**

x + b/2a = ±√[(b² - 4ac)/4a²]

x + b/2a = ±√(b² - 4ac)/(2a)

**Step 7: Selesaikan untuk x**

x = -b/2a ± √(b² - 4ac)/(2a)

x = [-b ± √(b² - 4ac)]/(2a)

**TADAAA! Itulah Rumus ABC!** 🎉

### **Rumus ABC: Formula Emas**

**x = [-b ± √(b² - 4ac)] / (2a)**

Komponen-komponennya:
- **a** = koefisien x²
- **b** = koefisien x
- **c** = konstanta
- **±** = artinya ada dua kemungkinan (+ dan -)

Yang menghasilkan dua akar:
- **x₁ = [-b + √(b² - 4ac)] / (2a)**
- **x₂ = [-b - √(b² - 4ac)] / (2a)**

### **Diskriminan (D): Si Penentu Nasib**

Bagian **b² - 4ac** di dalam akar disebut **Diskriminan** (dilambangkan **D**).

**D = b² - 4ac**

Ini adalah bagian PALING PENTING karena diskriminan menentukan:
1. **Jenis akar** persamaan
2. **Banyaknya akar**
3. **Karakteristik grafik parabola**

### **Syarat dan Jenis Akar Berdasarkan Diskriminan**

**KONDISI 1: D > 0 (Diskriminan Positif)**

Karakteristik:
- Persamaan punya **2 akar real berbeda**
- Grafik parabola **memotong sumbu x di 2 titik**

Sub-kondisi:
- **D > 0 dan D = bilangan kuadrat sempurna** → 2 akar **rasional** berbeda
  - Contoh: D = 25, maka √25 = 5 (rasional)
  
- **D > 0 dan D ≠ bilangan kuadrat sempurna** → 2 akar **irasional** berbeda
  - Contoh: D = 7, maka √7 (irasional)

**KONDISI 2: D = 0 (Diskriminan Nol)**

Karakteristik:
- Persamaan punya **2 akar real kembar** (sama)
- Grafik parabola **menyentuh sumbu x di 1 titik** (titik puncak)
- Akarnya selalu **rasional**
- x₁ = x₂ = -b/(2a)

**KONDISI 3: D < 0 (Diskriminan Negatif)**

Karakteristik:
- Persamaan **tidak punya akar real**
- Akarnya **imajiner** (kompleks)
- Grafik parabola **tidak memotong sumbu x**

### **Tabel Ringkasan Diskriminan**

| **Diskriminan** | **Jenis Akar** | **Grafik Parabola** |
|-----------------|----------------|---------------------|
| D > 0 (kuadrat sempurna) | 2 akar rasional berbeda | Memotong sumbu x di 2 titik |
| D > 0 (bukan kuadrat sempurna) | 2 akar irasional berbeda | Memotong sumbu x di 2 titik |
| D = 0 | 2 akar real kembar (rasional) | Menyentuh sumbu x di 1 titik |
| D < 0 | Tidak ada akar real (imajiner) | Tidak memotong sumbu x |

### **Contoh Penerapan Rumus ABC**

**Contoh 1: Akar Rasional Berbeda**

Selesaikan: x² - 7x + 12 = 0

**Identifikasi koefisien:**
- a = 1, b = -7, c = 12

**Hitung diskriminan:**

- D = 1 > 0 ✅

Karena D = 1 (kuadrat sempurna), maka ada 2 akar rasional berbeda.

**Gunakan rumus ABC:**

x = [7 ± 1] / 2

**x₁ = (7 + 1)/2 = 8/2 = 4**

**x₂ = (7 - 1)/2 = 6/2 = 3**

**Jawaban: x = 3 atau x = 4** ✅

**Contoh 2: Akar Irasional Berbeda**

**Rumus ABC:**

x = [-4 ± √12] / 2

**Jawaban: x = -2 ± √3** ✅

**Contoh 3: Akar Kembar**

**Contoh 4: Tidak Ada Akar Real**

**Jawaban: Tidak ada penyelesaian real** (atau x ∈ bilangan kompleks)

**Contoh 5: Koefisien Bukan 1**

Selesaikan: 2x² - 5x + 2 = 0

**Identifikasi:**

**Diskriminan:**

- D = 9 > 0 ✅ (kuadrat sempurna)

x = [-(-5) ± √9] / (2·2)

**x₁ = (5 + 3)/4 = 8/4 = 2**

**x₂ = (5 - 3)/4 = 2/4 = 1/2**

**Jawaban: x = 2 atau x = 1/2** ✅

## **Materi 1.3.4: Sifat-sifat Akar Persamaan Kuadrat**

### **Welcome to Vieta's World!**

Nah, sekarang kita masuk ke materi yang super powerful: **Rumus Vieta**! Ini adalah formula yang dikembangkan oleh matematikawan Prancis bernama François Viète di abad ke-16.

Dengan rumus ini, kita bisa:
- Mencari **jumlah** dan **hasil kali** akar TANPA menghitung akarnya!
- Menyusun persamaan kuadrat baru dari akar yang diketahui
- Menyelesaikan soal UTBK super cepat!

Kedengarannya kayak magic? Bukan! Ini murni matematika elegan! 🎩✨

### **Rumus Vieta: The Power Duo**

Untuk persamaan kuadrat **ax² + bx + c = 0** dengan akar-akar x₁ dan x₂:

**RUMUS 1: Jumlah Akar**

**x₁ + x₂ = -b/a**

**RUMUS 2: Hasil Kali Akar**

**x₁ × x₂ = c/a**

**Pembuktian Rumus Vieta:**

Dari rumus ABC, kita tahu:

x₁ = [-b + √(b² - 4ac)] / (2a)

x₂ = [-b - √(b² - 4ac)] / (2a)

**Untuk Jumlah:**

x₁ + x₂ = {[-b + √D] + [-b - √D]} / (2a)

x₁ + x₂ = (-b - b) / (2a)

x₁ + x₂ = **-2b / (2a) = -b/a** ✅

**Untuk Hasil Kali:**

x₁ × x₂ = {[-b + √D] / (2a)} × {[-b - √D] / (2a)}

x₁ × x₂ = [(-b)² - (√D)²] / (4a²)

x₁ × x₂ = (b² - D) / (4a²)

Ingat: D = b² - 4ac, jadi b² - D = b² - (b² - 4ac) = 4ac

x₁ × x₂ = 4ac / (4a²)

x₁ × x₂ = **c/a** ✅

### **Penerapan Rumus Vieta: Level Basic**

**Contoh 1: Mencari Jumlah dan Hasil Kali Akar**

Tentukan jumlah dan hasil kali akar dari: x² - 7x + 10 = 0

**Penyelesaian:**

Identifikasi: a = 1, b = -7, c = 10

**Jumlah akar:**
- x₁ + x₂ = -b/a = -(-7)/1 = **7** ✅

**Hasil kali akar:**
- x₁ × x₂ = c/a = 10/1 = **10** ✅

**Cek dengan mencari akarnya:**
- x² - 7x + 10 = (x - 2)(x - 5) = 0
- x₁ = 2, x₂ = 5
- Jumlah: 2 + 5 = 7 ✅
- Kali: 2 × 5 = 10 ✅

**Contoh 2: Koefisien a Bukan 1**

Tentukan jumlah dan hasil kali akar dari: 2x² + 6x - 8 = 0

**Penyelesaian:**

a = 2, b = 6, c = -8

**Jumlah:**
- x₁ + x₂ = -6/2 = **-3** ✅

**Hasil kali:**
- x₁ × x₂ = -8/2 = **-4** ✅

**Insight:** Perhatikan! Hasil kali negatif berarti satu akar positif, satu negatif!

### **Menyusun Persamaan Kuadrat Baru**

Kalau kita tahu x₁ dan x₂, kita bisa menyusun persamaan kuadratnya!

**RUMUS STANDAR:**

Persamaan dengan akar x₁ dan x₂ adalah:

**x² - (x₁ + x₂)x + (x₁ × x₂) = 0**

Atau dalam bentuk koefisien:

**x² - (jumlah akar)x + (hasil kali akar) = 0**

**Contoh 3: Menyusun dari Akar yang Diketahui**

Susun persamaan kuadrat yang akar-akarnya 3 dan 5!

**Penyelesaian:**

x₁ = 3, x₂ = 5

Jumlah: 3 + 5 = 8
Kali: 3 × 5 = 15

**Persamaan: x² - 8x + 15 = 0** ✅

**Cek:**
- (x - 3)(x - 5) = x² - 5x - 3x + 15 = x² - 8x + 15 ✅

**Contoh 4: Akar Berbentuk Pecahan**

Susun persamaan kuadrat dengan akar 1/2 dan -3!

**Penyelesaian:**

Jumlah: 1/2 + (-3) = 1/2 - 3 = -5/2

Kali: (1/2) × (-3) = -3/2

**Persamaan: x² - (-5/2)x + (-3/2) = 0**

**x² + (5/2)x - 3/2 = 0**

Kalikan dengan 2 untuk eliminasi pecahan:

**2x² + 5x - 3 = 0** ✅

### **Hubungan Akar dengan Koefisien: Advanced Level**

**Contoh 5: Mencari Nilai Lain dari Akar**

Diketahui x² - 5x + 6 = 0 dengan akar x₁ dan x₂. Tentukan:
a) x₁² + x₂²
b) 1/x₁ + 1/x₂
c) (x₁ - x₂)²

**Penyelesaian:**

Dari persamaan: a = 1, b = -5, c = 6

x₁ + x₂ = 5
x₁ × x₂ = 6

**a) x₁² + x₂² = ?**

Gunakan identitas: (x₁ + x₂)² = x₁² + 2x₁x₂ + x₂²

Maka: x₁² + x₂² = (x₁ + x₂)² - 2x₁x₂

x₁² + x₂² = (5)² - 2(6)

x₁² + x₂² = 25 - 12 = **13** ✅

**b) 1/x₁ + 1/x₂ = ?**

Samakan penyebut: 1/x₁ + 1/x₂ = (x₂ + x₁)/(x₁x₂)

= (x₁ + x₂)/(x₁ × x₂)

= 5/6 ✅

**c) (x₁ - x₂)² = ?**

Gunakan: (x₁ - x₂)² = (x₁ + x₂)² - 4x₁x₂

= (5)² - 4(6)

= 25 - 24 = **1** ✅

Atau bisa juga pakai diskriminan:

(x₁ - x₂)² = D/a² = (b² - 4ac)/a²

= (25 - 24)/1 = **1** ✅

**Contoh 6: Persamaan Kuadrat dengan Syarat**

Tentukan nilai m agar persamaan x² - 2mx + 9 = 0 memiliki akar kembar!

**Penyelesaian:**

Akar kembar terjadi jika D = 0

D = b² - 4ac = 0

(-2m)² - 4(1)(9) = 0

4m² - 36 = 0

4m² = 36

m² = 9

**m = ±3** ✅

### **Aplikasi Rumus Vieta dalam Soal UTBK**

**Tipe Soal 1: Hubungan Akar Baru**

Jika x₁ dan x₂ adalah akar dari x² - 5x + 3 = 0, tentukan persamaan kuadrat baru yang akar-akarnya (x₁ + 2) dan (x₂ + 2)!

**Penyelesaian:**

Dari persamaan awal:
- x₁ + x₂ = 5
- x₁ × x₂ = 3

Akar baru: α = x₁ + 2, β = x₂ + 2

**Jumlah akar baru:**
α + β = (x₁ + 2) + (x₂ + 2)
= x₁ + x₂ + 4
= 5 + 4 = **9**

**Hasil kali akar baru:**
α × β = (x₁ + 2)(x₂ + 2)
= x₁x₂ + 2x₁ + 2x₂ + 4
= x₁x₂ + 2(x₁ + x₂) + 4
= 3 + 2(5) + 4
= 3 + 10 + 4 = **17**

**Persamaan baru: x² - 9x + 17 = 0** ✅

**Tipe Soal 2: Akar Berlipat**

Jika akar-akar x² - 4x + 1 = 0 adalah x₁ dan x₂, tentukan persamaan baru yang akar-akarnya 2x₁ dan 2x₂!

**Penyelesaian:**

x₁ + x₂ = 4
x₁ × x₂ = 1

Akar baru: α = 2x₁, β = 2x₂

**Jumlah:**
α + β = 2x₁ + 2x₂ = 2(x₁ + x₂) = 2(4) = **8**

**Hasil kali:**
α × β = (2x₁)(2x₂) = 4x₁x₂ = 4(1) = **4**

**Persamaan baru: x² - 8x + 4 = 0** ✅

**Tipe Soal 3: Akar Resiprokal (Kebalikan)**

Persamaan kuadrat yang akar-akarnya kebalikan dari akar x² - 6x + 2 = 0 adalah...

**Penyelesaian:**

x₁ + x₂ = 6
x₁ × x₂ = 2

Akar baru: α = 1/x₁, β = 1/x₂

**Jumlah:**
α + β = 1/x₁ + 1/x₂ = (x₁ + x₂)/(x₁x₂) = 6/2 = **3**

**Hasil kali:**
α × β = (1/x₁)(1/x₂) = 1/(x₁x₂) = 1/2

**Persamaan baru: x² - 3x + 1/2 = 0**

Atau kalikan 2: **2x² - 6x + 1 = 0** ✅

**Shortcut:** Kalau akar-akarnya kebalikan, tinggal tukar koefisien a dan c!

x² - 6x + 2 = 0 → **2x² - 6x + 1 = 0** ✅

## **Materi 1.3.5: Fungsi Kuadrat**

### **From Equation to Function: Level Up!**

Oke gengs, sekarang kita naik level! Kalau sebelumnya kita fokus ke **persamaan** kuadrat (cari nilai x yang bikin persamaan = 0), sekarang kita masuk ke dunia **fungsi** kuadrat yang lebih luas dan seru!

Fungsi kuadrat itu kayak "mesin" yang:
- Input: masukin nilai x
- Process: diolah dengan rumus kuadrat
- Output: keluar nilai f(x) atau y

Dan yang paling keren? Fungsi kuadrat punya **visualisasi grafik** yang cantik bernama PARABOLA! 🎨

### **Bentuk Umum Fungsi Kuadrat**

Ada tiga bentuk fungsi kuadrat yang perlu kamu kuasai:

**BENTUK 1: Bentuk Umum (Standard Form)**

**f(x) = ax² + bx + c**

Di mana:
- **a ≠ 0** (koefisien x², penentu arah parabola)
- **b** = koefisien x
- **c** = konstanta (nilai f(x) saat x = 0)

Contoh: f(x) = 2x² - 8x + 6

**BENTUK 2: Bentuk Faktor**

**f(x) = a(x - x₁)(x - x₂)**

Di mana x₁ dan x₂ adalah **titik potong dengan sumbu x** (akar-akar)

Contoh: f(x) = 2(x - 1)(x - 3)

**BENTUK 3: Bentuk Vertex (Bentuk Puncak)**

**f(x) = a(x - p)² + q**

Di mana **(p, q)** adalah **koordinat titik puncak (vertex)** parabola

Contoh: f(x) = 2(x - 2)² - 2

**🔥 Pro Tip:** Ketiga bentuk ini bisa dikonversi satu sama lain! Pilih bentuk yang paling memudahkan untuk menjawab soal!

### **Grafik Fungsi Kuadrat: Si Parabola Cantik**

Grafik fungsi kuadrat membentuk kurva yang disebut **PARABOLA**. Ini adalah salah satu kurva paling penting dalam matematika dan sains!

**Karakteristik Parabola:**

1. **Simetris** terhadap garis vertikal yang melalui puncak
2. Punya **satu titik puncak** (maksimum atau minimum)
3. Bisa membuka **ke atas** atau **ke bawah**
4. Makin jauh dari puncak, kurva makin "curam"

**Elemen-elemen Penting Parabola:**

```
                |
        ----    |    ----
      /     \   |   /     \
     |   •   |  |  |   •   |    ← Titik Puncak (Vertex)
      \     /   |   \     /
        ----    |    ----
    _____|_____|_____|_____
         x₁    |     x₂         ← Titik potong sumbu x
               |
           Sumbu Simetri
```

### **Pengaruh Koefisien a: Si Pembentuk Wajah Parabola**

Koefisien **a** adalah "sutradara" yang menentukan bentuk dan arah parabola!

**ARAH PARABOLA:**

**Jika a > 0:**
- Parabola membuka ke **ATAS** (∪)
- Seperti mangkuk atau senyuman 😊
- Punya nilai **MINIMUM** di puncak
- Grafik naik di kanan puncak, turun di kiri puncak

**Jika a < 0:**
- Parabola membuka ke **BAWAH** (∩)
- Seperti gunung atau sedih ☹️
- Punya nilai **MAKSIMUM** di puncak
- Grafik turun di kanan puncak, naik di kiri puncak

**KETAJAMAN PARABOLA:**

**|a| besar** (misalnya a = 5, a = -10):
- Parabola **LANCIP** (sempit, curam)
- Kurva naik/turun dengan cepat
- "Tubuh" parabola ramping

**|a| kecil** (misalnya a = 0.2, a = -0.5):
- Parabola **TUMPUL** (lebar, landai)
- Kurva naik/turun dengan perlahan
- "Tubuh" parabola gemuk

**Perbandingan Visual:**

```
|a| besar (lancip):        |a| kecil (tumpul):
      /\                        ---
     /  \                      /   \
    /    \                    /     \
   /      \                  /       \
```

**Contoh Konkret:**

1. f(x) = 5x² → parabola lancip, buka atas
2. f(x) = 0.2x² → parabola tumpul, buka atas
3. f(x) = -3x² → parabola lancip, buka bawah
4. f(x) = -0.5x² → parabola tumpul, buka bawah

### **Pengaruh Koefisien b: Si Penggeser Horizontal**

Koefisien **b** menentukan **posisi horizontal** parabola dan **kemiringan** di sekitar puncak.

**Pengaruh b terhadap Posisi:**

- Jika **a dan b bertanda sama** (a > 0, b > 0 atau a < 0, b < 0):
  - Puncak berada di **kiri sumbu y** (x < 0)

- Jika **a dan b berbeda tanda** (a > 0, b < 0 atau a < 0, b > 0):
  - Puncak berada di **kanan sumbu y** (x > 0)

- Jika **b = 0**:
  - Puncak tepat di **sumbu y** (x = 0)
  - Parabola simetris terhadap sumbu y

**Koordinat x puncak:** p = -b/(2a)

**Contoh:**

1. f(x) = x² - 4x + 3
   - a = 1 (positif), b = -4 (negatif) → berbeda tanda
   - Puncak di x = -(-4)/(2·1) = 2 → di kanan sumbu y ✅

2. f(x) = -x² - 2x + 3
   - a = -1 (negatif), b = -2 (negatif) → sama tanda
   - Puncak di x = -(-2)/(2·(-1)) = -1 → di kiri sumbu y ✅

### **Pengaruh Koefisien c: Si Titik Temu Sumbu Y**

Koefisien **c** sangat sederhana tapi penting!

**c = nilai f(x) saat x = 0**

Artinya:
- **c** adalah **titik potong parabola dengan sumbu y**
- Koordinatnya: **(0, c)**

**Contoh:**

1. f(x) = x² - 4x + 5
   - c = 5
   - Parabola memotong sumbu y di **(0, 5)** ✅

2. f(x) = 2x² + 3x - 7
   - c = -7
   - Parabola memotong sumbu y di **(0, -7)** ✅

3. f(x) = -x² + 2x
   - c = 0
   - Parabola melewati titik **(0, 0)** (titik origin) ✅

**⚠️ PERHATIAN:**
- c positif → parabola di atas sumbu x (saat x = 0)
- c negatif → parabola di bawah sumbu x (saat x = 0)
- c = 0 → parabola melewati origin

### **Titik Puncak (Vertex) Parabola**

Titik puncak adalah "jantung" dari parabola! Ini adalah titik paling penting karena:
- Menentukan nilai maksimum/minimum fungsi
- Menjadi pusat simetri parabola
- Sering ditanyakan di UTBK!

**RUMUS KOORDINAT PUNCAK:**

Untuk f(x) = ax² + bx + c, koordinat puncak **(p, q)**:

**p = -b/(2a)** → koordinat x puncak

**q = f(p) = -(b² - 4ac)/(4a) = -D/(4a)** → koordinat y puncak

Atau bisa juga:
**q = c - b²/(4a)**

**Cara Mencari Puncak:**

**Metode 1: Pakai Rumus Langsung**

Contoh: f(x) = 2x² - 8x + 6

- a = 2, b = -8, c = 6
- p = -(-8)/(2·2) = 8/4 = **2**
- q = f(2) = 2(2)² - 8(2) + 6 = 8 - 16 + 6 = **-2**

**Puncak: (2, -2)** ✅

**Metode 2: Melengkapkan Kuadrat**

f(x) = 2x² - 8x + 6

= 2(x² - 4x) + 6

= 2(x² - 4x + 4 - 4) + 6

= 2[(x - 2)² - 4] + 6

= 2(x - 2)² - 8 + 6

= 2(x - 2)² - 2

Bentuk vertex: f(x) = 2(x - 2)² - 2

**Puncak: (2, -2)** ✅

**Interpretasi:**
- Karena a = 2 > 0 → parabola buka atas
- Jadi (2, -2) adalah titik **MINIMUM**
- Nilai minimum fungsi = **-2** (saat x = 2)

### **Sumbu Simetri Parabola**

Sumbu simetri adalah garis vertikal yang membagi parabola menjadi dua bagian yang identik.

**Persamaan Sumbu Simetri:**

**x = p = -b/(2a)**

Atau dalam bentuk verbal: **x = koordinat x puncak**

**Sifat-sifat Sumbu Simetri:**

1. Selalu berupa garis vertikal
2. Melewati titik puncak
3. Membagi parabola menjadi dua bagian cermin
4. Jika ada titik (x₁, y₁) di parabola, maka ada titik (x₂, y₁) di sisi lain dengan x₁ + x₂ = 2p

**Contoh:**

f(x) = x² - 6x + 5

- Sumbu simetri: x = -(-6)/(2·1) = **x = 3**
- Artinya: titik (2, y) dan (4, y) punya nilai y yang sama
- Cek: f(2) = 4 - 12 + 5 = -3
- Cek: f(4) = 16 - 24 + 5 = -3 ✅

**Aplikasi di UTBK:**

Kalau diketahui parabola melewati (1, 5) dan simetris terhadap x = 3, maka parabola juga melewati **(5, 5)**!

### **Nilai Maksimum dan Minimum Fungsi Kuadrat**

Ini adalah aplikasi super penting fungsi kuadrat!

**ATURAN EMAS:**

**Jika a > 0:**
- Parabola buka atas
- Punya nilai **MINIMUM** = q (koordinat y puncak)
- Nilai minimum tercapai saat **x = p**
- Tidak ada nilai maksimum (grafik naik terus ke atas)

**Jika a < 0:**
- Parabola buka bawah
- Punya nilai **MAKSIMUM** = q
- Nilai maksimum tercapai saat **x = p**
- Tidak ada nilai minimum (grafik turun terus ke bawah)

**Contoh 1: Mencari Nilai Minimum**

Tentukan nilai minimum dari f(x) = x² - 8x + 20!

**Penyelesaian:**

a = 1 > 0 → ada nilai minimum

**Cara 1: Rumus**
- p = -(-8)/(2·1) = 4
- q = f(4) = 16 - 32 + 20 = 4

**Nilai minimum = 4 (saat x = 4)** ✅

**Cara 2: Melengkapkan Kuadrat**

f(x) = x² - 8x + 20
= (x² - 8x + 16) + 4
= (x - 4)² + 4

Karena (x - 4)² ≥ 0, maka nilai minimum (x - 4)² = 0

Sehingga f(x) minimum = 0 + 4 = **4** ✅

**Contoh 2: Mencari Nilai Maksimum**

Tentukan nilai maksimum dari g(x) = -2x² + 12x - 10!

**Penyelesaian:**

a = -2 < 0 → ada nilai maksimum

- p = -12/(2·(-2)) = -12/(-4) = 3
- q = g(3) = -2(9) + 12(3) - 10 = -18 + 36 - 10 = 8

**Nilai maksimum = 8 (saat x = 3)** ✅

**Contoh 3: Soal Aplikasi**

Sebuah peluru ditembakkan dengan ketinggian h(t) = -5t² + 30t + 2 meter, dengan t dalam detik. Tentukan:
a) Ketinggian maksimum peluru
b) Kapan peluru mencapai ketinggian maksimum

**Penyelesaian:**

a = -5 < 0 → ada maksimum

**a) Ketinggian maksimum:**
- t = -30/(2·(-5)) = 30/10 = 3 detik
- h(3) = -5(9) + 30(3) + 2 = -45 + 90 + 2 = **47 meter** ✅

**b) Waktu mencapai maksimum: t = 3 detik** ✅

### **Titik Potong dengan Sumbu Koordinat**

**TITIK POTONG SUMBU Y:**

Terjadi saat **x = 0**

Titik potongnya: **(0, c)**

Caranya: substitusi x = 0 ke fungsi!

**Contoh:**
f(x) = 2x² - 5x + 3

Titik potong sumbu y:
- y = f(0) = 3
- Titik: **(0, 3)** ✅

**TITIK POTONG SUMBU X:**

Terjadi saat **y = f(x) = 0**

Caranya: selesaikan persamaan kuadrat ax² + bx + c = 0

**Ada tiga kemungkinan:**

**1. D > 0:** Dua titik potong berbeda (x₁, 0) dan (x₂, 0)

**2. D = 0:** Satu titik potong (akar kembar) → parabola menyentuh sumbu x

**3. D < 0:** Tidak ada titik potong → parabola tidak menyentuh sumbu x

**Contoh:**

f(x) = x² - 5x + 6

Titik potong sumbu x:
- x² - 5x + 6 = 0
- (x - 2)(x - 3) = 0
- x = 2 atau x = 3
- Titik: **(2, 0) dan (3, 0)** ✅

### **Hubungan D, Grafik, dan Sumbu X**

**Diskriminan (D = b² - 4ac)** menentukan hubungan parabola dengan sumbu x:

**UNTUK a > 0 (parabola buka atas):**

| **D** | **Grafik** | **Posisi** |
|-------|-----------|-----------|
| D > 0 | Memotong sumbu x di 2 titik | Puncak di bawah sumbu x |
| D = 0 | Menyentuh sumbu x di 1 titik | Puncak tepat di sumbu x |
| D < 0 | Tidak memotong sumbu x | Puncak di atas sumbu x |

**UNTUK a < 0 (parabola buka bawah):**

| **D** | **Grafik** | **Posisi** |
|-------|-----------|-----------|
| D > 0 | Memotong sumbu x di 2 titik | Puncak di atas sumbu x |
| D = 0 | Menyentuh sumbu x di 1 titik | Puncak tepat di sumbu x |
| D < 0 | Tidak memotong sumbu x | Puncak di bawah sumbu x |

**Ilustrasi Visual:**

```
a > 0, D > 0:        a > 0, D = 0:        a > 0, D < 0:
     \  /                 |                    ___
      \/                  •                   /   \
  ____|____           ____|____           ____|____
  x₁  •  x₂               x                    
```

```
a < 0, D > 0:        a < 0, D = 0:        a < 0, D < 0:
  ____|____           ____|____           
  x₁  •  x₂               x              ____|____
      /\                  •                  \   /
     /  \                 |                   ---
```

Untuk menggambar parabola dengan benar, ikuti langkah ini:

**LANGKAH 5: Cari Titik Potong Sumbu X (jika ada)**

**LANGKAH 7: Gambar Kurva Parabola**

**Contoh Lengkap:**

**Step 3:** Sumbu simetri: **x = 2** ✅

**Step 4:** Potong sumbu y
- f(0) = 3
- **Titik: (0, 3)** ✅

**Step 5:** Potong sumbu x
- x² - 4x + 3 = 0
- (x - 1)(x - 3) = 0
- **Titik: (1, 0) dan (3, 0)** ✅

**Step 6:** Titik tambahan (pakai simetri)
- f(0) = 3, maka f(4) = 3 (simetris terhadap x = 2)

**Step 7:** Gambar!

### **3. Koefisien c: The Y-Interceptor**

**c** adalah koefisien paling simple tapi sering jadi kunci!

**Fungsi c:**

1. **Titik Potong Sumbu Y**
   - Koordinat: (0, c)
   - Ini PASTI selalu berlaku untuk semua fungsi kuadrat

2. **Nilai Fungsi Saat x = 0**
   - f(0) = c
   - Starting point kalau kita trace dari origin

3. **Pergeseran Vertikal**
   - c positif → parabola naik
   - c negatif → parabola turun
   - c = 0 → parabola lewat origin

**Analisis Mendalam:**

**c > 0 (Positif):**
```
  3 •  (0, c)
    |    \  /
  0 |     \/
____|______|____
    |
```
- Parabola memotong sumbu y di ATAS origin
- Untuk a > 0: kalau c besar, kemungkinan tidak memotong sumbu x
- Untuk a < 0: pasti memotong sumbu x

**c = 0:**
```
    |   /\
    |  /  \
  0 •-------
    | origin
____|______|____
```
- Parabola melewati ORIGIN (0, 0)

### **Menggambar Sketsa Grafik Parabola: Teknik Pro**

Sekarang kita gabungkan semua pengetahuan di atas untuk menggambar parabola dengan cepat dan akurat!

**METODE SISTEMATIS:**

**Contoh 1: Fungsi dengan Informasi Lengkap**

Gambar sketsa f(x) = 2x² - 8x + 6!

**STEP 1: Analisis Koefisien**
- a = 2 > 0 → buka ATAS ✅
- |a| = 2 (sedang) → ketajaman normal
- b = -8, a dan b beda tanda → puncak di KANAN
- c = 6 > 0 → potong sumbu y di (0, 6)

**STEP 2: Hitung Puncak**
- p = -(-8)/(2·2) = 8/4 = 2
- q = f(2) = 2(4) - 8(2) + 6 = 8 - 16 + 6 = -2
- **Puncak: (2, -2)** → ini titik MINIMUM ✅

**STEP 3: Sumbu Simetri**
- x = 2 ✅

**STEP 4: Titik Potong Sumbu Y**
- (0, 6) ✅

**STEP 5: Titik Potong Sumbu X**
- 2x² - 8x + 6 = 0
- x² - 4x + 3 = 0
- (x - 1)(x - 3) = 0

## **Materi 1.3.7: Pertidaksamaan Kuadrat**

### **Welcome to the Inequality Zone!**

Oke squad, sekarang kita masuk ke level FINAL dari Topic Persamaan Kuadrat: **Pertidaksamaan Kuadrat**! 🎮

Kalau persamaan kuadrat itu cari nilai x yang pas banget (=), pertidaksamaan kuadrat cari **rentang nilai x** yang memenuhi syarat (<, >, ≤, ≥). 

Ini seperti perbedaan antara:
- "Umur kamu tepat 17 tahun" (persamaan)
- "Umur kamu di bawah 17 tahun" (pertidaksamaan)

Pertidaksamaan kuadrat ini SUPER PENTING di UTBK dan aplikasinya ada di mana-mana: ekonomi (profit/loss range), fisika (daerah pergerakan), dan masih banyak lagi!

Let's gooo! 🔥

### **Konsep Pertidaksamaan Kuadrat**

**Bentuk Umum:**

**ax² + bx + c < 0**
**ax² + bx + c > 0**
**ax² + bx + c ≤ 0**
**ax² + bx + c ≥ 0**

dengan a ≠ 0

**Perbedaan dengan Persamaan:**

| **Persamaan** | **Pertidaksamaan** |
|---------------|-------------------|
| x² - 5x + 6 = 0 | x² - 5x + 6 < 0 |
| Solusi: titik spesifik | Solusi: rentang nilai |
| Jawaban: x = 2 atau x = 3 | Jawaban: 2 < x < 3 |
| Mencari akar-akar | Mencari daerah penyelesaian |

**Konsep Kunci:**

Pertidaksamaan kuadrat pada dasarnya menanyakan:
- **"Kapan parabola berada di ATAS sumbu x?"** (untuk > 0)
- **"Kapan parabola berada di BAWAH sumbu x?"** (untuk < 0)

### **Metode Penyelesaian: Garis Bilangan (Number Line)**

Ini adalah metode PALING POWERFUL dan PALING SERING dipakai di UTBK!

**LANGKAH-LANGKAH SISTEMATIS:**

**STEP 1: Ubah ke Bentuk Standar**
- Pindahkan semua ke ruas kiri
- Ruas kanan = 0

**STEP 2: Faktorkan atau Cari Akar-akar**
- Gunakan pemfaktoran, ABC, atau cara lain
- Dapatkan x₁ dan x₂ (jika ada)

**STEP 3: Gambar Garis Bilangan**
- Tandai akar-akar di garis bilangan
- Bagi garis menjadi beberapa interval

**STEP 4: Tentukan Tanda di Setiap Interval**
- Test satu nilai di setiap interval
- Atau gunakan metode "tes tanda"

**STEP 5: Pilih Interval yang Sesuai**
- Untuk > 0: pilih interval positif
- Untuk < 0: pilih interval negatif
- Untuk ≥ atau ≤: sertakan batas

### **Menyelesaikan Pertidaksamaan Kuadrat dengan Garis Bilangan**

**Contoh 1: Basic Level**

Selesaikan: x² - 5x + 6 < 0

**STEP 1:** Sudah bentuk standar ✓

**STEP 2:** Faktorkan
- x² - 5x + 6 = 0
- (x - 2)(x - 3) = 0
- **x₁ = 2, x₂ = 3** ✓

**STEP 3:** Gambar garis bilangan

```
────●═══●────
    2   3
```

Tiga interval terbentuk:
- I:  x < 2
- II: 2 < x < 3
- III: x > 3

**STEP 4:** Tes tanda

**Metode Tes Nilai:**

Test **Interval I** (x < 2), ambil x = 0:
- (0)² - 5(0) + 6 = 6 > 0 → **POSITIF** ✓

Test **Interval II** (2 < x < 3), ambil x = 2.5:
- (2.5)² - 5(2.5) + 6 = 6.25 - 12.5 + 6 = -0.25 < 0 → **NEGATIF** ✓

Test **Interval III** (x > 3), ambil x = 4:
- (4)² - 5(4) + 6 = 16 - 20 + 6 = 2 > 0 → **POSITIF** ✓

**Tabel Tanda:**

```
────●═══●────
  + | - | +
    2   3
```

**STEP 5:** Pilih interval

Karena cari **< 0** (negatif), pilih interval **NEGATIF**:

**Jawaban: 2 < x < 3** ✓

**Notasi Interval: (2, 3)**

**Interpretasi Grafik:**

```
    y
    |    
  6 •\       /•
    |  \   /
  0 ●───●───● x
    0  2   3
    |   \▓/
```

Daerah yang diarsir (▓) adalah daerah di mana parabola < 0 (di bawah sumbu x)!

**Contoh 2: Tanda ≤ (Kurang dari atau sama dengan)**

Selesaikan: x² - 4x + 3 ≤ 0

**LANGKAH CEPAT:**

**Faktorkan:**
- (x - 1)(x - 3) = 0
- x = 1 atau x = 3

**Garis bilangan:**

```
────●═══●────
    1   3
  + | - | +
```

Karena **≤ 0**, pilih interval negatif DAN **SERTAKAN batas** (karena pakai ≤):

**Jawaban: 1 ≤ x ≤ 3** ✓

**Notasi Interval: [1, 3]**

**⚠️ PENTING:**
- **< atau >** → batas TIDAK termasuk → tanda **●** (bulat terbuka)
- **≤ atau ≥** → batas TERMASUK → tanda **●** (bulat tertutup)

**Contoh 3: Tanda > (Lebih dari)**

Selesaikan: -x² + 4x - 3 > 0

**STEP 1:** Ubah tanda (kalikan -1)

**⚠️ HATI-HATI:** Kalau kalikan/bagi dengan bilangan negatif, tanda pertidaksamaan **BERBALIK**!

- -x² + 4x - 3 > 0  (kalikan -1)
- x² - 4x + 3 < 0  (tanda > jadi <)

**STEP 2:** Faktorkan
- (x - 1)(x - 3) = 0
- x = 1 atau x = 3

**STEP 3:** Garis bilangan

```
────●═══●────
    1   3
  + | - | +
```

Karena **< 0**, pilih negatif:

**Jawaban: 1 < x < 3** ✓

**ALTERNATIF:** Tanpa mengubah tanda

Untuk **-x² + 4x - 3 > 0**:

Kita bisa langsung: (x - 1)(x - 3) dengan a = -1

Karena **a < 0** (parabola buka bawah):
- Parabola > 0 (di atas sumbu x) ada di **ANTARA akar**!

**Jawaban: 1 < x < 3** ✓

**Contoh 4: Akar Kembar**

Selesaikan: x² - 6x + 9 ≥ 0

**Faktorkan:**
- (x - 3)² = 0
- **x = 3** (akar kembar)

**Garis bilangan:**

```
────────●────────
        3
    +   |   +
```

**Analisis:**

Karena akar kembar, (x - 3)² **SELALU ≥ 0** untuk semua x!

Nilai (x - 3)² = 0 **hanya saat x = 3**
Untuk x ≠ 3, (x - 3)² > 0

Karena cari **≥ 0**:

**Jawaban: Semua bilangan real (x ∈ ℝ)** ✓

**Notasi: (-∞, ∞)**

**Contoh 5: Tidak Ada Akar Real**

Selesaikan: x² - 2x + 5 > 0

**Cek diskriminan:**
- D = 4 - 20 = -16 < 0
- **TIDAK ada akar real!**

**Analisis:**

Karena:
- a = 1 > 0 (parabola buka atas)
- D < 0 (tidak potong sumbu x)

Maka parabola **SELALU di ATAS sumbu x**!

Untuk x² - 2x + 5 > 0:

**Jawaban: Semua bilangan real (x ∈ ℝ)** ✓

**Grafik:**

```
    y
  5 |   ___
    |  /   \
  4 | |  •  |  (puncak di atas sumbu x)
    |  \___/
  0 |_________ x
```

Parabola tidak pernah sentuh sumbu x, jadi selalu positif!

**Contoh 6: Koefisien Bukan 1**

Selesaikan: 2x² + x - 6 < 0

**Faktorkan:**
- 2x² + x - 6 = 0
- (2x - 3)(x + 2) = 0
- x = 3/2 atau x = -2

**Garis bilangan:**

```
────●═══●────
   -2  3/2
  + | - | +
```

Karena **< 0**, pilih negatif:

**Jawaban: -2 < x < 3/2** ✓

**Notasi: (-2, 3/2)**

### **Hubungan dengan Grafik Parabola**

Ini adalah **KUNCI PEMAHAMAN** pertidaksamaan kuadrat!

**ATURAN EMAS:**

**UNTUK a > 0 (Parabola Buka ATAS):**

```
      y
      |
   +++|+++        (f(x) > 0)
  ────●───●────
      | ▓ |      (f(x) < 0)
     x₁  x₂
```

- **f(x) > 0**: x < x₁ **ATAU** x > x₂
- **f(x) < 0**: x₁ < x < x₂
- **f(x) ≥ 0**: x ≤ x₁ **ATAU** x ≥ x₂
- **f(x) ≤ 0**: x₁ ≤ x ≤ x₂

**Mnemonik:** Buka ATAS → positif di LUAR, negatif di DALAM

**UNTUK a < 0 (Parabola Buka BAWAH):**

```
     x₁  x₂
      | ▓ |      (f(x) > 0)
  ────●───●────
   ▓▓▓|▓▓▓      (f(x) < 0)
      |
```

- **f(x) > 0**: x₁ < x < x₂
- **f(x) < 0**: x < x₁ **ATAU** x > x₂
- **f(x) ≥ 0**: x₁ ≤ x ≤ x₂
- **f(x) ≤ 0**: x ≤ x₁ **ATAU** x ≥ x₂

**Mnemonik:** Buka BAWAH → positif di DALAM, negatif di LUAR

### **Menentukan Daerah Penyelesaian**

**Daerah Himpunan Penyelesaian (HP)** adalah kumpulan semua nilai x yang memenuhi pertidaksamaan.

**NOTASI:**

**1. Notasi Kurung:**
- **(a, b)** → a < x < b (batas tidak termasuk)
- **[a, b]** → a ≤ x ≤ b (batas termasuk)
- **[a, b)** → a ≤ x < b (a termasuk, b tidak)
- **(a, b]** → a < x ≤ b (a tidak, b termasuk)

**2. Notasi Gabungan (Union):**
- **(-∞, a) ∪ (b, ∞)** → x < a ATAU x > b

**3. Notasi Himpunan:**
- **{x | a < x < b}** → himpunan x yang memenuhi syarat

**Contoh Notasi:**

**1. Pertidaksamaan:** x² - 9 < 0

**Penyelesaian:**
- (x - 3)(x + 3) < 0
- -3 < x < 3

**Notasi:**
- Kurung: **(-3, 3)**
- Himpunan: **{x | -3 < x < 3, x ∈ ℝ}**
- Interval: **-3 < x < 3**

**2. Pertidaksamaan:** x² - 4 ≥ 0

**Penyelesaian:**
- (x - 2)(x + 2) ≥ 0
- x ≤ -2 atau x ≥ 2

**Notasi:**
- Kurung: **(-∞, -2] ∪ [2, ∞)**
- Himpunan: **{x | x ≤ -2 atau x ≥ 2, x ∈ ℝ}**
- Interval: **x ≤ -2 atau x ≥ 2**

Tapi kalau bisa, tetap dalam bentuk eksak (√)

**5. Cek Logika Jawaban**

- Kalau a > 0 dan D < 0, pertidaksamaan < 0 **tidak punya solusi**!
- Kalau a > 0 dan D < 0, pertidaksamaan > 0 **solusinya semua real**!

**6. Gunakan Grafik untuk Visualisasi**

Kalau bingung, sketch parabola cepat untuk bantuan visual!

**7. Interval Union (∪) vs Intersection (∩)**

- **ATAU** → gunakan **∪** (union)
- **DAN** → gunakan **∩** (intersection)

### **⚠️ JEBAKAN UMUM di UTBK:**

**Jebakan 1: Lupa Balik Tanda**

- ❌ -x² + 4x - 3 > 0, langsung faktorkan
- ✅ Kalikan -1 dulu → x² - 4x + 3 < 0

**Jebakan 2: Salah Pilih Interval**

Test dulu setiap interval! Jangan asal tebak!

**Jebakan 3: Notasi Kurung**

- (2, 5) → 2 < x < 5 ✅
- Bukan 2 ≤ x ≤ 5 ❌

**Jebakan 4: Lupa "Atau" untuk Interval Terpisah**

Untuk x < -2 atau x > 3:
- ✅ Benar: (-∞, -2) ∪ (3, ∞)
- ❌ Salah: (-∞, -2) ∩ (3, ∞) = ∅

**Jebakan 5: Diskriminan Negatif**

Kalau D < 0:
- a > 0: f(x) > 0 untuk **semua x**
- a > 0: f(x) < 0 untuk **tidak ada x**
- Jangan sampai tertukar!

**Jebakan 6: Akar Kembar**

Untuk (x - 3)² ≥ 0:
- ✅ Jawaban: semua real (x ∈ ℝ)
- ❌ Bukan: x = 3 saja!

**Jebakan 7: Soal Aplikasi - Batasan Domain**

Untuk waktu (t), jarak (x), atau jumlah barang:
- Nilai harus **positif**!
- Buang solusi negatif!
