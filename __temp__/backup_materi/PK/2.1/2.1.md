### Keluarga Besar Bilangan: Siapa Aja Nih?

#### 1. **Bilangan Asli (Natural Numbers) - The OG**

Bilangan asli itu kayak founding fathers dari semua bilangan. Mereka adalah bilangan yang pertama kali muncul di peradaban manusia. Simple banget: **1, 2, 3, 4, 5, ...** dan seterusnya sampai tak hingga.

**Karakteristik:**
- Dimulai dari 1 (bukan 0 ya! Ini sering jadi jebakan)
- Selalu positif, nggak ada yang negatif
- Digunakan untuk menghitung benda (makanya disebut "natural" - alami untuk menghitung)
- Simbol: **ℕ** atau **N**

**Fun Fact:** Kenapa mulai dari 1? Karena secara historis, manusia purba mulai menghitung dari "satu batu", "dua batu", bukan "nol batu" 😄

**Jebakan UTBK Alert! 🚨**
Soal sering bertanya "bilangan asli kurang dari 10" - jawabannya 1, 2, 3, 4, 5, 6, 7, 8, 9 (ada 9 bilangan). Jangan include 0 dan 10!

---

#### 2. **Bilangan Cacah (Whole Numbers) - Versi Plus**

Bilangan cacah itu basically bilangan asli plus satu anggota baru: **si 0**!

Set bilangan cacah: **0, 1, 2, 3, 4, 5, ...** sampai tak hingga.

**Karakteristik:**
- Dimulai dari 0 (ini yang bedain dari bilangan asli)
- Tetap selalu positif atau nol
- Simbol: **W** (dari Whole)

**Analogi Keren:**
Bilangan asli = Netflix tanpa profil "Kids"
Bilangan cacah = Netflix dengan profil "Kids" (ada satu tambahan!)

**Trik Mengingat:**
**CA**cah = mulai dari **CA**LONG (0) 😉

**Jebakan UTBK Alert! 🚨**
Pertanyaan: "Banyaknya bilangan cacah antara 3 dan 8"
Jawaban: 4, 5, 6, 7 (ada 4 bilangan)
Jangan include 3 dan 8 karena kata "antara"! Kalau "dari 3 sampai 8" baru include.

---

#### 3. **Bilangan Bulat (Integers) - The Expanded Universe**

Nah, sekarang mulai seru! Bilangan bulat itu keluarga besar yang mencakup:
- Bilangan negatif: **... -3, -2, -1**
- Nol: **0**
- Bilangan positif: **1, 2, 3, ...**

**Karakteristik:**
- Ada yang positif, ada yang negatif, ada yang nol
- Tidak ada pecahan atau desimal
- Simbol: **ℤ** (dari bahasa Jerman "Zahlen")

**Visualisasi Garis Bilangan:**
```
... ←─────●─────●─────●─────●─────●─────●─────●─────→ ...
      -3    -2    -1     0     1     2     3
```

**Konsep Penting:**
- **Bilangan bulat positif** = bilangan asli (1, 2, 3, ...)
- **Bilangan bulat negatif** = -1, -2, -3, ...
- **Bilangan bulat non-negatif** = bilangan cacah (0, 1, 2, ...)
- **Bilangan bulat non-positif** = ..., -3, -2, -1, 0

**Jebakan UTBK Alert! 🚨**
Soal: "Bilangan bulat antara -3 dan 5"
Banyak siswa lupa sama yang negatif! Jawabannya: -2, -1, 0, 1, 2, 3, 4 (ada 7 bilangan)

**Tips Pro:**
Kalau ditanya "banyaknya bilangan bulat dari a sampai b", rumusnya: **b - a + 1**
Contoh: dari -3 sampai 5 = 5 - (-3) + 1 = 9 bilangan (termasuk -3 dan 5)

---

#### 4. **Bilangan Rasional (Rational Numbers) - The Fraction Family**

Sekarang masuk ke level yang lebih sophisticated! Bilangan rasional adalah bilangan yang bisa dinyatakan sebagai **pecahan p/q** dimana:
- **p** = bilangan bulat (pembilang)
- **q** = bilangan bulat SELAIN 0 (penyebut)

**Contoh Bilangan Rasional:**
- 1/2, -3/4, 5/7 (pecahan biasa)
- 0.5 = 1/2 (desimal berakhir)
- 0.333... = 1/3 (desimal berulang)
- 2 = 2/1 (bilangan bulat juga rasional!)
- -5 = -5/1
- 0 = 0/1

**Karakteristik:**
- Bisa positif, negatif, atau nol
- Desimalnya **pasti berakhir** atau **berulang**
- Simbol: **ℚ** (dari "Quotient" - hasil bagi)

**Mind Blowing Fact:**
Semua bilangan bulat adalah bilangan rasional (karena bisa ditulis sebagai n/1), tapi tidak semua bilangan rasional adalah bilangan bulat!

**Cara Mengenali Desimal Rasional:**
- **Berakhir**: 0.25, 0.75, 1.5 ✓
- **Berulang**: 0.333..., 0.142857142857... ✓
- **Tidak berakhir & tidak berulang**: π = 3.14159... ✗ (ini irasional!)

**Trik Mengubah Desimal Berulang ke Pecahan:**

Contoh: 0.666... (angka 6 berulang)
1. Misalkan x = 0.666...
2. Kalikan 10: 10x = 6.666...
3. Kurangkan: 10x - x = 6.666... - 0.666...
4. Hasilnya: 9x = 6
5. Jadi: x = 6/9 = 2/3

**Jebakan UTBK Alert! 🚨**
Soal sering kasih desimal panjang kayak 0.142857142857... dan tanya "ini rasional atau irasional?"
Lihat polanya! Kalau ada yang berulang (142857), berarti RASIONAL!

---

#### 5. **Bilangan Irasional (Irrational Numbers) - The Rebels**

Ini adalah bilangan yang **TIDAK BISA** dinyatakan sebagai pecahan p/q. They break the rules!

**Contoh Bilangan Irasional:**
- **π (pi)** = 3.14159265358979... (tak pernah berakhir & tidak berulang)
- **e (konstanta Euler)** = 2.71828182845904...
- **√2** = 1.41421356237309...
- **√3** = 1.73205080756887...
- **∛5** (akar pangkat 3 dari 5)

**Karakteristik:**
- Desimalnya **tidak pernah berakhir** DAN **tidak berulang**
- Tidak bisa ditulis sebagai pecahan biasa
- Simbol: **ℚ'** atau **I** (complement dari rasional)

**Fun Fact Sejarah:**
Orang Yunani kuno (Pythagoras cs) shock berat pas nemuin √2 nggak bisa ditulis sebagai pecahan. Mereka bilang ini "tidak rasional" (irrational) - makanya namanya begitu! Ada yang bilang mereka sampai nyembunyiin fakta ini karena merusak filosofi matematika mereka 😱

**Cara Mengenali Bilangan Irasional:**
✓ Akar dari bilangan yang bukan kuadrat sempurna (√2, √3, √5, √7, dst)
✓ Konstanta terkenal (π, e)
✗ √4 = 2 (ini rasional karena hasilnya bulat!)
✗ √9 = 3 (rasional juga!)

**Jebakan UTBK Alert! 🚨**
Pertanyaan: "Manakah yang irasional?"
a) √16 = 4 (RASIONAL - jebakan!)
b) √8 = 2√2 (IRASIONAL ✓)
c) √(1/4) = 1/2 (RASIONAL)
d) 0.121212... (RASIONAL - berulang)

**Tips:** Kalau akar kuadrat hasilnya masih ada tanda √, kemungkinan besar irasional!

---

#### 6. **Bilangan Real (Real Numbers) - The Ultimate Boss**

Ini adalah **gabungan SEMUA** bilangan rasional DAN irasional. Basically, semua bilangan yang bisa kamu plot di garis bilangan!

**Karakteristik:**
- Mencakup semuanya: rasional + irasional
- Bisa direpresentasikan di garis bilangan
- Simbol: **ℝ** (dari Real)

**Rumus Ajaib:**
ℝ = ℚ ∪ ℚ' (Real = Rasional gabung Irasional)

### Garis Bilangan Real - Your Best Friend

Garis bilangan adalah representasi visual dari semua bilangan real. Ini tool paling powerful buat memahami posisi dan hubungan antar bilangan!

```
        ↓         ↓      ↓  ↓    ↓       ↓        ↓
... ─●────●────●──●──●────●───────●────────●──── ...
   -π   -3   -2  -√2 -1   0      √2       π
```

**Key Points:**
- Semakin ke kanan, bilangan semakin **besar**
- Semakin ke kiri, bilangan semakin **kecil**
- Jarak antar bilangan menunjukkan selisihnya
- Setiap titik di garis mewakili satu bilangan real

**Aplikasi:**
- Membandingkan bilangan: -3 < -√2 < 0 < √2 < π
- Menentukan nilai tengah
- Memvisualisasikan pertidaksamaan

**Aturan Emas:**
1. **Setiap bilangan asli** adalah bilangan cacah ✓

3. **Setiap bilangan bulat** adalah bilangan rasional ✓
4. **Setiap bilangan rasional** adalah bilangan real ✓

**Tabel Kebenaran:**

| Pernyataan | Benar/Salah |
|------------|-------------|
| Semua bilangan asli adalah bilangan bulat | ✓ Benar |

### Bilangan Genap dan Ganjil - The Twin Forces

#### **Bilangan Genap (Even Numbers)**

Bilangan genap adalah bilangan bulat yang **habis dibagi 2** atau bisa ditulis dalam bentuk **2n** (dimana n = bilangan bulat).

**Karakteristik:**
- Digit terakhirnya: 0, 2, 4, 6, atau 8
- Bisa positif, negatif, atau nol
- Contoh: ..., -6, -4, -2, 0, 2, 4, 6, 8, ...

**Fun Fact:** 0 adalah bilangan genap! (Ini sering jadi jebakan)
Bukti: 0 = 2 × 0 ✓

#### **Bilangan Ganjil (Odd Numbers)**

Bilangan ganjil adalah bilangan bulat yang **tidak habis dibagi 2** atau bisa ditulis dalam bentuk **2n + 1** atau **2n - 1**.

**Karakteristik:**
- Digit terakhirnya: 1, 3, 5, 7, atau 9
- Bisa positif atau negatif (tapi 0 bukan ganjil!)
- Contoh: ..., -5, -3, -1, 1, 3, 5, 7, ...

---

### Operasi Genap & Ganjil - The Magic Rules ✨

Ini adalah **aturan emas** yang WAJIB kamu hafal karena hampir selalu muncul di UTBK!

#### **1. Penjumlahan & Pengurangan**

| Operasi | Hasil |
|---------|--------|
| **Genap + Genap** | **= Genap** |
| **Ganjil + Ganjil** | **= Genap** |
| **Genap + Ganjil** | **= Ganjil** |
| **Genap - Genap** | **= Genap** |
| **Ganjil - Ganjil** | **= Genap** |
| **Genap - Ganjil** | **= Ganjil** |
| **Ganjil - Genap** | **= Ganjil** |

**Trik Mengingat:**
- **Genap + Genap = Genap** (G+G=G)
- **Ganjil + Ganjil = Genap** (GJ+GJ=G)
- **Beda jenis = Ganjil** (campuran selalu ganjil!)

**Contoh Penerapan:**
- 4 + 8 = 12 (genap + genap = genap) ✓
- 3 + 7 = 10 (ganjil + ganjil = genap) ✓
- 5 + 2 = 7 (ganjil + genap = ganjil) ✓

#### **2. Perkalian**

| Operasi | Hasil |
|---------|--------|
| **Genap × Genap** | **= Genap** |
| **Genap × Ganjil** | **= Genap** |
| **Ganjil × Ganjil** | **= Ganjil** |

**Aturan Platinum:**
"Kalau ada SATU saja yang genap, hasilnya PASTI genap!"

**Trik Mengingat:**
Genap itu kayak "virus" - sekali ada, langsung menular! 🦠

**Contoh:**
- 2 × 3 × 5 × 7 × 9 = ? 
  Mau ada berapa ganjil juga, karena ada 2 (genap), hasilnya PASTI genap!

#### **3. Perpangkatan**

| Operasi | Hasil |
|---------|--------|
| **Genap^n** (n positif) | **= Genap** |
| **Ganjil^n** (n positif) | **= Ganjil** |

**Mind Blowing:**
- 2¹⁰⁰ = Genap (genap dipangkatkan berapa pun tetap genap)
- 3¹⁰⁰⁰ = Ganjil (ganjil dipangkatkan berapa pun tetap ganjil)

### Bilangan Positif, Negatif, dan Nol - The Three Kingdoms

#### **1. Bilangan Positif (+)**

Bilangan yang lebih besar dari nol.
- Contoh: 1, 2, 3, 4.5, 100, 1/2, √2, π
- Di garis bilangan: sebelah **kanan** nol
- Sifat: hasil operasi yang "menambah"

#### **2. Bilangan Negatif (-)**

Bilangan yang lebih kecil dari nol.
- Contoh: -1, -2, -3, -4.5, -100, -1/2
- Di garis bilangan: sebelah **kiri** nol
- Sifat: hasil operasi yang "mengurangi"

#### **3. Nol (0)**

Bilangan netral - bukan positif, bukan negatif.
- Titik tengah di garis bilangan
- Elemen identitas penjumlahan
- The Great Divide antara positif dan negatif

### Operasi pada Bilangan Bulat - Master the Skills!

#### **1. Penjumlahan Bilangan Bulat**

**Aturan Tanda:**
- **(+) + (+) = (+)** → langsung jumlahkan
  - Contoh: 5 + 3 = 8
  
- **(-) + (-) = (-)** → jumlahkan, tanda tetap negatif
  - Contoh: -5 + (-3) = -8
  
- **(+) + (-) atau (-) + (+)** → kurangkan, ikuti yang lebih besar
  - Contoh: 7 + (-3) = 4 (positif lebih besar)
  - Contoh: -7 + 3 = -4 (negatif lebih besar)

**Trik Visual:**
Bayangkan garis bilangan sebagai ladder:
- Positif = naik tangga
- Negatif = turun tangga

#### **2. Pengurangan Bilangan Bulat**

**Golden Rule:**
**a - b = a + (-b)**
(Pengurangan = tambah dengan lawan)

**Contoh:**
- 5 - 3 = 5 + (-3) = 2
- 5 - (-3) = 5 + 3 = 8 ← **SUPER PENTING!**
- -5 - 3 = -5 + (-3) = -8
- -5 - (-3) = -5 + 3 = -2

**Jebakan UTBK Alert! 🚨**
Dua tanda negatif berurutan (**- -**) menjadi **+**!
- 10 - (-5) = 10 + 5 = 15
- Banyak yang jawab 5! SALAH!

#### **3. Perkalian Bilangan Bulat**

**Aturan Tanda (WAJIB HAFAL!):**

| Operasi | Hasil Tanda |
|---------|-------------|
| **(+) × (+)** | **= (+)** |
| **(+) × (-)** | **= (-)** |
| **(-) × (+)** | **= (-)** |
| **(-) × (-)** | **= (+)** |

**Mantra Ajaib:**
- **Sama** → **Positif** (+) ⚡
- **Beda** → **Negatif** (-) 🌧️

**Contoh:**
- 3 × 4 = 12 (sama-sama positif → positif)
- 3 × (-4) = -12 (beda tanda → negatif)
- (-3) × 4 = -12 (beda tanda → negatif)
- (-3) × (-4) = 12 (sama-sama negatif → positif!)

**Multiple Multiplication:**
(-2) × (-3) × (-4) × (-5) = ?

**Trik Cepat:** Hitung jumlah tanda negatif!
- Jumlah negatif **genap** → Hasil **positif** (+)
- Jumlah negatif **ganjil** → Hasil **negatif** (-)

Ada 4 negatif (genap) → Hasilnya POSITIF = 120 ✓

#### **4. Pembagian Bilangan Bulat**

**Aturan Tanda (SAMA dengan perkalian!):**

| Operasi | Hasil Tanda |
|---------|-------------|
| **(+) : (+)** | **= (+)** |
| **(+) : (-)** | **= (-)** |
| **(-) : (+)** | **= (-)** |
| **(-) : (-)** | **= (+)** |

**Mantra yang Sama:**
- **Sama** → **Positif** (+)
- **Beda** → **Negatif** (-)

**Contoh:**
- 12 : 3 = 4
- 12 : (-3) = -4
- (-12) : 3 = -4
- (-12) : (-3) = 4

### The Great Divide: Rasional vs Irasional 🌓

Oke, ini salah satu materi yang bikin banyak siswa UTBK bingung. Tapi tenang, setelah baca ini, kamu bakal jadi master dalam membedakan dan mengoperasikan kedua jenis bilangan ini!

Bayangin bilangan rasional dan irasional itu kayak dua suku yang berbeda: satu teratur dan bisa diprediksi (rasional), satunya lagi wild dan unpredictable (irasional). Let's dive in! 🏊‍♂️

### Bilangan Rasional (ℚ) - The Rational Gang

#### **Definisi - What Makes It Rational?**

Bilangan rasional adalah bilangan yang bisa dinyatakan sebagai **pecahan p/q** dimana:
- **p** = bilangan bulat (bisa positif, negatif, atau nol)
- **q** = bilangan bulat **SELAIN 0** (q ≠ 0)

**Formula Magic:**
ℚ = {p/q | p, q ∈ ℤ, q ≠ 0}

**Kenapa "Rasional"?**
Kata "rasional" berasal dari kata "ratio" (perbandingan). Jadi bilangan rasional = bilangan yang bisa dinyatakan sebagai **perbandingan dua bilangan bulat**.

---

#### **Karakteristik Bilangan Rasional - The DNA Test**

**1. Representasi Desimal**

Bilangan rasional punya ciri khas dalam bentuk desimal:

✓ **Desimal Berakhir (Terminating)**
- 0.5 = 1/2
- 0.25 = 1/4
- 0.125 = 1/8
- 1.75 = 7/4
- -2.4 = -12/5

✓ **Desimal Berulang (Repeating/Recurring)**
- 0.333... = 1/3 (angka 3 berulang terus)
- 0.666... = 2/3 (angka 6 berulang terus)
- 0.142857142857... = 1/7 (pola 142857 berulang)
- 0.1212... = 4/33 (pola 12 berulang)

**Notasi Desimal Berulang:**
- 0.333... = 0.3̄ (garis di atas angka yang berulang)
- 0.142857142857... = 0.1̄4̄2̄8̄5̄7̄
- 0.1666... = 0.16̄ (hanya 6 yang berulang)

**Trik Mengenali:**
Ambil kalkulator, bagi 1 dengan bilangan prima!
- 1 ÷ 2 = 0.5 (berakhir)
- 1 ÷ 3 = 0.333... (berulang)
- 1 ÷ 7 = 0.142857142857... (berulang)
- 1 ÷ 11 = 0.090909... (berulang)

---

#### **Contoh-contoh Bilangan Rasional**

**Kategori 1: Bilangan Bulat**
Semua bilangan bulat adalah rasional karena bisa ditulis sebagai n/1:
- 5 = 5/1 ✓
- -3 = -3/1 ✓
- 0 = 0/1 ✓
- 100 = 100/1 ✓

**Kategori 2: Pecahan Biasa**
- 1/2, 3/4, -5/7, 22/7, 100/3 ✓

**Kategori 3: Pecahan Campuran**
- 2½ = 5/2 ✓
- -1¾ = -7/4 ✓

**Kategori 4: Desimal Berakhir**
- 0.5 = 5/10 = 1/2 ✓
- 0.75 = 75/100 = 3/4 ✓
- 1.25 = 125/100 = 5/4 ✓

**Kategori 5: Desimal Berulang**
- 0.333... = 1/3 ✓
- 0.666... = 2/3 ✓
- 0.272727... = 3/11 ✓

**Kategori 6: Persentase**
- 50% = 50/100 = 1/2 ✓
- 75% = 75/100 = 3/4 ✓

**Kategori 7: Akar Kuadrat Sempurna**
- √4 = 2 = 2/1 ✓
- √9 = 3 = 3/1 ✓
- √16 = 4 = 4/1 ✓
- √(1/4) = 1/2 ✓
- √0.25 = 0.5 = 1/2 ✓

---

#### **Mengubah Desimal Berulang ke Pecahan - The Ultimate Trick! 🎩**

Ini adalah skill yang SERING banget keluar di UTBK dan bikin banyak siswa panik. Tapi sebenarnya gampang kalau kamu tahu triknya!

**Teknik 1: Untuk Desimal dengan Satu Angka Berulang**

Contoh: Ubah 0.333... ke pecahan

**Langkah-langkah:**
1. Misalkan x = 0.333...
2. Kalikan dengan 10: 10x = 3.333...
3. Kurangkan persamaan (2) - (1):
   ```
   10x = 3.333...
    -x = 0.333...
   _______________
    9x = 3
   ```
4. Selesaikan: x = 3/9 = 1/3 ✓

**Teknik 2: Untuk Desimal dengan Lebih dari Satu Angka Berulang**

Contoh: Ubah 0.142857142857... ke pecahan

**Langkah-langkah:**
1. Hitung berapa digit yang berulang → ada 6 digit (142857)
2. Misalkan x = 0.142857142857...
3. Kalikan dengan 10⁶: 1.000.000x = 142857.142857...
4. Kurangkan:
   ```
   1.000.000x = 142857.142857...
          -x =      0.142857...
   _________________________________
    999.999x = 142857
   ```
5. x = 142857/999999 = 1/7 ✓

**Rumus Cepat:**
Untuk 0.abcabc... (pola abc berulang):
**x = abc/999** (jumlah angka 9 = jumlah digit yang berulang)

Contoh:
- 0.121212... → pola "12" berulang → x = 12/99 = 4/33
- 0.456456... → pola "456" berulang → x = 456/999 = 152/333

**Teknik 3: Untuk Desimal Campuran (Sebagian Berulang)**

Contoh: Ubah 0.1666... ke pecahan (1 tidak berulang, 6 berulang)

**Langkah-langkah:**
1. x = 0.1666...
2. Kalikan 10 (untuk bagian yang tidak berulang): 10x = 1.666...
3. Kalikan 100 (satu digit lagi): 100x = 16.666...
4. Kurangkan (3) - (2):
   ```
   100x = 16.666...
   -10x =  1.666...
   __________________
    90x = 15
   ```
5. x = 15/90 = 1/6 ✓

#### **Operasi pada Bilangan Rasional**

**1. Penjumlahan & Pengurangan Pecahan**

**Aturan Emas:** Samakan penyebut dulu!

**Langkah-langkah:**
1. Cari KPK dari penyebut
2. Ubah pecahan ke penyebut yang sama
3. Jumlahkan/kurangkan pembilangnya
4. Sederhanakan hasilnya

**Contoh:**
1/4 + 2/3 = ?

1. KPK(4, 3) = 12
2. 1/4 = 3/12; 2/3 = 8/12
3. 3/12 + 8/12 = 11/12 ✓

**Trik Cepat (Butterfly Method):**
```
a/b + c/d = (ad + bc)/(bd)
```
1/4 + 2/3 = (1×3 + 4×2)/(4×3) = (3+8)/12 = 11/12 ✓

**2. Perkalian Pecahan**

**Super Simple:** Langsung kali atas dengan atas, bawah dengan bawah!

```
a/b × c/d = (a×c)/(b×d)
```

**Contoh:**
2/3 × 4/5 = (2×4)/(3×5) = 8/15 ✓

**Trik Pro:** Sederhanakan SEBELUM mengalikan!
2/3 × 9/4 = (2×9)/(3×4) 
→ Coret 3 dan 9 → 2/1 × 3/4 = 6/4 = 3/2 (lebih cepat!)

**3. Pembagian Pecahan**

**Golden Rule:** Balik pecahan kedua, lalu kalikan!

```
a/b : c/d = a/b × d/c = (a×d)/(b×c)
```

**Contoh:**
2/3 : 4/5 = 2/3 × 5/4 = 10/12 = 5/6 ✓

**Mnemonik:** "**K**eep, **C**hange, **F**lip"
- **Keep** pecahan pertama
- **Change** bagi jadi kali
- **Flip** pecahan kedua

### Bilangan Irasional (I atau ℚ') - The Wild Ones 🌪️

#### **Definisi - What Makes It Irrational?**

Bilangan irasional adalah bilangan yang **TIDAK BISA** dinyatakan sebagai pecahan p/q (dimana p dan q bilangan bulat).

**Karakteristik Desimal:**
- **Tidak pernah berakhir** DAN **tidak pernah berulang**
- Digitnya terus berlanjut tanpa pola yang teratur
- Unpredictable dan "liar"!

---

#### **Jenis-jenis Bilangan Irasional**

**1. Akar dari Bilangan Non-Kuadrat Sempurna**

**Kuadrat Sempurna (1-20) - WAJIB HAFAL!**
```
1²=1, 2²=4, 3²=9, 4²=16, 5²=25, 6²=36, 7²=49, 8²=64, 9²=81, 10²=100
11²=121, 12²=144, 13²=169, 14²=196, 15²=225, 16²=256, 17²=289, 18²=324, 19²=361, 20²=400
```

**Aturan:**
- √(kuadrat sempurna) = RASIONAL ✓
  - √4 = 2 (rasional)
  - √9 = 3 (rasional)
  - √16 = 4 (rasional)

- √(bukan kuadrat sempurna) = IRASIONAL ✗
  - √2 = 1.41421356... (irasional)
  - √3 = 1.73205080... (irasional)
  - √5 = 2.23606797... (irasional)
  - √7, √8, √10, √11, ... (semua irasional)

**2. Konstanta Matematika Terkenal**

**π (Pi)**
- π = 3.14159265358979323846...
- Perbandingan keliling dengan diameter lingkaran
- Tidak pernah berakhir, tidak pernah berulang
- 22/7 ≠ π (hanya aproksimasi!)

**e (Konstanta Euler)**
- e = 2.71828182845904523536...
- Basis logaritma natural
- Penting dalam kalkulus dan pertumbuhan eksponensial

**φ (Phi - Golden Ratio)**
- φ = 1.61803398874989...
- (1 + √5)/2
- Muncul di alam, seni, dan arsitektur

**3. Kombinasi Operasi yang Menghasilkan Irasional**

- √2 + √3 (irasional)
- π + e (irasional)
- 2√5 (irasional)
- 1/√2 (irasional)

---

#### **Cara Mengenali Bilangan Irasional di UTBK**

**Test 1: Cek Desimalnya**
Kalau kamu lihat desimal yang sangat panjang tanpa pola, kemungkinan besar irasional.

**Test 2: Akar Bukan Kuadrat Sempurna**
√(bilangan) → cek apakah bilangan tersebut hasil kuadrat?
- √50 → 50 bukan kuadrat sempurna → irasional ✓
- √49 → 49 = 7² → rasional ✓

**Test 3: Lihat Konstanta**
Kalau ada π, e, atau phi → pasti irasional!

**Test 4: Operasi Campuran**
- √2 × √2 = 2 (rasional!) ← Jebakan!
- √2 + √2 = 2√2 (irasional)
- √2 × √3 = √6 (irasional)

---

#### **Jebakan UTBK - Bilangan yang Terlihat Irasional Tapi Sebenarnya Rasional! 🎭**

**Jebakan #1: Akar Kuadrat Sempurna**
❌ Siswa pikir: "Ada √ berarti irasional"
✓ √16 = 4 (RASIONAL!)
✓ √25 = 5 (RASIONAL!)
✓ √100 = 10 (RASIONAL!)

**Jebakan #2: Akar dari Pecahan**
√(1/4) = 1/2 = 0.5 (RASIONAL!)
√(4/9) = 2/3 (RASIONAL!)

**Jebakan #3: Perkalian Akar yang Sama**
√2 × √2 = 2 (RASIONAL!)
√3 × √3 = 3 (RASIONAL!)
√5 × √5 = 5 (RASIONAL!)

**Jebakan #4: Akar dari Pangkat**
√(2²) = 2 (RASIONAL!)
√(3⁴) = 3² = 9 (RASIONAL!)

**Jebakan #5: 22/7**
❌ Banyak yang bilang 22/7 = π (irasional)
✓ 22/7 adalah RASIONAL! (sudah berbentuk pecahan)
✓ 22/7 ≈ 3.142857... (hanya aproksimasi π)

### Operasi pada Bilangan Irasional

#### **1. Penjumlahan & Pengurangan Bentuk Akar**

**Aturan:** Hanya bisa dijumlahkan kalau **bentuk akarnya sama**!

**Contoh yang BISA dijumlahkan:**
- 2√3 + 5√3 = 7√3 ✓ (sama-sama √3)
- 4√2 - √2 = 3√2 ✓ (sama-sama √2)
- 3√5 + 2√5 - √5 = 4√5 ✓

**Contoh yang TIDAK BISA dijumlahkan langsung:**
- √2 + √3 = √2 + √3 (tidak bisa disederhanakan!)
- 2√5 + 3√7 (tetap seperti ini)

**Analogi:** Kayak buah!
- 2 apel + 3 apel = 5 apel ✓
- 2 apel + 3 jeruk = tetap 2 apel + 3 jeruk ✓

**Tapi Sometimes Ada Trik!**
√8 + √2 = ?
→ √8 = √(4×2) = 2√2
→ 2√2 + √2 = 3√2 ✓

**Tips:** Selalu sederhanakan akar dulu sebelum menjumlahkan!

---

#### **2. Perkalian Bentuk Akar**

**Aturan Dasar:**
```
√a × √b = √(a×b)
```

**Contoh:**
- √2 × √3 = √6 ✓
- √5 × √5 = √25 = 5 ✓
- 2√3 × 3√2 = 6√6 ✓
- √8 × √2 = √16 = 4 ✓

**Dengan Koefisien:**
```
(a√b) × (c√d) = (a×c)√(b×d)
```

**Contoh:**
- 2√3 × 4√5 = 8√15 ✓
- 3√2 × 5√2 = 15√4 = 15×2 = 30 ✓

---

#### **3. Pembagian Bentuk Akar**

**Aturan Dasar:**
```
√a : √b = √(a/b)
```

**Contoh:**
- √8 : √2 = √(8/2) = √4 = 2 ✓
- √18 : √2 = √9 = 3 ✓

---

#### **4. Merasionalkan Penyebut - The Black Belt Skill! 🥋**

**Why Rasionalkan?**
Dalam matematika, bentuk seperti 1/√2 dianggap "belum rapi". Kita harus "rasionalkan" dengan menghilangkan akar dari penyebut.

**Teknik 1: Penyebut Bentuk √a**

**Rumus:** Kalikan dengan √a/√a

**Contoh:**
```
1/√2 = (1/√2) × (√2/√2) = √2/2 ✓
```

```
3/√5 = (3/√5) × (√5/√5) = 3√5/5 ✓
```

```
2/√3 = (2/√3) × (√3/√3) = 2√3/3 ✓
```

**Teknik 2: Penyebut Bentuk a√b**

**Contoh:**
```
6/(2√3) = 6/(2√3) × (√3/√3) = 6√3/6 = √3 ✓
```

**Teknik 3: Penyebut Bentuk (a + √b) atau (a - √b)**

**Rumus:** Gunakan **sekawan** (conjugate)!
- Sekawan (a + √b) adalah (a - √b)
- Sekawan (a - √b) adalah (a + √b)

**Why It Works?**
(a + √b)(a - √b) = a² - b (tidak ada akar lagi!)

**Contoh 1:**
```
1/(2 + √3) = ?
```
Kalikan dengan sekawan (2 - √3)/(2 - √3):
```
= 1/(2+√3) × (2-√3)/(2-√3)
= (2-√3)/(4-3)
= (2-√3)/1
= 2 - √3 ✓
```

**Contoh 2:**
```
1/(√5 - 2) = ?
```
Sekawan: (√5 + 2)/(√5 + 2)
```
= 1/(√5-2) × (√5+2)/(√5+2)
= (√5+2)/(5-4)
= √5 + 2 ✓
```

**Contoh 3:**
```
(3+√2)/(3-√2) = ?
```
Kalikan dengan (3+√2)/(3+√2):
```
= (3+√2)²/(9-2)
= (9 + 6√2 + 2)/7
= (11 + 6√2)/7 ✓
```

**Jebakan UTBK Alert! 🚨**
Jangan lupa mengkuadratkan dengan benar!
(a + √b)² = a² + 2a√b + b (bukan a² + b!)

### Membuktikan Suatu Bilangan Rasional atau Irasional

#### **Cara 1: Metode Kontradiksi (untuk √2)**

**Teorema:** √2 adalah irasional.

**Bukti (Simplified):**
1. Anggap √2 rasional, maka √2 = p/q (bentuk paling sederhana)
2. Kuadratkan: 2 = p²/q²
3. Maka: 2q² = p²
4. Berarti p² genap, maka p genap
5. Tulis p = 2k, maka p² = 4k²
6. Substitusi: 2q² = 4k², jadi q² = 2k²
7. Berarti q² genap, maka q genap
8. Kontradiksi! p dan q keduanya genap, padahal sudah bentuk paling sederhana.
9. Kesimpulan: √2 IRASIONAL ✓

**Cara 2: Cek Desimal**
Kalau ada pola berulang → rasional
Kalau tidak ada pola → irasional

**Cara 3: Cek Bentuk Pecahan**
Kalau bisa ditulis p/q → rasional
Kalau tidak bisa → irasional

### Sifat-sifat Penting Rasional & Irasional

**Sifat 1: Penjumlahan & Pengurangan**
- Rasional + Rasional = Rasional ✓
- Irasional + Irasional = **Bisa rasional, bisa irasional!**
  - √2 + √2 = 2√2 (irasional)
  - √2 + (-√2) = 0 (rasional!)
- Rasional + Irasional = Irasional ✓
  - 3 + √2 (irasional)

**Sifat 2: Perkalian**
- Rasional × Rasional = Rasional ✓
- Irasional × Irasional = **Bisa rasional, bisa irasional!**
  - √2 × √2 = 2 (rasional!)
  - √2 × √3 = √6 (irasional)
- Rasional (≠0) × Irasional = Irasional ✓
  - 2 × √3 = 2√3 (irasional)

**Sifat 3: Pembagian**
- Rasional : Rasional = Rasional ✓
- Irasional : Irasional = **Bisa rasional, bisa irasional!**
  - √8 : √2 = 2 (rasional!)
  - √2 : √3 = √(2/3) (irasional)

**Sifat 4: Kerapatan**
- Antara dua bilangan rasional, selalu ada bilangan rasional lain.
- Antara dua bilangan rasional, selalu ada bilangan irasional.
- Antara dua bilangan irasional, selalu ada bilangan rasional DAN irasional.

## Materi 2.1.4: Operasi pada Bilangan Pecahan

### Pecahan: Small Numbers, Big Impact! 🎯

Pecahan itu kayak puzzle pieces - keliatan kecil tapi kalau salah pasang, rusak semua! Di UTBK, soal pecahan sering jadi "speed bump" yang bikin siswa kehilangan waktu berharga. Tapi tenang, setelah ini kamu bakal jago operasi pecahan dengan cepat dan akurat!

---

### Jenis-jenis Pecahan - Know Your Enemy!

#### **1. Pecahan Biasa**

Bentuk standar: **a/b** (a = pembilang, b = penyebut)

**Klasifikasi:**
- **Pecahan Murni:** Pembilang < Penyebut
  - 1/2, 3/4, 5/8, 7/10
  
- **Pecahan Tidak Murni:** Pembilang ≥ Penyebut
  - 5/3, 7/4, 9/2, 10/10

**Syarat Penyebut:**
- **TIDAK BOLEH NOL!** (b ≠ 0)
- Kalau b = 0, pecahan tidak terdefinisi (undefined)

---

#### **2. Pecahan Campuran**

Bentuk: **a b/c** (a = bilangan bulat, b/c = pecahan murni)

**Contoh:**
- 2½ (dua setengah)
- 3¾ (tiga tiga perempat)
- 5⅖ (lima dua perlima)

**Hubungan dengan Pecahan Biasa:**
```
a b/c = (a×c + b)/c
```

**Contoh Konversi:**
- 2½ = (2×2 + 1)/2 = 5/2
- 3¾ = (3×4 + 3)/4 = 15/4

### Menyederhanakan Pecahan - Making It Simple!

**Aturan Emas:** Bagi pembilang dan penyebut dengan **FPB** mereka.

**Langkah-langkah:**
1. Cari FPB dari pembilang dan penyebut
2. Bagi keduanya dengan FPB
3. Ulangi sampai tidak bisa disederhanakan lagi

**Contoh 1:**
```
12/18 = ?
FPB(12, 18) = 6
12/18 = (12÷6)/(18÷6) = 2/3 ✓
```

**Contoh 2:**
```
24/36 = ?
FPB(24, 36) = 12
24/36 = (24÷12)/(36÷12) = 2/3 ✓
```

**Trik Cepat - Faktorisasi Prima:**
```
48/72 = (2⁴×3)/(2³×3²)
Coret yang sama: 2³ dan 3
= 2/3 ✓
```

**Pecahan Sudah Sederhana Kalau:**
- FPB(pembilang, penyebut) = 1
- Tidak ada faktor persekutuan lagi
- Contoh: 3/7, 5/8, 7/11

### Penjumlahan dan Pengurangan Pecahan

#### **Rule #1: Penyebut Harus Sama!**

**Kasus 1: Penyebut Sudah Sama**

Super gampang! Langsung jumlahkan/kurangkan pembilangnya.

```
a/c + b/c = (a+b)/c
a/c - b/c = (a-b)/c
```

**Contoh:**
```
2/7 + 3/7 = 5/7 ✓
5/9 - 2/9 = 3/9 = 1/3 ✓
```

---

**Kasus 2: Penyebut Berbeda**

**Langkah-langkah:**
1. Cari **KPK** dari penyebut
2. Ubah setiap pecahan ke penyebut KPK
3. Jumlahkan/kurangkan pembilangnya
4. Sederhanakan hasil

**Contoh 1: 1/4 + 2/3**
```
Step 1: KPK(4, 3) = 12
Step 2: 1/4 = 3/12; 2/3 = 8/12
Step 3: 3/12 + 8/12 = 11/12 ✓
```

**Contoh 2: 3/5 - 1/6**
```
KPK(5, 6) = 30
3/5 = 18/30; 1/6 = 5/30
18/30 - 5/30 = 13/30 ✓
```

---

**Trik Cepat: Butterfly Method / Cross Multiply**

Untuk penjumlahan **a/b + c/d**:
```
a/b + c/d = (a×d + b×c)/(b×d)
```

Visual:
```
  a     c       a×d + b×c
 ─── + ─── = ─────────────
  b     d          b×d
```

**Contoh:**
```
1/4 + 2/3 = (1×3 + 4×2)/(4×3) = (3+8)/12 = 11/12 ✓
```

**Warning:** Jangan lupa sederhanakan kalau perlu!

---

**Kasus 3: Pecahan Campuran**

**Cara 1: Ubah ke Pecahan Biasa Dulu**
```
2½ + 1¾ = 5/2 + 7/4
        = 10/4 + 7/4
        = 17/4
        = 4¼ ✓
```

**Cara 2: Pisahkan Bulat dan Pecahan**
```
2½ + 1¾ = (2 + 1) + (½ + ¾)
        = 3 + (2/4 + 3/4)
        = 3 + 5/4
        = 3 + 1¼
        = 4¼ ✓
```

**Pengurangan Campuran:**
```
3¾ - 1⅖
= 15/4 - 7/5
= 75/20 - 28/20
= 47/20
= 2 7/20 ✓
```

### Pengertian Bilangan Berpangkat

**Definisi:**
Bilangan berpangkat adalah perkalian berulang dari bilangan yang sama.

**Bentuk Umum:**
```
aⁿ = a × a × a × ... × a (n kali)
```

**Komponen:**
- **a** = basis (bilangan pokok)
- **n** = eksponen (pangkat)
- **aⁿ** = hasil perpangkatan

**Contoh:**
```
2³ = 2 × 2 × 2 = 8
5² = 5 × 5 = 25
10⁴ = 10 × 10 × 10 × 10 = 10.000
```

---

### Jenis-jenis Pangkat

#### **1. Pangkat Bulat Positif**

Yang paling dasar dan paling sering dipakai.

**n = 1:** (Identitas)
```
a¹ = a
5¹ = 5
100¹ = 100
```

**n = 2:** (Kuadrat)
```
a² = a × a
3² = 9
7² = 49
```

**n = 3:** (Kubik)
```
a³ = a × a × a
2³ = 8
4³ = 64
```

**Hafal Pangkat 2 (1-20):**
```
1²=1, 2²=4, 3²=9, 4²=16, 5²=25, 6²=36, 7²=49, 8²=64, 9²=81, 10²=100
11²=121, 12²=144, 13²=169, 14²=196, 15²=225, 16²=256, 17²=289, 18²=324, 19²=361, 20²=400
```

**Hafal Pangkat 3 (1-10):**
```
1³=1, 2³=8, 3³=27, 4³=64, 5³=125, 6³=216, 7³=343, 8³=512, 9³=729, 10³=1000
```

---

#### **2. Pangkat Nol**

**Aturan Emas:**
```
a⁰ = 1 (untuk a ≠ 0)
```

**Contoh:**
```
5⁰ = 1
100⁰ = 1
(-3)⁰ = 1
(1/2)⁰ = 1
```

**Why?** Karena:
```
aⁿ/aⁿ = aⁿ⁻ⁿ = a⁰ = 1 ✓
```

**PENTING:** 0⁰ adalah **tidak terdefinisi** (undefined)!

---

#### **3. Pangkat Negatif**

**Aturan:**
```
a⁻ⁿ = 1/aⁿ
```

**Pangkat negatif = Kebalikan dari pangkat positif!**

**Contoh:**
```
2⁻³ = 1/2³ = 1/8
5⁻² = 1/5² = 1/25
10⁻¹ = 1/10 = 0.1
```

**Untuk Pecahan:**
```
(a/b)⁻ⁿ = (b/a)ⁿ
(2/3)⁻² = (3/2)² = 9/4
```

---

#### **4. Pangkat Pecahan (Akar)**

**Aturan:**
```
a^(1/n) = ⁿ√a (akar pangkat n dari a)
a^(m/n) = ⁿ√(aᵐ) = (ⁿ√a)ᵐ
```

**Contoh:**
```
4^(1/2) = √4 = 2
8^(1/3) = ³√8 = 2
27^(1/3) = ³√27 = 3
16^(3/4) = (⁴√16)³ = 2³ = 8
```

**Hubungan Akar dan Pangkat:**
```
√a = a^(1/2)
³√a = a^(1/3)
ⁿ√a = a^(1/n)
```

Ini adalah **HUKUM ALAM** dalam dunia pangkat. Wajib hafal!

#### **Sifat 1: Perkalian dengan Basis Sama**

```
aᵐ × aⁿ = a^(m+n)
```

**Pangkat dijumlahkan!**

**Contoh:**

```
x² × x³ = x⁵
5⁴ × 5² × 5 = 5⁷
```

```

```

**Contoh:**
```

x⁷ / x³ = x⁴
10⁶ / 10² = 10⁴ = 10.000
```

**Special Case:**
```
aⁿ / aⁿ = a⁰ = 1
```

---

```
(aᵐ)ⁿ = a^(m×n)
```

```
(ab)ⁿ = aⁿ × bⁿ
```

#### **Sifat 5: Pembagian Berpangkat**

```
(a/b)ⁿ = aⁿ/bⁿ
```

**Contoh:**

```
(x/y)³ = x³/y³
(10/5)² = 10²/5² = 100/25 = 4
```

#### **Sifat 6: Pangkat Negatif**

**Contoh:**

```
1/2⁻³ = 2³ = 8
```

#### **Sifat 7: Pangkat Nol**

## Materi 2.1.6: Akar dan Operasinya

### Welcome to the Root Zone! 🌱

Kalau bilangan berpangkat itu kayak naik ke atas, maka akar adalah kebalikannya - turun ke bawah mencari asal-usul! Akar adalah **inverse** (kebalikan) dari perpangkatan. Di UTBK, kemampuan operasi akar ini KRUSIAL banget, terutama dalam menyederhanakan ekspresi aljabar yang kompleks!

---

### Pengertian Akar

**Definisi:**
Akar pangkat n dari bilangan a adalah bilangan b sedemikian sehingga bⁿ = a.

**Notasi:**
```
ⁿ√a = b ↔ bⁿ = a
```

**Komponen:**
- **√** = simbol akar (radikal)
- **n** = indeks akar (pangkat)
- **a** = radikan (bilangan di dalam akar)
- **b** = hasil akar

---

### Jenis-jenis Akar

#### **1. Akar Kuadrat (n = 2)**

**Notasi:** √a (tanpa angka 2)

**Definisi:**
```
√a = b ↔ b² = a
```

**Contoh:**
```
√4 = 2 (karena 2² = 4)
√9 = 3 (karena 3² = 9)
√16 = 4 (karena 4² = 16)
√25 = 5 (karena 5² = 25)
```

**PENTING:** 
- √a selalu berarti akar kuadrat **POSITIF**!
- √4 = 2 (bukan ±2)
- Untuk ±, harus ditulis eksplisit: ±√4 = ±2

**Kuadrat Sempurna 1-20 (HAFAL!):**
```
√1=1, √4=2, √9=3, √16=4, √25=5, √36=6, √49=7, √64=8, √81=9, √100=10
√121=11, √144=12, √169=13, √196=14, √225=15, √256=16, √289=17, √324=18, √361=19, √400=20
```

---

#### **2. Akar Kubik (n = 3)**

**Notasi:** ³√a

**Definisi:**
```
³√a = b ↔ b³ = a
```

**Contoh:**
```
³√8 = 2 (karena 2³ = 8)
³√27 = 3 (karena 3³ = 27)
³√64 = 4 (karena 4³ = 64)
³√125 = 5 (karena 5³ = 125)
```

**Beda dengan Akar Kuadrat:**
Akar kubik bisa untuk bilangan negatif!
```
³√(-8) = -2 (karena (-2)³ = -8)
³√(-27) = -3 (karena (-3)³ = -27)
```

**Kubik Sempurna 1-10 (HAFAL!):**
```
³√1=1, ³√8=2, ³√27=3, ³√64=4, ³√125=5, ³√216=6, ³√343=7, ³√512=8, ³√729=9, ³√1000=10
```

---

#### **3. Akar Pangkat n**

**Notasi:** ⁿ√a

**Sifat Genap vs Ganjil:**

**n Genap (4, 6, 8, ...):**
- Hanya berlaku untuk a ≥ 0
- Hasil selalu positif
- ⁴√16 = 2 (bukan ±2)

**n Ganjil (3, 5, 7, ...):**
- Berlaku untuk semua bilangan real
- Tanda mengikuti radikan
- ⁵√(-32) = -2

### Hubungan Akar dengan Pangkat Pecahan

**Formula Konversi:**
```
ⁿ√a = a^(1/n)
ⁿ√(aᵐ) = a^(m/n)
```

**Contoh:**
```
√a = a^(1/2)
³√a = a^(1/3)
⁴√a = a^(1/4)

√(a³) = a^(3/2)
³√(a²) = a^(2/3)
⁴√(a⁵) = a^(5/4)
```

**Aplikasi:**
```
√8 = 8^(1/2) = (2³)^(1/2) = 2^(3/2) = 2√2
³√16 = 16^(1/3) = (2⁴)^(1/3) = 2^(4/3)
```

**Akar dari perkalian = perkalian dari akar**

**Contoh:**

```
√36 = 6 ✓
```

**Jebakan #4: Sekawan Salah**
❌ Sekawan (3 + √2) adalah (-3 - √2)
✓ Sekawan (3 + √2) adalah (3 - √2)

**Jebakan #5: Tanda dalam Akar**
❌ √(-4) = -2
✓ √(-4) tidak terdefinisi dalam bilangan real!

**Jebakan #6: Akar Negatif**
```
√4 = ±2 ❌
√4 = 2 ✓ (selalu positif!)

Untuk ±2, harus ditulis: ±√4
```

