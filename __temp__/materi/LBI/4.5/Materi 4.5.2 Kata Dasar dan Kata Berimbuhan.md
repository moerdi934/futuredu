## **Topik 4.5: Ejaan - Penulisan Kata**

### **Materi 4.5.2: Kata Dasar dan Kata Berimbuhan**

#### **Kata Dasar: The Foundation**

Kata dasar itu ibarat fondasi rumah. Simple, polos, belum diapa-apain. Contohnya: *tulis*, *baca*, *datang*, *pergi*, *rumah*, *sekolah*. Penulisannya? Ya tulis aja apa adanya. Nggak ada drama, nggak ada jebakan.

Tapi jangan ketipu! SNBT kadang kasih kata dasar yang mirip sama kata berimbuhan. Contoh: *tahu* (kata dasar) vs *ketahuan* (kata berimbuhan). Jadi tetep harus teliti!

#### **Kata Berimbuhan: The Real Deal**

Nah, ini yang seru! Kata berimbuhan itu kata dasar yang udah dikasih "baju" berupa imbuhan. Imbuhannya bisa di mana aja:
- **Awalan (Prefiks)**: di depan kata dasar
- **Akhiran (Sufiks)**: di belakang kata dasar
- **Sisipan (Infiks)**: di tengah kata dasar (jarang sih)
- **Gabungan (Konfiks)**: awalan + akhiran sekaligus

**ATURAN EMAS:** Kata berimbuhan **SELALU DITULIS SERANGKAI** dengan kata dasarnya!

#### **Awalan (Prefiks) yang Harus Kamu Kuasai**

**1. Awalan ME-**

Ini awalan paling sering muncul dan paling banyak variasi peluluhannya. Bentuk dasarnya *me-*, tapi bisa berubah jadi *mem-*, *men-*, *meng-*, *meny-*, atau *menge-* tergantung huruf awal kata dasarnya.

**Aturan Peluluhan ME-:**

- **ME- + kata dasar berawalan l, m, n, r, w, y** → tetap *me-*
  - *me* + *lawan* = *melawan*
  - *me* + *rawat* = *merawat*
  - *me* + *yakin* = *meyakin*

- **MEM- + kata dasar berawalan b, f, p, v** → jadi *mem-*
  - *mem* + *baca* = *membaca*
  - *mem* + *fitnah* = *memfitnah*
  - *mem* + *pakai* = *memakai* (huruf p luluh!)
  - *mem* + *vonis* = *memvonis*

- **MEN- + kata dasar berawalan c, d, j, sy, t** → jadi *men-*
  - *men* + *catat* = *mencatat*
  - *men* + *dengar* = *mendengar*
  - *men* + *jual* = *menjual*
  - *men* + *tulis* = *menulis* (huruf t luluh!)

- **MENG- + kata dasar berawalan vokal, g, h, k** → jadi *meng-*
  - *meng* + *ambil* = *mengambil*
  - *meng* + *gali* = *menggali*
  - *meng* + *hitung* = *menghitung*
  - *meng* + *kaji* = *mengkaji* (huruf k luluh!)

- **MENY- + kata dasar berawalan s** → jadi *meny-*
  - *meny* + *sapu* = *menyapu* (huruf s luluh!)
  - *meny* + *usun* = *menyusun*

- **MENGE- + kata dasar satu suku kata** → jadi *menge-*
  - *menge* + *cat* = *mengecat*
  - *menge* + *bom* = *mengebom*
  - *menge* + *las* = *mengelas*

**Jebakan SNBT:**
- Mereka suka kasih pilihan yang nggak luluh padahal harusnya luluh. Contoh: "mengkaji" (salah) vs "mengaji" (benar kalau dari kata *kaji*)
- Atau sebaliknya: meluluhkan yang nggak perlu luluh. Contoh: "mempunyai" (benar) bukan "memunyai"

**Pengecualian Penting:**
- *mengkaji* (dari kata *kaji*, k luluh jadi ng)
- *mempunyai* (dari kata *punya*, TIDAK luluh! Ini pengecualian!)

**2. Awalan DI-**

Ini lebih simple. Awalan *di-* nggak mengalami peluluhan seperti *me-*. Bentuknya tetap *di-* untuk semua kata dasar.

Contoh:
- *di* + *makan* = *dimakan*
- *di* + *tulis* = *ditulis*
- *di* + *kerjakan* = *dikerjakan*
- *di* + *percaya* = *dipercaya*

**SUPER PENTING - Bedakan DI- (Awalan) vs DI (Kata Depan):**

Ini jebakan favorit SNBT! Banyak siswa yang bingung kapan *di* ditulis serangkai dan kapan dipisah.

**DI- sebagai Awalan (Serangkai):**
- Menunjukkan kata kerja pasif
- Bisa diganti dengan awalan *ter-* atau frasa "telah/sudah"
- Contoh: *dimakan* (sudah dimakan), *ditulis* (sudah ditulis)

**DI sebagai Kata Depan (Terpisah):**
- Menunjukkan tempat
- Diikuti oleh kata benda tempat
- Contoh: *di rumah*, *di sekolah*, *di sana*

**Cara Tes Cepat:**
- Coba tambahkan kata "tempat" setelah *di*. Kalau masuk akal, berarti kata depan (terpisah).
  - "di (tempat) rumah" → masuk akal → *di rumah* (terpisah)
  - "di (tempat) makan" → nggak masuk akal → *dimakan* (serangkai)

**Contoh Jebakan:**
- ❌ *di percaya* (salah) → ✅ *dipercaya* (benar)
- ❌ *dirumah* (salah) → ✅ *di rumah* (benar)
- ❌ *di beri* (salah) → ✅ *diberi* (benar)
- ❌ *disekolah* (salah) → ✅ *di sekolah* (benar)

**3. Awalan TER-**

Awalan *ter-* juga nggak mengalami peluluhan. Bentuknya tetap *ter-* untuk semua kata dasar.

Contoh:
- *ter* + *tulis* = *tertulis*
- *ter* + *buka* = *terbuka*
- *ter* + *sangkut* = *tersangkut*
- *ter* + *lihat* = *terlihat*

Makna *ter-*:
- **Paling** (superlatif): *terbesar*, *tercantik*, *terpintar*
- **Dapat/bisa** (kemungkinan): *terbaca*, *terlihat*, *terdengar*
- **Tidak sengaja** (ketidaksengajaan): *terjatuh*, *tertidur*, *terpeleset*
- **Sudah** (perfektif): *tertutup*, *terbuka*, *tersimpan*

**4. Awalan BER-**

Awalan *ber-* juga stabil, nggak banyak drama. Tapi ada beberapa variasi:

- **BER-** (bentuk standar):
  - *ber* + *jalan* = *berjalan*
  - *ber* + *main* = *bermain*
  - *ber* + *temu* = *bertemu*

- **BE-** (kalau kata dasar berawalan r):
  - *be* + *renang* = *berenang* (r luluh!)
  - *be* + *rakhir* = *berakhir* (TIDAK luluh! Pengecualian!)

- **BEL-** (bentuk khusus):
  - *bel* + *ajar* = *belajar*
  - Ini satu-satunya kata dengan *bel-*!

Makna *ber-*:
- **Mempunyai**: *berambut* (punya rambut), *beruang* (punya uang)
- **Memakai/menggunakan**: *bersepeda* (pakai sepeda), *berbaju* (pakai baju)
- **Melakukan**: *berlari*, *berjalan*, *bermain*

**5. Awalan PE-**

Awalan *pe-* digunakan untuk membentuk kata benda. Peluluhannya mirip dengan *me-*, tapi hasilnya kata benda, bukan kata kerja.

- **PE-**: *pe* + *lari* = *pelari*
- **PEM-**: *pem* + *baca* = *pembaca*, *pem* + *bantu* = *pembantu*
- **PEN-**: *pen* + *dengar* = *pendengar*, *pen* + *jual* = *penjual*
- **PENG-**: *peng* + *usaha* = *pengusaha*, *peng* + *gali* = *penggali*
- **PENY-**: *peny* + *sapu* = *penyapu*
- **PENGE-**: *penge* + *cat* = *pengecat*

**6. Awalan SE-**

Awalan *se-* relatif simple dan nggak ada peluluhan.

Contoh:
- *se* + *rumah* = *serumah*
- *se* + *kelas* = *sekelas*
- *se* + *orang* = *seorang*
- *se* + *hari* = *sehari*

Makna *se-*:
- **Satu**: *seorang*, *sebuah*, *sehelai*
- **Sama**: *setinggi*, *sebesar*, *sepanjang*
- **Seluruh/semua**: *sedunia*, *seantero*, *semesta*

#### **Akhiran (Sufiks) yang Harus Kamu Kuasai**

**1. Akhiran -KAN**

Akhiran *-kan* digunakan untuk membentuk kata kerja transitif (butuh objek).

Contoh:
- *makan* + *kan* = *makanan* (eh ini kata benda ternyata!)
- *besar* + *kan* = *besarkan*
- *ajari* + *kan* = *ajarkan*

**Hati-hati dengan bentuk gabungan:**
- *me* + *besar* + *kan* = *membesarkan*
- *di* + *baca* + *kan* = *dibacakan*

Makna *-kan*:
- **Menyebabkan**: *besarkan* (menyebabkan besar)
- **Membuat jadi**: *besarkan* (membuat jadi besar)
- **Menjadikan**: *ajarkan* (menjadikan tahu)
- **Benefaktif** (untuk orang lain): *bacakan* (baca untuk orang lain)

**2. Akhiran -I**

Akhiran *-i* juga membentuk kata kerja transitif, tapi dengan nuansa berbeda dari *-kan*.

Contoh:
- *datang* + *i* = *datangi*
- *kunjung* + *i* = *kunjungi*
- *jauhi* + *i* = *jauhi*

**Bentuk gabungan:**
- *me* + *datang* + *i* = *mendatangi*
- *di* + *kunjung* + *i* = *dikunjungi*

Makna *-i*:
- **Melakukan ke objek**: *datangi* (datang ke...)
- **Melakukan berulang**: *pukuli* (pukul berkali-kali)
- **Melakukan di tempat**: *duduki* (duduk di...)

**Bedanya -KAN vs -I:**
- *-kan*: lebih ke arah "menyebabkan" atau "untuk orang lain"
- *-i*: lebih ke arah "ke objek tertentu" atau "berulang"

Contoh:
- *bacakan* = baca untuk orang lain
- *bacai* = nggak ada! (nggak lazim)
- *datangkan* = menyebabkan datang/mendatangkan
- *datangi* = datang ke tempat

**3. Akhiran -AN**

Akhiran *-an* punya banyak fungsi dan bisa membentuk berbagai jenis kata.

Contoh:
- *makan* + *an* = *makanan* (kata benda)
- *rumah* + *an* = *rumahan* (kata sifat)
- *besar* + *an* = *besaran* (kata benda)
- *tanam* + *an* = *tanaman* (kata benda)

Makna *-an*:
- **Hasil dari**: *makanan* (hasil dari makan), *tulisan* (hasil dari tulis)
- **Alat untuk**: *timbangan* (alat untuk timbang), *gantungan* (alat untuk gantung)
- **Tempat**: *dudukan* (tempat duduk), *simpanan* (tempat simpan)
- **Bersifat**: *rumahan* (bersifat rumah), *kampungan* (bersifat kampung)
- **Yang di-**: *bacaan* (yang dibaca), *kiriman* (yang dikirim)

#### **Sisipan (Infiks) - The Rare One**

Sisipan itu jarang banget dipakai dalam bahasa Indonesia modern. Tapi tetep harus tahu karena kadang muncul di SNBT!

Ada tiga sisipan: *-el-*, *-em-*, *-er-*

Contoh:
- *-el-*: *g* + *el* + *etar* = *geletar*, *t* + *el* + *unju* = *telunjuk*
- *-em-*: *g* + *em* + *uruh* = *gemuruh*, *t* + *em* + *aling* = *temali*
- *-er-*: *g* + *er* + *igi* = *gerigi*, *s* + *er* + *uling* = *seruling*

Sisipan ini biasanya dipakai di kata-kata khusus atau kata yang udah baku gitu. Jarang ada yang baru.

#### **Gabungan (Konfiks) - The Power Couple**

Ini kombinasi awalan dan akhiran yang dipasang bersamaan. Mereka bekerja sebagai satu kesatuan, nggak bisa dipisah-pisahin.

**1. KE-AN**

Konfiks *ke-an* membentuk kata benda atau kata sifat.

Contoh:
- *ke* + *bahagia* + *an* = *kebahagiaan*
- *ke* + *rinduan* + *an* = *kerinduaan*
- *ke* + *mampuan* + *an* = *kemampuan*
- *ke* + *besaran* + *an* = *kebesaran*

Makna *ke-an*:
- **Hal/sifat**: *kebahagiaan* (hal bahagia), *kecantikan* (hal cantik)
- **Tempat**: *kerajaan* (tempat raja), *kedutaan* (tempat duta)
- **Terlalu** (berlebihan): *kepanasan* (terlalu panas), *kehujanan* (terlalu hujan)
- **Terkena**: *kecopetan* (terkena copet), *ketilangan* (terkena hilang)

**2. PE-AN**

Konfiks *pe-an* membentuk kata benda yang abstrak.

Contoh:
- *pe* + *laku* + *an* = *pelakuan* (tapi yang lazim: *perlakuan*)
- *pem* + *baca* + *an* = *pembacaan*
- *pen* + *dengar* + *an* = *pendengaran*
- *peng* + *usaha* + *an* = *pengusahaan*

Makna *pe-an*:
- **Proses**: *pembacaan* (proses membaca), *penulisan* (proses menulis)
- **Hal**: *perdagangan* (hal berdagang), *pembelajaran* (hal belajar)
- **Tempat**: *peladangan* (tempat ladang), *perkebunan* (tempat kebun)

**3. BER-AN**

Konfiks *ber-an* membentuk kata kerja dengan makna jamak atau saling.

Contoh:
- *ber* + *lari* + *an* = *berlarian* (lari bersama-sama)
- *ber* + *kejar* + *an* = *berkejaran* (saling kejar)
- *ber* + *tabrakan* + *an* = *bertabrakan* (saling tabrakan)

**4. PER-AN**

Konfiks *per-an* membentuk kata benda.

Contoh:
- *per* + *temu* + *an* = *pertemuan*
- *per* + *tanding* + *an* = *pertandingan*
- *per* + *main* + *an* = *permainan*

#### **Hukum K, T, S, P - The Disappearing Act**

Ini nih yang sering bikin bingung! Ada huruf-huruf tertentu yang "hilang" atau "luluh" ketika ketemu awalan tertentu.

**Huruf K:**
- Luluh jadi *ng* kalau ketemu *me-*
- *me* + *kaji* = *mengkaji* (k luluh jadi ng)
- *me* + *kirim* = *mengirim* (k luluh jadi ng)

**Huruf P:**
- Luluh jadi *m* kalau ketemu *me-*
- *me* + *pukul* = *memukul* (p luluh jadi m)
- *me* + *pakai* = *memakai* (p luluh jadi m)

**Huruf T:**
- Luluh jadi *n* kalau ketemu *me-*
- *me* + *tulis* = *menulis* (t luluh jadi n)
- *me* + *tanam* = *menanam* (t luluh jadi n)

**Huruf S:**
- Luluh jadi *ny* kalau ketemu *me-*
- *me* + *sapu* = *menyapu* (s luluh jadi ny)
- *me* + *usun* = *menyusun* (s luluh jadi ny)

#### **Pengecualian: The Rule Breakers**

Nah, ini yang harus kamu hafalin karena SNBT suka banget ngejebak di sini!

**1. MEMPUNYAI**
Kata ini TIDAK luluh! Bukan "memunyai", tapi **mempunyai**.

**2. MENGKAJI**
Ini contoh peluluhan yang benar: k luluh jadi ng.

**3. BER- + R**
Biasanya luluh (*berenang*), tapi ada pengecualian seperti *berakhir* (TIDAK luluh).

**4. Kata Serapan**
Kata dari bahasa asing biasanya nggak luluh.
- *me* + *format* = *memformat* (TIDAK luluh karena kata serapan)
- *me* + *program* = *memprogram* (TIDAK luluh)

#### **Tips Menghadapi Soal Kata Berimbuhan di SNBT**

1. **Kenali Jenis Imbuhannya**
   
   Lihat dulu imbuhannya apa. Awalan? Akhiran? Konfiks? Setiap jenis punya aturan sendiri.

2. **Cek Peluluhan**
   
   Kalau ada awalan *me-*, cek apakah peluluhannya sudah benar. Ini jebakan favorit!

3. **Jangan Lupa Pengecualian**
   
   Hafalin pengecualian seperti *mempunyai*. SNBT pasti ngejebak di sini.

4. **Baca dengan Teliti**
   
   Kadang perbedaannya cuma satu huruf. *Mengkaji* vs *mengaji* beda makna lho!

5. **Latihan Identifikasi Cepat**
   
   Latih kemampuan kamu untuk langsung tahu ini kata berimbuhan atau bukan. Speed is key!
