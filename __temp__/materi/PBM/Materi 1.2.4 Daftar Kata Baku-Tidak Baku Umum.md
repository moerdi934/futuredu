### **G. Preposisi dan Kata Depan yang Sering Keliru**

| **Tidak Baku** | **Baku** | **Penjelasan** |
|----------------|----------|----------------|
| dirumah | di rumah | "Di" sebagai kata depan ditulis terpisah |
| disekolah | di sekolah | Pisahkan kata depan |
| kepasar | ke pasar | "Ke" sebagai kata depan ditulis terpisah |
| diberitahu | diberitahu | Ini benar (imbuhan, bukan kata depan) |
| di beri tahu | diberitahu | Salah! Kalau imbuhan, tulis serangkai |
| dari pada | daripada | Ditulis serangkai |
| mana kala | manakala | Ditulis serangkai |
| di antara | di antara | Benar, ditulis terpisah |
| diantara | di antara | Salah! Harus terpisah |
| terhadap | terhadap | Bukan "terhadapan" |
| mengenai | mengenai | Bukan "mengenain" |

**Tips Penting:**
- **"Di", "ke", "dari"** sebagai **kata depan** → ditulis **terpisah**
  - Contoh: di rumah, ke sekolah, dari kantor
- **"Di-"** sebagai **imbuhan** → ditulis **serangkai**
  - Contoh: dibawa, diambil, diberitahu

**Cara Bedain:**
- Kalau "di/ke/dari" + **kata benda tempat** → **terpisah**
- Kalau "di-" + **kata kerja** → **serangkai** (imbuhan pasif)

### **H. Kata Ganti yang Sering Salah**

| **Tidak Baku** | **Baku** | **Konteks** |
|----------------|----------|-------------|
| saya punya | milik saya | Lebih formal |
| punya saya | milik saya / saya | Informal |
| dia punya | miliknya | Atau "milik dia" |
| aku | saya | Formal: saya. Informal: aku |
| gue/gw | saya | "Gue" sangat tidak baku |
| lu/lo | kamu / Anda | "Lu" sangat tidak baku |
| ente | Anda | Betawi, tidak baku |
| kalian | kalian | Ini baku! |
| mereka semua | mereka | "Semua" bisa redundan tergantung konteks |

**Dalam Konteks Formal/SNBT:**
- Gunakan: **saya, kamu, Anda, dia, mereka, kami, kita**
- Hindari: **aku, gue, lu, ente, kalian** (meskipun "kalian" baku, tapi kurang formal)

### **J. Bentuk Tidak Baku Karena Redundansi (Mubazir)**

Ini kesalahan yang sering nggak disadari—ngulang kata atau makna yang udah jelas.

| **Redundan (Salah)** | **Baku (Benar)** | **Alasan** |
|----------------------|------------------|------------|
| para tamu-tamu | para tamu / tamu-tamu | "Para" dan "-tamu" sama-sama menunjukkan jamak |
| sejak dari | sejak | "Sejak" sudah mengandung makna "dari" |
| turun ke bawah | turun | "Turun" otomatis ke bawah |
| naik ke atas | naik | "Naik" otomatis ke atas |
| masuk ke dalam | masuk | "Masuk" otomatis ke dalam |
| keluar ke luar | keluar | "Keluar" otomatis ke luar |
| kembali lagi | kembali | "Kembali" dan "lagi" artinya sama |
| sudah pernah | pernah / sudah | Keduanya menunjukkan waktu lampau |
| agak sedikit | agak / sedikit | Pilih salah satu |
| lebih baik lagi | lebih baik | "Lagi" tidak perlu |
| hanya saja | hanya / saja | Pilih salah satu |
| hanya semata-mata | hanya / semata-mata | Artinya sama |
| yang mana | yang | "Mana" tidak perlu |
| seperti misalnya | seperti / misalnya | Keduanya fungsi sama |
| mulai dari | mulai / dari | Pilih salah satu |

**Kenapa Redundan?**
Karena dua kata mengungkapkan makna yang sama, jadi salah satunya jadi "sampah". Kalimat efektif itu hemat—jangan buang-buang kata!
