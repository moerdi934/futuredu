# List Materi - Literasi Bahasa Inggris SNBT

## Section 1: Text Idea

### Topik 1.1: Main Idea

**Materi 1.1.1: Pengenalan Main Idea dan Topic** *(Materi Dibuka)*
- Perbedaan konsep Main Idea (kalimat lengkap) dan Topic (frasa/kata kunci)
- Karakteristik Main Idea: dasar pembahasan, inti paragraf/teks, memiliki subjek dan predikat
- Variasi pertanyaan dalam soal SNBT (main idea, primary idea, best title, subject, topic)
- Posisi Main Idea dalam struktur teks (awal, tengah, akhir, atau tersirat)
- Referensi silang: hubungan Main Idea dengan analisis Purpose (Topik 1.2)

**Materi 1.1.2: Analisis Main Idea di Paragraf Pertama**
- Main Idea deductive (di awal paragraf): kalimat pertama sebagai general statement
- Main Idea inductive (di akhir paragraf): kalimat terakhir sebagai kesimpulan
- Main Idea tersirat (implicit): menyimpulkan dari keseluruhan informasi paragraf
- Teknik identifikasi: membaca kalimat pertama dan terakhir, mencari pola pengembangan
- Analisis supporting details yang mendukung Main Idea

**Materi 1.1.3: Analisis Main Idea di Paragraf Tengah dan Akhir**
- Fungsi paragraf tengah: mengembangkan ide dari paragraf pertama
- Posisi Main Idea paragraf tengah: biasanya di kalimat pertama
- Paragraf akhir sebagai kesimpulan atau ringkasan keseluruhan teks
- Teknik skimming: fokus pada kalimat pertama setiap paragraf untuk mapping ide
- Hubungan koheren antar Main Idea dalam teks multi-paragraf

**Materi 1.1.4: Menentukan Best Title dari Bacaan**
- Perbedaan Title dengan Main Idea: title lebih ringkas, mencakup keseluruhan teks
- Kriteria title yang baik: tidak terlalu umum (too broad) atau terlalu spesifik (too narrow)
- Title harus merepresentasikan ide sentral dari semua paragraf
- Analisis opsi: eliminasi yang terlalu fokus pada satu detail atau terlalu abstrak
- Teknik verifikasi: memastikan title mencakup aspek utama dari setiap bagian teks

**Materi 1.1.5: Main Idea untuk Multi-Paragraph Text**
- Teknik menggabungkan Main Idea dari beberapa paragraf menjadi ide global
- Membedakan Main Idea keseluruhan dengan Main Idea per paragraf
- Mapping struktur: ide utama → ide pendukung → detail spesifik
- Identifikasi pola pengembangan teks (kronologis, cause-effect, problem-solution, dll)
- Analisis jebakan opsi: terlalu spesifik (hanya satu paragraf), menggunakan kata dari teks tapi salah konteks, terlalu umum tidak mencerminkan isi

### Topik 1.2: Purpose

**Materi 1.2.1: Pengenalan Purpose dan Jenisnya** *(Materi Dibuka)*
- Definisi Purpose: tujuan penulis dalam menyampaikan teks/informasi
- Purpose of the whole passage: tujuan keseluruhan teks
- Purpose of a paragraph/sentence: tujuan bagian spesifik dalam teks
- Purpose of mentioning specific information: alasan penyebutan detail tertentu
- Variasi pertanyaan: purpose, objective, intention, aim, author's goal
- Referensi silang: hubungan Purpose dengan Main Idea (Topik 1.1) dan Author's Attitude (Topik 1.5)

**Materi 1.2.2: Analisis Purpose dari Main Idea dan Tone**
- Korelasi Main Idea dengan Purpose: what (main idea) → why (purpose)
- Analisis tone penulis: objektif (inform, explain) vs subjektif (persuade, argue)
- Diksi dan pilihan kata sebagai indikator purpose
- Struktur argumentasi: data/fakta (inform) vs opini/ajakan (persuade)
- Konteks penulisan: genre, audience, situation

**Materi 1.2.3: Purpose dalam Berbagai Genre Teks**
- Teks ekspositori: to inform, to explain, to describe, to clarify
- Teks argumentatif: to persuade, to convince, to argue, to promote
- Teks analitis: to analyze, to compare, to evaluate, to critique
- Teks prosedural: to instruct, to demonstrate, to guide
- Teks naratif: to entertain, to illustrate, to exemplify

**Materi 1.2.4: Analisis Vocabulary Purpose dalam Opsi**
- Kelompok "informative": inform, explain, describe, present, report, clarify, define
- Kelompok "persuasive": persuade, convince, argue, promote, advocate, encourage
- Kelompok "analytical": analyze, compare, contrast, evaluate, examine, distinguish
- Kelompok "critical": criticize, refute, counter-argue, challenge, oppose, deny
- Kelompok "supportive": support, defend, justify, prove, confirm, illustrate

**Materi 1.2.5: Purpose of Mentioning Specific Information**
- Fungsi example: untuk mengilustrasikan konsep abstrak atau memperjelas ide
- Fungsi data/statistik: untuk mendukung argumen dengan bukti konkret
- Fungsi quotation/expert opinion: untuk menambah kredibilitas dan otoritas
- Fungsi anecdote: untuk membuat koneksi emosional atau mempermudah pemahaman
- Analisis pertanyaan "Why does the author mention...": cari fungsi dalam konteks paragraf

### Topik 1.3: Detail Information

**Materi 1.3.1: Pengenalan Detail Information** *(Materi Dibuka)*
- Perbedaan Stated (tersurat, eksplisit) vs Unstated (tersirat, implicit)
- Karakteristik soal: TRUE/FALSE, EXCEPT, NOT mentioned, According to the passage
- Pentingnya keyword identification untuk scanning efektif
- Perbedaan detail information dengan Main Idea: spesifik vs general
- Referensi silang: perbedaan Stated Information dengan Inference (Topik 1.4)

**Materi 1.3.2: Analisis Stated Information dengan Scanning**
- Teknik scanning: mencari keyword dari soal dalam teks dengan cepat
- Membaca konteks sekitar keyword: kalimat sebelum, kalimat mengandung, kalimat sesudah
- Fokus pada subject, verb, object untuk ekstraksi informasi akurat
- Time markers, numbers, proper nouns sebagai anchor points
- Verifikasi: mencocokkan informasi teks dengan opsi jawaban secara literal

**Materi 1.3.3: Analisis Paraphrased Information**
- Parafrase: informasi sama dengan redaksi berbeda (sinonim, struktur kalimat berbeda)
- Jebakan redaksi sama tapi makna berbeda: kata muncul tapi konteks berubah
- Jebakan redaksi berbeda tapi makna sama: sinonim atau active-passive voice
- Identifikasi core meaning: fokus pada subjek dan aksi, bukan kata persis
- Teknik matching: bandingkan esensi informasi, bukan kata per kata

**Materi 1.3.4: Analisis Soal EXCEPT dan NOT TRUE**
- Strategi untuk "All of the following are true EXCEPT": cari yang SALAH/TIDAK DISEBUTKAN
- Teknik eliminasi: check setiap opsi satu per satu dengan teks
- Cross-referencing: tandai lokasi informasi setiap opsi di teks
- Time management: soal EXCEPT biasanya lebih lama, alokasikan waktu lebih
- Verifikasi ganda: pastikan opsi yang dipilih benar-benar tidak ada/salah di teks

**Materi 1.3.5: Detail Information Tersebar Multi-Paragraf**
- Informasi terdistribusi di berbagai paragraf dalam teks panjang
- Teknik noting mental: catat lokasi informasi penting saat membaca
- Menggabungkan detail dari paragraf berbeda untuk menjawab satu soal
- Konsistensi informasi: pastikan tidak ada kontradiksi antar paragraf
- Mapping informasi: hubungkan detail spesifik dengan Main Idea masing-masing paragraf

### Topik 1.4: Inference

**Materi 1.4.1: Pengenalan Inference dan Conclusion** *(Materi Dibuka)*
- Konsep inference: menarik kesimpulan dari informasi yang tidak langsung dinyatakan
- "Reading between the lines": memahami implied meaning
- Perbedaan dengan Stated Information: inference butuh logical reasoning
- Variasi pertanyaan: infer, conclude, imply, suggest, indicate, hypothesize
- Referensi silang: Stated Information (Topik 1.3) sebagai basis untuk inference

**Materi 1.4.2: Analisis Inference dari Main Idea**
- Main Idea sebagai foundation untuk inference global
- Logical extension: apa yang bisa disimpulkan dari ide utama
- Tone dan attitude penulis sebagai clue untuk inference
- Underlying message: pesan tersirat di balik informasi eksplisit
- Scope inference: harus sejalan dengan cakupan teks, tidak over-generalize

**Materi 1.4.3: Analisis Local Inference (Satu Paragraf)**
- Inference dari supporting details dan examples
- Context clues: kalimat sebelum dan sesudah sebagai petunjuk
- Cause-effect relationships yang tersirat
- Comparison dan contrast yang tidak eksplisit dinyatakan
- Implicit assumptions dalam paragraf

**Materi 1.4.4: Analisis Global Inference (Keseluruhan Teks)**
- Menyatukan clues dari seluruh teks untuk kesimpulan menyeluruh
- Inference tentang author's viewpoint: sikap penulis terhadap topik
- Inference tentang intended audience: untuk siapa teks ditulis
- Inference tentang context/situation: kapan, di mana, mengapa teks dibuat
- Broader implications: dampak atau konsekuensi yang bisa disimpulkan

**Materi 1.4.5: Analisis Jebakan dalam Soal Inference**
- Over-inference: kesimpulan terlalu ekstrem, tidak didukung cukup bukti
- Stated information: bukan inference jika sudah eksplisit dinyatakan
- Misuse of text words: menggunakan kata dari teks tapi inference salah
- Out of scope: kesimpulan di luar jangkauan informasi yang diberikan
- Teknik verifikasi: cari bukti tekstual yang mendukung inference

### Topik 1.5: Author's Attitude

**Materi 1.5.1: Pengenalan Author's Attitude** *(Materi Dibuka)*
- Author's Attitude: sikap/perasaan/pendapat penulis terhadap topik
- Perbedaan Opinion (pendapat/pandangan) dan Tone (nada/emosi)
- Subjektif vs Objektif: bias penulis vs netralitas
- Variasi pertanyaan: opinion, attitude, tone, feeling, view
- Referensi silang: hubungan Attitude dengan Purpose (Topik 1.2)

**Materi 1.5.2: Analisis Author's Opinion**
- Karakteristik opini: subjektif, personal belief, tidak dapat diverifikasi objektif
- Frasa penanda opinion: I believe, in my opinion, it seems, arguably, perhaps, may be
- Ekspresi ketidakpastian: might, could, possibly, likely, probably
- Modal verbs untuk spekulasi: should, would, could
- Interpretasi personal vs fakta: penilaian penulis vs data objektif

**Materi 1.5.3: Analisis Fact vs Opinion**
- Fact: dapat diverifikasi, objektif, berdasarkan bukti konkret
- Opinion: penilaian subjektif, berdasarkan belief atau preference
- Mixed statement: kalimat mengandung fakta DAN opini
- Indicators: angka/data (fact) vs evaluative adjectives (opinion)
- Konteks penentuan: kadang perlu cek sumber dan verifiability

**Materi 1.5.4: Analisis Author's Tone**
- Tone: emotional quality atau sikap yang terpancar dari tulisan
- Vocabulary untuk tone positif: optimistic, enthusiastic, supportive, reverent, sincere
- Vocabulary untuk tone negatif: pessimistic, critical, cynical, sarcastic, contemptuous
- Vocabulary untuk tone netral: objective, detached, informative, matter-of-fact
- Word choice dan connotation sebagai indikator tone

**Materi 1.5.5: Analisis Emotional Language dan Bias**
- Loaded words: kata dengan connotation kuat (positif atau negatif)
- Identifying bias: keberpihakan penulis yang tersirat dari pilihan kata
- Emotionally charged language: bahasa yang memicu respons emosional
- Objectivity vs subjectivity: derajat netralitas dalam penyampaian
- Impact pada credibility: bias yang kuat dapat mengurangi kredibilitas

## Section 2: Text Structure

### Topik 2.1: Organization of Ideas

**Materi 2.1.1: Pengenalan Organization of Ideas** *(Materi Dibuka)*
- Organization: bagaimana informasi disusun dan diurutkan dalam teks
- Pentingnya struktur untuk coherence (kepaduan) dan cohesion (keterkaitan)
- Variasi pertanyaan: how is the information organized, how does paragraph relate
- Pattern recognition: mengenali pola pengembangan ide
- Referensi silang: struktur mendukung pemahaman Main Idea (Topik 1.1)

**Materi 2.1.2: Analisis Pola Organisasi Teks**
- Chronological order: urutan waktu (first, then, next, finally)
- Cause and effect: sebab-akibat (because, therefore, as a result, consequently)
- Problem and solution: masalah-solusi (problem, solution, address, solve)
- Compare and contrast: perbandingan (similarly, however, on the other hand, whereas)
- General to specific: umum ke khusus (general statement → examples/details)
- Order of importance: dari penting ke kurang penting atau sebaliknya

**Materi 2.1.3: Analisis Hubungan Antar Paragraf**
- Sequential relationship: paragraf mengikuti urutan logis atau kronologis
- Contrastive relationship: paragraf menyajikan ide yang kontras atau berlawanan
- Elaborative relationship: paragraf mengembangkan atau menjelaskan paragraf sebelumnya
- Exemplification relationship: paragraf memberi contoh dari ide paragraf sebelumnya
- Conclusive relationship: paragraf menyimpulkan atau merangkum paragraf-paragraf sebelumnya

**Materi 2.1.4: Analisis Main Idea Tiap Paragraf untuk Mapping**
- Teknik identifikasi Main Idea per paragraf dengan cepat (fokus kalimat pertama)
- Mapping struktur: visualisasi hubungan ide antar paragraf
- Transition words sebagai penanda hubungan antar paragraf
- Logical progression: bagaimana ide berkembang dari paragraf ke paragraf
- Consistency check: memastikan semua paragraf mendukung thesis/main idea keseluruhan

**Materi 2.1.5: Analisis Kalimat yang Tidak Relevan**
- Irrelevant sentence: kalimat yang tidak mendukung Main Idea paragraf
- Off-topic information: informasi di luar topik yang dibahas
- Disruption dalam logical flow: kalimat yang memutus alur logis
- Kriteria relevansi: kalimat harus directly relate to topic sentence
- Teknik identifikasi: bandingkan setiap kalimat dengan Main Idea paragraf

### Topik 2.2: Transition Questions

**Materi 2.2.1: Pengenalan Preceding dan Following Paragraph** *(Materi Dibuka)*
- Preceding paragraph: paragraf yang kemungkinan ada sebelum paragraf pertama
- Following paragraph: paragraf yang kemungkinan ada setelah paragraf terakhir
- Logical flow: teks harus memiliki introduction dan continuation yang natural
- Variasi pertanyaan: preceding, prior to, previous, following, next paragraph
- Referensi silang: pemahaman Organization (Topik 2.1) untuk prediksi preceding-following

**Materi 2.2.2: Analisis Preceding Paragraph**
- Clue dari kalimat pertama paragraf 1: referensi yang butuh antecedent
- Demonstrative pronouns tanpa antecedent: this, that, these, those, such
- The + noun: definite article mengindikasikan sudah disebutkan sebelumnya
- Topik yang langsung dibahas tanpa introduction: butuh pengenalan di preceding
- Continuation words: also, moreover, furthermore di awal teks

**Materi 2.2.3: Analisis Following Paragraph**
- Clue dari kalimat terakhir paragraf akhir: hints untuk continuation
- Unfinished discussion: topik yang baru disinggung belum dijelaskan detail
- Transitional phrases: looking ahead, in the future, next, subsequently
- Open-ended statement: pernyataan yang mengundang elaborasi lebih lanjut
- Logical next step: apa yang secara logis akan dibahas selanjutnya

**Materi 2.2.4: Analisis Transition Words untuk Preceding-Following**
- Continuation markers: furthermore, moreover, in addition, also, besides
- Contrast markers: however, nevertheless, on the other hand, conversely
- Cause-effect markers: therefore, thus, as a result, consequently, hence
- Summary markers: in conclusion, to sum up, finally, in short
- Time sequence markers: subsequently, afterward, eventually, ultimately

**Materi 2.2.5: Analisis Common Patterns Preceding-Following**
- Pattern: Background/Introduction → Definition/Explanation (preceding → current)
- Pattern: General concept → Specific example/case study (preceding → current)
- Pattern: Problem stated → Detailed explanation of problem (preceding → current)
- Pattern: Discussion/Analysis → Solution/Recommendation (current → following)
- Pattern: Current situation → Future implications/predictions (current → following)

### Topik 2.3: Text Coherence

**Materi 2.3.1: Pengenalan Text Coherence** *(Materi Dibuka)*
- Coherence: kejelasan hubungan antar ide dalam teks
- Unity: semua bagian teks mendukung satu main idea
- Cohesion: keterkaitan antar kalimat melalui cohesive devices
- Perbedaan coherence (logical) vs cohesion (linguistic)
- Referensi silang: coherence mendukung Organization of Ideas (Topik 2.1)

**Materi 2.3.2: Analisis Coherence Devices**
- Pronoun reference: he, she, it, they, this, that merujuk ke noun sebelumnya
- Repeated key terms: pengulangan kata kunci untuk emphasis dan continuity
- Synonyms dan word variations: variasi kata untuk menghindari repetisi
- Parallel structures: struktur gramatikal serupa untuk ide serupa
- Transition words dan phrases: penanda hubungan logis antar ide

**Materi 2.3.3: Analisis Paragraph Unity**
- Topic sentence: satu main idea per paragraf
- Supporting sentences: semua kalimat harus mendukung topic sentence
- No irrelevant information: tidak ada informasi di luar topik
- Consistency dalam focus: tidak berpindah topik di tengah paragraf
- Concluding sentence (optional): reinforces atau summarizes main point

**Materi 2.3.4: Analisis Logical Flow Between Sentences**
- Sentence-to-sentence connection: setiap kalimat terhubung dengan sebelumnya
- Old information → New information pattern: informasi lama di awal, baru di akhir
- Given-new contract: reader expectation tentang information flow
- Cause-effect relationships eksplisit dan implisit antar kalimat
- Time sequence maintenance: konsistensi urutan waktu

**Materi 2.3.5: Analisis Discourse Markers**
- Listing markers: first(ly), second(ly), third(ly), finally, lastly
- Exemplification markers: for example, for instance, such as, like, including
- Emphasis markers: indeed, in fact, actually, especially, particularly
- Concession markers: although, even though, despite, in spite of, while
- Result markers: so, thus, therefore, as a result, consequently

### Topik 2.4: Sentence Function

**Materi 2.4.1: Pengenalan Sentence Function** *(Materi Dibuka)*
- Topic sentence: kalimat yang menyatakan Main Idea paragraf
- Supporting sentences: kalimat yang mengembangkan/mendukung topic sentence
- Concluding sentence: kalimat penutup yang reinforces main point
- Variasi posisi topic sentence: awal, tengah, akhir, atau tersirat
- Referensi silang: sentence function terkait Purpose of a sentence (Topik 1.2)

**Materi 2.4.2: Analisis Topic Sentences**
- Karakteristik topic sentence: general, mencakup ide utama paragraf, complete sentence
- Posisi di awal paragraf (most common): langsung menyatakan main point
- Posisi di tengah/akhir (less common): setelah background atau sebagai kesimpulan
- Implicit topic sentence: main idea tersirat, harus disimpulkan dari kalimat-kalimat
- Scope: topic sentence menentukan cakupan pembahasan paragraf

**Materi 2.4.3: Analisis Supporting Sentences**
- Examples dan illustrations: memberikan contoh konkret dari general statement
- Facts dan statistics: data untuk mendukung klaim
- Expert opinions dan quotations: otoritas untuk strengthen argument
- Descriptions dan details: elaborasi karakteristik atau proses
- Explanations dan reasons: menjelaskan mengapa atau bagaimana

**Materi 2.4.4: Analisis Concluding Sentences**
- Fungsi: restate main idea, summarize key points, atau provide transition
- Restating vs summarizing: mengulang topic sentence vs merangkum semua poin
- Transition ke paragraf berikutnya: menghubungkan dengan topik selanjutnya
- Tidak semua paragraf memiliki concluding sentence eksplisit
- Penanda concluding sentence: in conclusion, thus, therefore, in summary

**Materi 2.4.5: Analisis Paragraph Development Patterns**
- Definition paragraph: mendefinisikan term atau concept
- Classification paragraph: membagi topik ke dalam categories
- Process paragraph: menjelaskan how something works atau how to do something
- Cause-effect paragraph: menjelaskan reasons dan consequences
- Comparison-contrast paragraph: menunjukkan similarities dan differences

## Section 3: Vocabulary 

### Topik 3.1: Synonym

**Materi 3.1.1: Pengenalan Synonym dalam Konteks** *(Materi Dibuka)*
- Synonym: kata dengan makna sama atau mirip
- Pentingnya konteks: arti kata tergantung penggunaan dalam kalimat
- Polysemy: satu kata bisa punya beberapa arti berbeda
- Variasi pertanyaan: closest in meaning, best replaced by, similar meaning
- Referensi silang: synonym penting untuk comprehension dan paraphrase (Topik 3.3)

**Materi 3.1.2: Analisis Synonym dari Context Clues**
- Definition clues: definisi langsung dalam kalimat (is, means, refers to)
- Example clues: contoh yang membantu inference meaning (such as, for example, like)
- Contrast clues: antonim yang membantu deduce meaning (unlike, however, but)
- Restatement clues: kata diulang dengan cara berbeda (in other words, that is)
- Inference from general context: memahami dari keseluruhan situasi/topik

**Materi 3.1.3: Analisis Multiple Meanings**
- Kata dengan beberapa arti: run, set, light, fair, etc.
- Menentukan arti yang tepat sesuai konteks kalimat dan paragraf
- Part of speech consideration: noun vs verb bisa beda arti (book, fly, park)
- Jebakan: arti umum yang familiar tapi salah dalam konteks spesifik
- Collocation: kata yang sering berpasangan mempengaruhi meaning

**Materi 3.1.4: Analisis Synonym untuk Different Word Classes**
- Noun synonyms: person/individual, problem/issue, idea/concept
- Verb synonyms: show/demonstrate, increase/rise, reduce/decrease
- Adjective synonyms: important/significant, difficult/challenging, large/substantial
- Adverb synonyms: quickly/rapidly, very/extremely, often/frequently
- Maintaining word class: synonym harus sama part of speech dengan kata asli

**Materi 3.1.5: Analisis Academic Vocabulary dan Register**
- Academic word list: vocabulary umum dalam teks akademik
- Formal vs informal synonyms: assist vs help, purchase vs buy, commence vs start
- Register consistency: pilih synonym sesuai tingkat formalitas teks
- Denotation vs connotation: makna literal vs konotasi/asosiasi
- Precision: synonym tidak selalu 100% interchangeable, ada nuansa

### Topik 3.2: Reference

**Materi 3.2.1: Pengenalan Reference** *(Materi Dibuka)*
- Reference: kata ganti (pronoun) yang merujuk ke noun (antecedent)
- Jenis pronouns: personal, demonstrative, relative, indefinite
- Antecedent: kata benda yang digantikan oleh pronoun
- Variasi pertanyaan: the word "X" refers to, what does "X" refer to
- Referensi silang: pronoun reference sebagai coherence device (Topik 2.3)

**Materi 3.2.2: Analisis Personal Pronouns Reference**
- Subject pronouns: I, you, he, she, it, we, they
- Object pronouns: me, you, him, her, it, us, them
- Possessive pronouns: my, your, his, her, its, our, their, mine, yours, hers, ours, theirs
- Number agreement: singular pronoun untuk singular noun, plural untuk plural
- Gender consideration (untuk he/she): perhatikan gender antecedent

**Materi 3.2.3: Analisis Demonstrative Pronouns Reference**
- This, that: singular, merujuk noun atau idea
- These, those: plural, merujuk multiple nouns
- Proximity: this/these (dekat), that/those (jauh) secara temporal atau spatial
- Reference ke whole clause atau idea: "this" bisa merujuk seluruh kalimat sebelumnya
- The + noun: the berfungsi seperti demonstrative, merujuk noun yang sudah disebutkan

**Materi 3.2.4: Analisis Relative Pronouns dan Other References**
- Relative pronouns: who (orang-subject), whom (orang-object), which (benda), that (orang/benda), whose (possessive)
- One, ones: menggantikan noun untuk menghindari repetisi
- Some, others, another: indefinite pronouns merujuk subset dari group
- Such: merujuk type atau kind yang disebutkan sebelumnya
- Former, latter: merujuk yang pertama dan yang terakhir dari dua hal

**Materi 3.2.5: Analisis Ambiguous Reference**
- Ambiguity: ketika pronoun bisa merujuk ke lebih dari satu antecedent
- Multiple possible antecedents dalam satu kalimat atau kalimat sebelumnya
- Clarifying dari konteks: logic, subject matter, verb agreement
- Proximity principle: pronoun biasanya merujuk noun terdekat
- Number dan gender clues: untuk narrow down possibilities

### Topik 3.3: Paraphrase

**Materi 3.3.1: Pengenalan Paraphrase dan Restatement** *(Materi Dibuka)*
- Paraphrase: mengungkapkan informasi sama dengan kata/struktur berbeda
- Restatement: menyatakan ulang ide dengan cara berbeda
- Pentingnya dalam soal SNBT: opsi jawaban sering paraphrased
- Variasi pertanyaan: best restates, another way of saying, best summary
- Referensi silang: paraphrase terkait Stated Information (Topik 1.3) dan Synonym (Topik 3.1)

**Materi 3.3.2: Analisis Paraphrase dengan Synonym Substitution**
- Mengganti kata kunci dengan synonym: significant → important, demonstrate → show
- Maintaining meaning: inti informasi harus tetap sama
- Multiple word substitution: mengganti beberapa kata sekaligus
- Connotation awareness: perhatikan nuansa makna synonym
- Function words: artikel, preposisi bisa berubah tapi meaning tetap

**Materi 3.3.3: Analisis Paraphrase dengan Structure Change**
- Active voice → Passive voice: The team won → The game was won by the team
- Positive → Negative: important → not insignificant, remember → not forget
- Clause restructuring: complex sentence → simple sentences atau sebaliknya
- Noun clause → Verb phrase: His success → That he succeeded
- Word class change: differ (verb) → difference (noun), quick (adj) → quickly (adv)

**Materi 3.3.4: Analisis Complex Paraphrase**
- Kombinasi synonym substitution DAN structure change
- Condensing: informasi panjang dijadikan lebih ringkas tanpa kehilangan meaning
- Expanding: informasi ringkas dijelaskan lebih detail
- Maintaining all key information: semua elemen penting harus ada
- Different perspective: mengubah sudut pandang tapi informasi sama

**Materi 3.3.5: Analisis Jebakan dalam Soal Restatement**
- Sama kata tapi beda makna: menggunakan kata dari original tapi konteks berubah
- Beda kata beda makna: terlihat paraphrase tapi informasi actually berbeda
- Partial information: hanya sebagian informasi, tidak lengkap
- Added information: menambahkan info yang tidak ada di original
- Distorted meaning: twist informasi sehingga makna berubah

### Topik 3.4: Affixes

**Materi 3.4.1: Pengenalan Word Formation** *(Materi Dibuka)*
- Word parts: prefix (awalan), root (akar kata), suffix (akhiran)
- Derivation: membentuk kata baru dari base word dengan affix
- Morphological awareness: memahami meaning dari word parts
- Aplikasi: membantu infer meaning kata tidak familiar
- Referensi silang: word formation memperkaya Vocabulary (Topik 3.1)

**Materi 3.4.2: Analisis Common Prefixes**
- Negative prefixes: un- (unhappy), dis- (disagree), in-/im-/il-/ir- (impossible), non- (nonsense)
- Number prefixes: uni- (one), bi- (two), tri- (three), multi- (many), semi- (half)
- Time/position prefixes: pre- (before), post- (after), re- (again), ex- (former), ante- (before)
- Degree prefixes: super- (above), sub- (under), hyper- (excessive), ultra- (beyond)
- Direction prefixes: inter- (between), trans- (across), circum- (around)

**Materi 3.4.3: Analisis Common Suffixes**
- Noun suffixes: -tion/-sion (action), -ment (state), -ness (quality), -ity (state), -er/-or (person)
- Adjective suffixes: -ful (full of), -less (without), -able/-ible (capable), -ive (having quality), -ous/-ious (characterized by)
- Verb suffixes: -ize (make), -ify (make), -en (make), -ate (cause)
- Adverb suffixes: -ly (manner), -ward (direction), -wise (manner)
- Diminutive suffixes: -let (small), -ette (small)

**Materi 3.4.4: Analisis Root Words dan Word Families**
- Common Latin roots: port (carry), dict (say), script (write), spect (see), mit/miss (send)
- Common Greek roots: bio (life), geo (earth), graph (write), phone (sound), psych (mind)
- Building word families: port → portable, transport, import, export, report
- Combining forms: tele- (distant) + phone (sound) = telephone
- Inferring meaning: jika tahu roots, bisa deduce meaning unfamiliar words

**Materi 3.4.5: Aplikasi Word Formation untuk Comprehension**
- Breaking down complex words: un-pre-dict-able → not-before-say-can be
- Recognizing patterns dalam academic vocabulary
- Expanding vocabulary knowledge dari satu root
- Verifikasi contextual: tetap check apakah meaning yang di-infer cocok dengan context
- Technical terms dalam science texts sering menggunakan Latin/Greek roots

### Topik 3.5: Idiom

**Materi 3.5.1: Pengenalan Figurative Language** *(Materi Dibuka)*
- Figurative language: bahasa non-literal, bersifat kiasan
- Types: idioms, metaphors, similes, personification, hyperbole
- Literal meaning vs figurative meaning: surface vs intended meaning
- Cultural considerations: idioms often culture-specific
- Referensi silang: figurative language mempengaruhi Tone (Topik 1.5)

**Materi 3.5.2: Analisis Common Idioms**
- Definition: fixed expressions dengan meaning yang tidak bisa ditebak dari kata-kata individual
- Examples: piece of cake (easy), break the ice (start conversation), hit the books (study)
- Inferring dari context: situasi dan surrounding words sebagai clues
- Formal vs informal: idioms biasanya informal, jarang dalam academic writing
- Recognizing idioms: tidak masuk akal jika diartikan literally

**Materi 3.5.3: Analisis Metaphors dan Similes**
- Metaphor: implicit comparison tanpa "like" atau "as" (Time is money, Life is a journey)
- Simile: explicit comparison dengan "like" atau "as" (brave as a lion, works like a charm)
- Identifying figurative comparisons: cari perbandingan dua hal yang berbeda
- Interpreting implied meanings: apa yang ingin disampaikan melalui comparison
- Effect: membuat abstract concept lebih concrete dan vivid

**Materi 3.5.4: Analisis Connotation vs Denotation**
- Denotation: literal, dictionary meaning of a word
- Connotation: associated meanings, emotional/cultural associations
- Positive connotation: slender (baik) vs skinny (kurang baik) untuk thin
- Negative connotation: cheap (murah tapi murahan) vs inexpensive (murah tapi netral)
- Neutral words: factual tanpa emotional baggage

**Materi 3.5.5: Analisis Other Figurative Devices**
- Personification: memberi sifat manusia ke non-human (The wind whispered)
- Hyperbole: exaggeration untuk emphasis (I'm so hungry I could eat a horse)
- Understatement: deliberately represent something as less than it is
- Allusion: indirect reference to well-known person, event, work
- Irony: saying opposite of what is meant atau situasi yang unexpected

## Section 4: Text Analysis

### Topik 4.1: Two Texts Comparison

**Materi 4.1.1: Pengenalan Two Texts Analysis** *(Materi Dibuka)*
- Karakteristik soal: membandingkan dua teks yang related tapi berbeda
- Types of questions: similarities, differences, relationships, synthesis
- Complexity: butuh pemahaman mendalam kedua teks sekaligus
- Identifying main idea masing-masing teks sebagai langkah awal
- Referensi silang: gunakan skills dari Section 1-3 untuk analyze each text

**Materi 4.1.2: Analisis Tema dan Main Idea Dua Teks**
- Common theme: tema yang sama dibahas kedua teks
- Different focus: aspek berbeda dari tema yang sama
- Overlapping information: informasi yang muncul di both texts
- Unique information: informasi hanya ada di satu teks
- Synthesizing untuk create complete picture

**Materi 4.1.3: Analisis Persamaan Dua Teks**
- Similar factual information: data atau facts yang konsisten
- Shared perspectives: viewpoint atau stance yang sejalan
- Common conclusions: kesimpulan yang sama atau similar
- Parallel structure atau organization patterns
- Agreement on key issues atau main points

**Materi 4.1.4: Analisis Perbedaan Dua Teks**
- Contrasting viewpoints: perspektif yang bertentangan atau different
- Different focus/emphasis: prioritas berbeda dalam pembahasan
- Conflicting information: fakta yang tidak konsisten antar teks
- Tone differences: objektif vs subjektif, formal vs informal
- Different purpose: inform vs persuade, describe vs argue

**Materi 4.1.5: Analisis Relationship antara Dua Teks**
- Complementary: saling melengkapi, provides fuller picture together
- Contradictory: bertentangan, opposing views atau claims
- Elaborative: satu menjelaskan lebih detail dari yang lain
- Sequential: satu melanjutkan topic dari yang lain
- Supporting: satu menyediakan evidence untuk claims di text lainnya

### Topik 4.2: Cloze Test

**Materi 4.2.1: Pengenalan Cloze Test** *(Materi Dibuka)*
- Cloze test: fill in the blank dalam paragraf/teks
- Types of blanks: grammar-based, vocabulary-based, logical connectors
- Contextual understanding: harus pahami keseluruhan untuk fill correctly
- Integration of skills: grammar, vocabulary, dan logic sekaligus
- Referensi silang: Vocabulary (Section 3) dan Coherence (Topik 2.3)

**Materi 4.2.2: Analisis Grammar-Based Blanks**
- Subject-verb agreement: singular subject dengan singular verb
- Tense consistency: maintain tense sepanjang paragraf/teks
- Word class requirements: posisi blank menentukan part of speech
- Articles: a/an (indefinite, first mention), the (definite, second mention)
- Prepositions: in/on/at untuk time dan place, by/with untuk means

**Materi 4.2.3: Analisis Vocabulary-Based Blanks**
- Context clues: surrounding words dan sentences untuk determine meaning
- Collocation: kata-kata yang naturally go together (make a decision, strong coffee)
- Semantic field: pilih kata yang topically related dengan subject matter
- Register matching: formal text butuh formal vocabulary
- Connotation appropriateness: positive, negative, or neutral sesuai context

**Materi 4.2.4: Analisis Logical Connector Blanks**
- Addition connectors: and, moreover, furthermore, in addition, also, besides
- Contrast connectors: but, however, although, nevertheless, yet, whereas
- Cause-effect connectors: because, so, therefore, thus, as a result, consequently
- Time sequence connectors: then, next, after, before, meanwhile, finally
- Clarification connectors: that is, in other words, for example, for instance

**Materi 4.2.5: Analisis Integrated Cloze**
- Multiple blank types dalam satu teks: combination approach
- Overall coherence check: semua blanks create coherent passage
- Cross-checking answers: verify dengan surrounding context
- Paragraph unity: ensure filled words maintain focus dan consistency
- Final verification: baca complete passage untuk ensure naturalness

### Topik 4.3: Infographic

**Materi 4.3.1: Pengenalan Infographic Reading** *(Materi Dibuka)*
- Infographic: visual representation of information atau data

- Components: title, labels, legends, scales, units
- Integration: combine text information dengan visual data
- Referensi silang: inference dan prediction skills (Topik 1.4)

**Materi 4.3.2: Analisis Bar Charts dan Pie Charts**
- Bar charts: comparing quantities across different categories
- Identifying highest, lowest, dan middle values
- Pie charts: showing proportions atau percentages of a whole
- Reading percentages dan comparing segments
- Making comparisons between categories atau time periods

**Materi 4.3.3: Analisis Line Graphs dan Trends**
- Line graphs: showing changes over time atau continuous data
- Identifying trends: upward, downward, stable, fluctuating

- Turning points: peaks (highest), troughs (lowest), plateaus (flat)

**Materi 4.3.4: Analisis Tables dan Statistical Data**
- Table structure: reading rows (horizontal) dan columns (vertical)
- Extracting specific information: locate intersection points
- Making calculations: differences, totals, averages jika needed
- Comparing values: across rows, columns, atau specific cells
- Identifying patterns: consistent increase, random variation, correlations

**Materi 4.3.5: Analisis Predictions dan Inferences dari Data**

- Logical projections: if pattern continues, likely future state
- Comparative inference: what data reveals about relationships
- Limitations awareness: data shows correlation not necessarily causation
- Synthesis: combining visual data dengan text information untuk conclusions

### Topik 4.4: Text Reconstruction

**Materi 4.4.1: Pengenalan Sentence Completion** *(Materi Dibuka)*
- Missing sentences dalam paragraf: completing the gap
- Context analysis: what comes before dan after the gap
- Types: completing first sentence, middle sentence, atau last sentence
- Maintaining coherence: filled sentence must fit logically
- Referensi silang: Coherence (Topik 2.3) dan Organization (Topik 2.1)

**Materi 4.4.2: Analisis Missing First Sentence**
- Functions: introduce topic, provide background, set context
- Topic introduction: general statement about main subject
- Transition dari preceding text: connecting previous information
- Clues dari second sentence: what it refers to atau elaborates
- Tone consistency: match formality dan style of passage

**Materi 4.4.3: Analisis Missing Middle Sentence**
- Bridging function: connecting idea sebelum dengan sesudah
- Logical flow: must follow from previous dan lead to next
- Transition markers: look for continuation atau contrast signals
- Topic continuity: maintaining subject matter consistency
- Supporting role: often provides example, detail, atau elaboration

**Materi 4.4.4: Analisis Missing Last Sentence**
- Functions: conclude paragraph, summarize, atau transition forward
- Concluding statements: restate main idea atau wrap up discussion
- Forward-looking: introduce next topic atau broader implication
- Logical culmination: natural ending dari development sebelumnya
- Closure: sense of completeness untuk paragraph

**Materi 4.4.5: Analisis Jumbled Sentences**
- Ordering scrambled sentences: create logical sequence
- Clues untuk order: time markers, pronouns, logical connectors, topic progression
- Reference words: this, these, such refer to previous content
- Transition words: moreover (addition), however (contrast), therefore (result)
- Topic development: general → specific, problem → solution, cause → effect

### Topik 4.5: Genre-Specific Text Analysis

**Materi 4.5.1: Pengenalan Text Genres dalam SNBT** *(Materi Dibuka)*
- Four main genres: teks umum, teks sastra, teks saintek, teks soshum

- Quick recognition: identify genre dari opening sentences dan vocabulary
- Adapted approach: focus berbeda untuk each genre
- Referensi silang: apply appropriate analysis skills dari Section 1-3

**Materi 4.5.2: Analisis Teks Umum (Inspirational/General Interest)**
- Content characteristics: human interest, relatable experiences, motivational
- Language: accessible, conversational, emotive vocabulary
- Common structures: narrative, anecdotal, personal reflection

**Materi 4.5.3: Analisis Teks Sastra (Literary/Novel Excerpts)**

**Materi 4.5.5: Analisis Teks Sosial Humaniora (Social Sciences/Humanities)**

- Evidence types: case studies, historical examples, sociological data, expert opinions
- Typical questions: author's argument, different perspectives, supporting evidence, implications, critical evaluation

### Topik 4.6: Summary

**Materi 4.6.1: Pengenalan Summary Questions** *(Materi Dibuka)*
- Summary: condensed version yang captures essential points
- Difference dari paraphrase: summary shorter, covers main ideas only
- Types: summarizing whole passage, paragraph, atau section
- Effective summary: includes all key points, omits minor details
- Referensi silang: Main Idea (Topik 1.1) sebagai foundation untuk summary

**Materi 4.6.2: Analisis Summary untuk Single Paragraph**
- Identify topic sentence: usually main point of paragraph
- Key supporting points: major details yang develop topic
- Omit minor details: examples, statistics dapat dihilangkan jika not crucial
- Maintain accuracy: summary must accurately reflect original meaning
- Conciseness: express main idea dan key supports briefly

**Materi 4.6.3: Analisis Summary untuk Multi-Paragraph Text**
- Main idea dari each paragraph: identify key point per section
- Synthesize: combine main ideas into coherent overall summary
- Hierarchical structure: overall main idea → major supporting ideas
- Proportional representation: important points get more emphasis dalam summary
- Eliminate redundancy: avoid repeating similar points

**Materi 4.6.4: Analisis Summary Options**
- Too specific: mencakup only details dari one paragraph
- Too general: too broad, could apply to many different texts
- Partial coverage: misses important points dari some sections
- Distorted meaning: technically uses text words tapi changes intended meaning
- Balanced summary: covers all main points proportionally dan accurately

**Materi 4.6.5: Distinguishing Main Points dari Supporting Details**
- Main points: essential ideas that carry primary message
- Supporting details: examples, illustrations, elaborations, minor facts
- Testing importance: would removing this change fundamental understanding?
- Hierarchy recognition: main idea > major support > minor details
- Summary inclusion: main ideas always included, major supports sometimes, minor details rarely
