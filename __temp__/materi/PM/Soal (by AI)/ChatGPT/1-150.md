
# **Bacaan 1**

Di sebuah perusahaan manufaktur furnitur di Jakarta, manajer produksi menganalisis pola peningkatan produksi kursi kayu selama beberapa bulan terakhir. Pada bulan pertama, perusahaan memproduksi **150 kursi**, dan setiap bulan berikutnya produksi meningkat secara tetap sebanyak **40 kursi per bulan** karena penambahan tenaga kerja dan optimalisasi mesin.

Setiap kursi membutuhkan biaya bahan baku sebesar **Rp200.000**, sedangkan biaya operasional tetap pabrik adalah **Rp5.000.000 per bulan**. Kursi dijual dengan harga **Rp300.000 per unit**. Manajemen menargetkan produksi tahunan minimal **2.500 kursi** dan menetapkan bahwa strategi produksi hanya layak dilanjutkan jika **margin keuntungan minimal 20% dari total pendapatan** tetap terjaga.

---

**Topic 1.1: Pola Bilangan**
**Materi 1.1.2: Pola Bilangan Aritmatika**

## **Pembahasan 1**

Diketahui:

* Produksi bulan pertama = ( a )
* Kenaikan produksi per bulan = ( b )
* Bulan ke-( n )
* Produksi bulan ke-( n ) = ( U_n )

Model:
[
U_n = a + (n-1)b
]

Substitusi:

* ( a = 150 )
* ( b = 40 )
* ( n = 6 )

Perhitungan:
[
U_6 = 150 + 5(40) = 350
]

Hasil akhir:
Produksi pada bulan ke-6 adalah **350 kursi**.

**Soal 1:**

**Pilihan 1:**

**Topic 4.1: Aritmatika Sosial dan Aplikasi**
**Materi 4.1.5: Penalaran Keuntungan dan Rugi**

## **Pembahasan 3**

* Harga jual per kursi = ( H )
* Biaya variabel per kursi = ( C_v )
* Biaya tetap bulanan = ( C_f )
* Jumlah produksi = ( Q )

Model pendapatan:
[
R = H \times Q
]

Model biaya:
[
C = C_f + C_v \times Q
]

Model keuntungan:
[
L = R - C
]

Margin keuntungan:
[

]

* ( Q = 350 )

Perhitungan:
[

]
[
C = 5.000.000 + 200.000 \times 350 = 75.000.000
]
[
L = 30.000.000
]
[
\text{Margin} = \frac{30.000.000}{105.000.000} \approx 28{,}6%
]

Hasil akhir:
Margin keuntungan **melebihi 20%**, sehingga strategi **layak dilanjutkan**.
