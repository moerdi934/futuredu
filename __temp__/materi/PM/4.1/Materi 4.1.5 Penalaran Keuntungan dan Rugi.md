## **Materi 4.1.5: Penalaran Keuntungan dan Rugi**

### **📊 Anatomi Keuntungan dan Kerugian**

Di bisnis, ada satu pertanyaan fundamental: **"Gue untung atau rugi?"**

Sounds simple, tapi di SNBT (dan real life), perhitungannya bisa kompleks banget!

### **💰 Definisi dan Konsep Dasar**

**Keuntungan (Profit/Laba):**
```
Keuntungan = Harga Jual - Harga Beli
atau
Keuntungan = Pendapatan - Total Biaya
```

**Kerugian (Loss):**
```
Kerugian = Harga Beli - Harga Jual
atau
Kerugian = Total Biaya - Pendapatan
```

**Impas (Break Even):**
```
Harga Jual = Harga Beli
atau
Pendapatan = Total Biaya
```

### **📈 Persentase Untung dan Rugi**

**Formula Persentase Keuntungan:**
```
% Untung = (Keuntungan/Harga Beli) × 100%
% Untung = ((Harga Jual - Harga Beli)/Harga Beli) × 100%
```

**Formula Persentase Kerugian:**
```
% Rugi = (Kerugian/Harga Beli) × 100%
% Rugi = ((Harga Beli - Harga Jual)/Harga Beli) × 100%
```

**⚠️ PERHATIAN:** Basis perhitungan SELALU dari **Harga Beli** (modal), bukan harga jual!

### **🎯 Menghitung Harga Jual dari Target Keuntungan**

**Scenario:** Lo mau untung 25% dari barang yang dibeli Rp400.000

**Cara 1: Step by step**
```
Keuntungan = 25% × Rp400.000 = Rp100.000
Harga Jual = Rp400.000 + Rp100.000 = Rp500.000
```

**Cara 2: Langsung**
```
Harga Jual = Harga Beli × (1 + % Untung)
Harga Jual = Rp400.000 × 1,25 = Rp500.000
```

**Untuk Kerugian:**
```
Harga Jual = Harga Beli × (1 - % Rugi)
```

### **🔄 Reverse Engineering: Mencari Harga Beli**

**Scenario:** Jual barang Rp600.000 dengan untung 20%. Berapa harga belinya?

**Penalaran:**
```
Harga Jual = Harga Beli × 1,2
Rp600.000 = Harga Beli × 1,2
Harga Beli = Rp600.000 ÷ 1,2
Harga Beli = Rp500.000
```

**Verifikasi:**
```
Untung = Rp600.000 - Rp500.000 = Rp100.000
% = Rp100.000/Rp500.000 = 20% ✓
```

### **💸 Multi-Item Profit Calculation**

**Scenario Real:**
Beli 100 buah barang @Rp50.000
- 70 buah terjual @Rp70.000
- 20 buah terjual @Rp60.000
- 10 buah rusak (tidak terjual)

Berapa total untung/rugi?

**Perhitungan:**
```
Total Modal = 100 × Rp50.000 = Rp5.000.000

Pendapatan:
- 70 × Rp70.000 = Rp4.900.000
- 20 × Rp60.000 = Rp1.200.000
Total Pendapatan = Rp6.100.000

Untung = Rp6.100.000 - Rp5.000.000 = Rp1.100.000
% Untung = (Rp1.100.000/Rp5.000.000) × 100% = 22%
```

**Insight:** Meskipun ada barang rusak, masih bisa untung kalau harga jualnya cukup tinggi!

### **🎯 Break Even Point (BEP)**

BEP itu titik di mana **total pendapatan = total biaya**. Gak untung, gak rugi.

**Komponen Biaya:**
1. **Fixed Cost (Biaya Tetap):** Sewa, gaji, dll
2. **Variable Cost (Biaya Variabel):** Bahan baku, kemasan, dll

**Formula BEP (dalam unit):**
```
BEP = Fixed Cost / (Harga Jual per unit - Variable Cost per unit)
BEP = Fixed Cost / Margin per unit
```

**Contoh:**
- Fixed Cost: Rp10.000.000/bulan
- Variable Cost: Rp30.000/unit
- Harga Jual: Rp50.000/unit

```
Margin per unit = Rp50.000 - Rp30.000 = Rp20.000
BEP = Rp10.000.000 / Rp20.000 = 500 unit
```

Artinya: Harus jual minimal **500 unit** per bulan biar impas!

**Formula BEP (dalam rupiah):**
```
BEP (Rp) = BEP (unit) × Harga Jual per unit
BEP (Rp) = 500 × Rp50.000 = Rp25.000.000
```

### **📊 Analisis Contribution Margin**

**Contribution Margin** = Harga Jual - Variable Cost

Ini menunjukkan berapa banyak setiap penjualan "berkontribusi" untuk cover fixed cost.

**Contoh:**
- Harga Jual: Rp100.000
- Variable Cost: Rp60.000
- Contribution Margin: Rp40.000

Artinya: Setiap jual 1 unit, dapat Rp40.000 untuk bayar fixed cost dan profit.

**Contribution Margin Ratio:**
```
CM Ratio = Contribution Margin / Harga Jual
CM Ratio = Rp40.000 / Rp100.000 = 40%
```

### **💡 Optimasi Keuntungan**

**Scenario:** Lo punya modal Rp10 juta, ada 2 pilihan:

**Opsi A:**
- Beli 100 unit @Rp100.000
- Jual @Rp130.000
- Margin: 30%

**Opsi B:**
- Beli 200 unit @Rp50.000
- Jual @Rp65.000
- Margin: 30%

Mana yang lebih untung?

**Opsi A:**
```
Keuntungan = 100 × (Rp130.000 - Rp100.000)
Keuntungan = 100 × Rp30.000 = Rp3.000.000
```

**Opsi B:**
```
Keuntungan = 200 × (Rp65.000 - Rp50.000)
Keuntungan = 200 × Rp15.000 = Rp3.000.000
```

**Sama!** Persentase margin sama, total keuntungan juga sama.

**But...** faktor lain yang perlu dipertimbangkan:
- Mana yang lebih cepat laku?
- Mana yang lebih mudah disimpan?
- Mana yang risikonya lebih rendah?

### **🎲 Risk vs Return**

Dalam bisnis, umumnya:
**High Risk = Potential High Return**
**Low Risk = Potential Low Return**

**Contoh:**

**Bisnis A (Low Risk):**
- Success rate: 90%
- Keuntungan kalau sukses: 20%
- Expected return: 90% × 20% = 18%

**Bisnis B (High Risk):**
- Success rate: 40%
- Keuntungan kalau sukses: 50%
- Expected return: 40% × 50% = 20%

Bisnis B punya expected return lebih tinggi, tapi risikonya juga lebih besar!

### **📉 Dealing with Losses**

**Strategi Minimize Loss:**

**1. Cut Loss Strategy**
Jual dengan rugi kecil sebelum rugi makin besar.

**2. Hold Strategy**
Tunggu sampai harga pulih (kalau yakin akan naik).

**3. Average Down**
Beli lagi dengan harga lebih murah untuk turunkan harga rata-rata.

**Contoh Average Down:**
```
Pembelian 1: 100 unit @Rp1.000 = Rp100.000
Harga turun!
Pembelian 2: 100 unit @Rp800 = Rp80.000

Harga rata-rata = (Rp100.000 + Rp80.000) / 200 = Rp900/unit
```

Sekarang BEP di Rp900, bukan Rp1.000!

### **💰 Gross Profit vs Net Profit**

**Gross Profit (Laba Kotor):**
```
Gross Profit = Pendapatan - HPP (Harga Pokok Penjualan)
```

**Net Profit (Laba Bersih):**
```
Net Profit = Gross Profit - Biaya Operasional - Pajak
```

**Contoh:**
```
Pendapatan: Rp100.000.000
HPP: Rp60.000.000
Gross Profit: Rp40.000.000 (margin 40%)

Biaya Operasional:
- Gaji: Rp15.000.000
- Sewa: Rp5.000.000
- Utilitas: Rp2.000.000
- Lain-lain: Rp3.000.000
Total: Rp25.000.000

EBIT: Rp15.000.000
Pajak (20%): Rp3.000.000
Net Profit: Rp12.000.000 (margin 12%)
```

**Insight:** Gross margin 40% tapi net margin cuma 12%! Ini realita bisnis - banyak biaya "tersembunyi".

### **📊 Profit Margin Ratio**

**Gross Profit Margin:**
```
GPM = (Gross Profit / Revenue) × 100%
```

**Net Profit Margin:**
```
NPM = (Net Profit / Revenue) × 100%
```

**Operating Profit Margin:**
```
OPM = (Operating Profit / Revenue) × 100%
```

**Benchmark (beda per industri):**
- Retail: GPM 20-40%, NPM 2-6%
- Software: GPM 70-90%, NPM 15-30%
- Restaurant: GPM 60-70%, NPM 3-9%

### **🎯 Penalaran untuk SNBT**

**Pattern #1: Multiple Transactions**
"Beli X dengan harga A, jual Y dengan harga B, sisanya rusak..."
→ Hitung total cost vs total revenue

**Pattern #2: Percentage-based**
"Untung X% dari produk A, rugi Y% dari produk B..."
→ Convert to actual numbers, then calculate net

**Pattern #3: Break Even**
"Berapa unit harus dijual untuk BEP?"
→ Fixed Cost / Margin per unit

**Pattern #4: Optimization**
"Mana strategi yang paling menguntungkan?"
→ Calculate each, compare net profit

### **⚠️ Jebakan Umum**

**Jebakan #1: Basis Persentase**
"Untung 30% lalu rugi 20%" ≠ Net untung 10%!
```
Awal: 100
Untung 30%: 130
Rugi 20%: 130 × 0,8 = 104
Net: +4%
```

**Jebakan #2: Mengabaikan Biaya Operasional**
Gross profit tinggi ≠ net profit tinggi

**Jebakan #3: Volume vs Margin**
High volume low margin vs low volume high margin
→ Yang penting total profit!

**Jebakan #4: Sunk Cost Fallacy**
"Udah rugi banyak, jangan dijual dulu"
→ Past cost irrelevant untuk keputusan future!

### **💡 Tips Cepat**

**Quick Check Profitability:**
```
ROI = (Profit / Investment) × 100%
```

**Quick Calculate Selling Price:**
```
Selling Price = Cost × (1 + Desired Margin%)
```

**Quick Find Break Even:**
```
BEP = Fixed Cost / Contribution Margin
```

### **🎓 Kesimpulan: Keuntungan dan Rugi**

**Key Formulas:**
```
Profit = Revenue - Cost
Profit % = (Profit / Cost) × 100%
Selling Price = Cost × (1 + Profit%)
BEP = Fixed Cost / (Price - Variable Cost)
```

**Key Concepts:**
- Profit % always based on **cost**, not selling price
- Gross profit ≠ Net profit
- BEP is crucial for business viability
- Risk and return go hand in hand

**SNBT Tips:**
- Always check what's the base of percentage
- Don't forget operational costs
- For multiple items, calculate total
- BEP questions → focus on contribution margin
