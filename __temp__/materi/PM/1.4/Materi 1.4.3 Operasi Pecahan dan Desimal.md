## **Materi 1.4.3: Operasi Pecahan dan Desimal**

### Pecahan: Love It or Hate It, You Need It!

Pecahan itu ibarat bumbu masakan—kadang bikin hidup lebih enak, kadang bikin ribet. Tapi tanpa pecahan, banyak hal di dunia real yang nggak bisa kita hitung! Di SNBT, pecahan dan desimal adalah "langganan tetap" yang nggak pernah absen.

### Membandingkan dan Mengurutkan Pecahan (Lagi, Tapi Lebih Dalam!)

Kita udah bahas dikit di materi sebelumnya. Sekarang kita going deeper!

**Metode 1: Penyebut Sama (KPK)**

Misal, bandingkan: 2/3, 3/4, dan 5/6

Cari KPK dari 3, 4, dan 6:
- Kelipatan 3: 3, 6, 9, 12, ...
- Kelipatan 4: 4, 8, 12, ...
- Kelipatan 6: 6, 12, ...
- **KPK = 12**

Ubah semua:
- 2/3 = 8/12
- 3/4 = 9/12
- 5/6 = 10/12

Urutan: 2/3 < 3/4 < 5/6

**Metode 2: Desimal (Paling Praktis Kalau Boleh Kalkulator)**

- 2/3 = 0,666...
- 3/4 = 0,75
- 5/6 = 0,833...

Urutan: 2/3 < 3/4 < 5/6

**Metode 3: Benchmark Fraction (Pakai Patokan)**

Kadang nggak perlu hitung detail. Pakai 1/2 sebagai patokan:
- 2/3 > 1/2 (karena 2/3 = 4/6, sedangkan 1/2 = 3/6)
- 3/4 > 1/2 (karena 3/4 = 6/8, sedangkan 1/2 = 4/8)
- 5/6 > 1/2 (karena 5/6 = 10/12, sedangkan 1/2 = 6/12)

Tapi kalau semuanya > 1/2, ya perlu metode lain untuk detail ranking.

**Trik untuk Pecahan "Hampir 1"**

Kalau ada pecahan yang pembilangnya cuma beda sedikit dari penyebut:
- 7/8, 9/10, 15/16

Liat selisihnya dari 1:
- 7/8 kurang 1/8
- 9/10 kurang 1/10
- 15/16 kurang 1/16

Yang selisihnya paling kecil (1/16) berarti paling mendekati 1!
Urutan: 15/16 > 9/10 > 7/8

### Operasi Penjumlahan dan Pengurangan Pecahan

**Aturan Emas**: Penyebut harus SAMA!

**Langkah-langkah:**
1. Samakan penyebut (cari KPK)
2. Sesuaikan pembilang
3. Jumlahkan/kurangkan pembilang
4. Penyebut tetap!
5. Sederhanakan kalau bisa

**Contoh:**
```
1/4 + 2/3 = ?
```

KPK dari 4 dan 3 = 12
```
= 3/12 + 8/12
= 11/12
```

**Contoh campuran:**
```
2 1/3 + 1 3/4 = ?
```

Cara 1 (ubah ke pecahan biasa):
```
= 7/3 + 7/4
= 28/12 + 21/12
= 49/12
= 4 1/12
```

Cara 2 (pisahkan bilangan bulat dan pecahan):
```
= (2 + 1) + (1/3 + 3/4)
= 3 + (4/12 + 9/12)
= 3 + 13/12
= 3 + 1 1/12
= 4 1/12
```

**Pengurangan dengan "pinjam":**
```
3 1/4 - 1 3/4 = ?
```

Karena 1/4 < 3/4, kita "pinjam" 1 dari 3:
```
= 2 5/4 - 1 3/4
= (2 - 1) + (5/4 - 3/4)
= 1 + 2/4
= 1 1/2
```

### Perkalian Pecahan: Surprisingly Simple!

Beda sama tambah-kurang, perkalian pecahan justru lebih gampang!

**Rumus**: (a/b) × (c/d) = (a×c)/(b×d)

**Langsung aja kali pembilang dengan pembilang, penyebut dengan penyebut!**

```
2/3 × 3/5 = ?
= (2×3)/(3×5)
= 6/15
= 2/5 (disederhanakan)
```

**Pro tip**: Sederhanakan SEBELUM mengalikan (biar angkanya nggak gede-gede banget)

```
4/9 × 3/8 = ?
```

Lihat: 4 dan 8 bisa disederhanakan (bagi 4)
Juga: 3 dan 9 bisa disederhanakan (bagi 3)

```
= (4÷4)/(9÷3) × (3÷3)/(8÷4)
= 1/3 × 1/2
= 1/6
```

Lebih cepat dan rapi kan?

**Perkalian dengan bilangan bulat:**
```
5 × 2/3 = ?
= (5×2)/3
= 10/3
= 3 1/3
```

**Perkalian bilangan campuran:**
Ubah dulu ke pecahan biasa!
```
2 1/2 × 1 1/3 = ?
= 5/2 × 4/3
= 20/6
= 10/3
= 3 1/3
```

### Pembagian Pecahan: Flip and Multiply!

Ini dia yang terkenal: **"Keep, Change, Flip"** atau **KCF**!

**Rumus**: (a/b) ÷ (c/d) = (a/b) × (d/c)

**Keep** - Pecahan pertama tetap
**Change** - Bagi jadi kali
**Flip** - Balik pecahan kedua

```
2/3 ÷ 4/5 = ?
= 2/3 × 5/4
= 10/12
= 5/6
```

**Kenapa dibalik?** 
Karena membagi dengan suatu bilangan = mengalikan dengan kebalikannya!
- Bagi 2 = kali 1/2
- Bagi 1/2 = kali 2
- Bagi 4/5 = kali 5/4

**Contoh real-life:**
> Kamu punya 3/4 liter susu. Mau dituang ke gelas yang isinya 1/8 liter. Berapa gelas yang bisa diisi?

```
3/4 ÷ 1/8 = ?
= 3/4 × 8/1
= 24/4
= 6 gelas
```

Masuk akal! 1/8 liter itu kan kecil, jadi dari 3/4 liter bisa banyak gelasnya.

### Operasi Pecahan dan Desimal Campur

Di SNBT, sering banget ada soal yang **ngaduk pecahan dan desimal** jadi satu. Strategi: ubah ke bentuk yang sama!

**Contoh:**
```
0,5 + 1/4 + 0,75 = ?
```

**Cara 1: Ubah semua ke desimal**
```
= 0,5 + 0,25 + 0,75
= 1,5
```

**Cara 2: Ubah semua ke pecahan**
```
= 1/2 + 1/4 + 3/4
= 2/4 + 1/4 + 3/4
= 6/4
= 3/2
= 1 1/2
```

Hasil sama kan? Pilih yang paling nyaman buatmu!

**Jebakan klasik:**
```
1,2 × 2/3 = ?
```

Banyak yang langsung: "wah, desimal kali pecahan, gimana nih?"

Tenang! Ubah salah satunya:
```
= 12/10 × 2/3
= 24/30
= 4/5
= 0,8
```

Atau:
```
= 1,2 × 0,666...
≈ 0,8
```

### Pecahan Senilai dan Penyederhanaan

**Pecahan senilai** = pecahan yang nilainya sama meskipun beda bentuk

```
1/2 = 2/4 = 3/6 = 4/8 = ... (semua senilai!)
```

**Cara dapat pecahan senilai**: Kali atau bagi pembilang DAN penyebut dengan bilangan yang sama

**Penyederhanaan** = bikin pecahan ke bentuk paling sederhana dengan FPB

```
24/36 = ?
```

FPB dari 24 dan 36 = 12
```
= (24÷12)/(36÷12)
= 2/3
```

**Cara cepat**: Bagi terus sama angka yang sama sampai nggak bisa lagi
```
24/36
= 12/18 (bagi 2)
= 6/9 (bagi 2)
= 2/3 (bagi 3)
```

**Kapan pecahan udah paling sederhana?**
Kalau pembilang dan penyebut nggak punya faktor persekutuan selain 1 (FPB = 1)

### Konversi: Pecahan ↔ Desimal ↔ Persen

Ini trio yang wajib kamu kuasai untuk SNBT!

**Pecahan → Desimal**
Bagi pembilang dengan penyebut
```
3/4 = 3 ÷ 4 = 0,75
```

**Desimal → Pecahan**
1. Hitung ada berapa angka di belakang koma
2. Pembilang = angka tanpa koma
3. Penyebut = 10, 100, 1000, ... (tergantung jumlah desimal)
4. Sederhanakan

```
0,75 = 75/100 = 3/4
0,125 = 125/1000 = 1/8
```

**Pecahan/Desimal → Persen**
Kali 100, kasih tanda %
```
3/4 = 0,75 = 75%
1/8 = 0,125 = 12,5%
```

**Persen → Pecahan/Desimal**
Bagi 100
```
25% = 25/100 = 1/4 = 0,25
12,5% = 12,5/100 = 1/8 = 0,125
```

**Nilai-nilai yang WAJIB dihapal:**

|---------|---------|--------|
| 1/2 | 0,5 | 50% |
| 1/3 | 0,333... | 33,33...% |

**Kenapa harus hapal?** Biar ngerjain soal SNBT cepet! Nggak perlu buang waktu bagi-bagian di tengah ujian.

### Desimal Berulang

Kadang hasil bagi nggak berhenti, tapi berulang terus:
```
1/3 = 0,333333... (3 berulang)
1/6 = 0,166666... (6 berulang)
1/7 = 0,142857142857... (142857 berulang)
```

**Notasi:** Angka yang berulang dikasih garis di atas
- 0,333... = 0,3̅
- 0,142857142857... = 0,1̅4̅2̅8̅5̅7̅

**Fun fact:** Setiap pecahan bisa jadi desimal, tapi nggak semua desimal bisa jadi pecahan sederhana. Desimal yang berulang PASTI bisa jadi pecahan. Desimal yang nggak berulang dan nggak berhenti (kayak π) itu bilangan irasional!

### Operasi dengan Penyebut Berbeda: The Real Challenge

```
2/3 + 3/4 - 5/6 = ?
```

Ini tipe soal yang sering bikin panik. Tenang, ikuti langkah:

1. **Cari KPK semua penyebut** (3, 4, 6)
   - KPK(3,4,6) = 12

2. **Ubah semua pecahan**
   - 2/3 = 8/12
   - 3/4 = 9/12
   - 5/6 = 10/12

3. **Operasikan**
   ```
   = 8/12 + 9/12 - 10/12
   = (8 + 9 - 10)/12
   = 7/12
   ```

**Trik pengecekan cepat:** Kalau hasilnya aneh atau terlalu gede/kecil, mungkin ada yang salah!

### Jebakan-Jebakan di Operasi Pecahan (SNBT Edition)

**Jebakan #1: Lupa Samakan Penyebut Saat Tambah/Kurang**
```
SALAH: 1/2 + 1/3 = 2/5 ❌ (jangan langsung jumlahin!)
BENAR: 1/2 + 1/3 = 3/6 + 2/6 = 5/6 ✓
```

**Jebakan #2: Samakan Penyebut Saat Kali (Nggak Perlu!)**
```
TIDAK EFISIEN: 1/2 × 1/3 = 3/6 × 2/6 = 6/36 = 1/6
LEBIH CEPAT: 1/2 × 1/3 = 1/6 ✓
```

**Jebakan #3: Bagi Langsung Tanpa Flip**
```
SALAH: 2/3 ÷ 1/2 = 2/6 = 1/3 ❌
BENAR: 2/3 ÷ 1/2 = 2/3 × 2/1 = 4/3 ✓
```

**Jebakan #4: Lupa Sederhanakan Jawaban Akhir**
