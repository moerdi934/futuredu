# Topik 1.2: Perubahan Makna Kata


## Materi 1.2.7: Sinestesia

### Apa Itu Sinestesia?

**Sinestesia** adalah perubahan makna yang terjadi karena **pertukaran atau pencampuran dua indra** (penglihatan, pendengaran, pengecapan, penciuman, perabaan).

Gampangnya: kata yang biasanya untuk indra A, tiba-tiba dipakai untuk indra B!

Contoh paling gampang: "Suaranya manis" → "suara" = indra pendengaran, "manis" = indra pengecapan. Harusnya nggak nyambung kan? Tapi karena sinestesia, jadi nyambung!

### Ciri-Ciri Sinestesia

1. **Melibatkan minimal dua indra berbeda**
2. **Makna kata dari satu indra digunakan untuk indra lain**
3. **Sering digunakan untuk deskripsi yang lebih kaya/puitis**

### Jenis-Jenis Sinestesia Berdasarkan Indra

#### 1. **Pengecapan → Pendengaran**
Kata untuk rasa (pengecapan) dipakai untuk suara (pendengaran)

**Contoh:**
- "Suaranya manis" → manis = rasa, tapi dipakai untuk suara
- "Kata-katanya pahit" → pahit = rasa, tapi untuk kata-kata (suara)
- "Ucapannya asam" → asam = rasa, untuk ucapan

#### 2. **Perabaan → Pendengaran**
Kata untuk tekstur/suhu (perabaan) dipakai untuk suara (pendengaran)

**Contoh:**
- "Suaranya lembut" → lembut = tekstur, tapi untuk suara
- "Nada yang dingin" → dingin = suhu, tapi untuk nada
- "Suaranya keras" → keras = tekstur, untuk suara

#### 3. **Penglihatan → Pendengaran**
Kata untuk visual (penglihatan) dipakai untuk suara (pendengaran)

**Contoh:**
- "Suaranya cerah" → cerah = penglihatan, untuk suara
- "Warna suara yang gelap" → gelap = penglihatan, untuk suara
- "Nada yang tajam" → tajam = visual, untuk nada

#### 4. **Penciuman → Pendengaran**
Kata untuk aroma (penciuman) dipakai untuk suara (pendengaran)

**Contoh:**
- "Kata-kata yang harum" → harum = aroma, untuk kata
- "Suaranya busuk" → busuk = aroma, untuk suara

#### 5. **Pengecapan → Penglihatan**
Kata untuk rasa (pengecapan) dipakai untuk visual (penglihatan)

**Contoh:**
- "Warna yang manis" → manis = rasa, untuk warna
- "Pemandangan yang segar" → segar = rasa (minuman), untuk pemandangan

#### 6. **Perabaan → Penglihatan**
Kata untuk tekstur (perabaan) dipakai untuk visual (penglihatan)

**Contoh:**
- "Wajahnya lembut" → lembut = tekstur, untuk wajah (visual)
- "Pandangan yang tajam" → tajam = tekstur, untuk pandangan

### Contoh Detail dalam Kalimat

1. **"Perkataannya manis sekali."**
   - **Perkataan** = indra **pendengaran** (kita dengar orang bicara)
   - **Manis** = indra **pengecapan** (kita rasakan dengan lidah)
   - **Sinestesia:** Pengecapan → Pendengaran

2. **"Suaranya lembut seperti kapas."**
   - **Suara** = indra **pendengaran**
   - **Lembut** = indra **perabaan** (kita sentuh)
   - **Sinestesia:** Perabaan → Pendengaran

3. **"Pandangannya tajam menusuk."**
   - **Pandangan** = indra **penglihatan**
   - **Tajam, menusuk** = indra **perabaan**
   - **Sinestesia:** Perabaan → Penglihatan

4. **"Warna yang hangat membuat ruangan terasa nyaman."**
   - **Warna** = indra **penglihatan**
   - **Hangat** = indra **perabaan** (suhu)
   - **Sinestesia:** Perabaan → Penglihatan

5. **"Kata-katanya pahit di telinga."**
   - **Kata-kata, telinga** = indra **pendengaran**
   - **Pahit** = indra **pengecapan**
   - **Sinestesia:** Pengecapan → Pendengaran

### Sinestesia vs Metafora

Sinestesia adalah **jenis khusus dari metafora** yang melibatkan indra:

- **Metafora umum:** "Dia adalah matahari hidupku" (benda → orang)
- **Sinestesia:** "Suaranya manis" (indra pengecapan → indra pendengaran)

Jadi semua sinestesia adalah metafora, tapi tidak semua metafora adalah sinestesia!

### Kenapa Sinestesia Sering Dipakai?

1. **Lebih ekspresif** – Deskripsi jadi lebih kaya dan hidup
2. **Lebih puitis** – Cocok untuk karya sastra
3. **Lebih mudah dipahami** – Orang jadi bisa "merasakan" deskripsi dengan lebih baik

### Jebakan di Soal SNBT

**Jebakan #1: Dikira cuma metafora biasa**
❌ Sinestesia adalah metafora **khusus yang melibatkan indra**!

**Jebakan #2: Semua deskripsi = sinestesia?**
❌ Sinestesia harus ada **pertukaran indra**. Kalau "suara keras" itu bukan sinestesia karena "keras" memang bisa untuk suara (volume).

**Jebakan #3: Bingung indra mana yang bertukar**
✅ Selalu identifikasi: kata asli untuk indra apa → dipakai untuk indra apa?

**Contoh soal:**
> "Pemandangan di puncak gunung itu sangat segar, membuat pikiran jernih."

Pertanyaan mungkin: "Kata 'segar' dalam kalimat tersebut menggunakan..."
- ✅ Pertukaran indra (pengecapan → penglihatan)
- ❌ Makna leksikal (salah, ini makna kiasan)
- ❌ Makna konotatif biasa (terlalu umum, lebih spesifik: sinestesia)

### Tips Mengenali Sinestesia

1. **Identifikasi kata yang "aneh"** – Apakah ada kata yang seharusnya untuk indra lain?
2. **Cek indra yang terlibat** – Indra apa yang bertukar?
3. **Perhatikan deskripsi** – Apakah deskripsi jadi lebih hidup/puitis?
