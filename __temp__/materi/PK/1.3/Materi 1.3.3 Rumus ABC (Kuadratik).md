## **Materi 1.3.3: Rumus ABC (Kuadratik)**

### **The Ultimate Weapon: Rumus ABC!**

Oke gengs, sekarang kita masuk ke senjata PAMUNGKAS dalam menyelesaikan persamaan kuadrat: **RUMUS ABC** atau sering disebut **Rumus Kuadratik**! 

Ini adalah rumus legendaris yang bisa menyelesaikan SEMUA persamaan kuadrat, mau sesusah apapun, mau sekompleks apapun. Udah gitu, rumus ini juga kasih info bonus tentang jenis akar-akarnya. Keren banget kan?

Tapi sebelum kita pakai rumusnya, kita harus paham dulu dari mana rumus ini datang. Trust me, ini penting biar kamu nggak cuma hafal doang!

### **Penurunan Rumus ABC dari Melengkapkan Kuadrat**

Nah, ini adalah "behind the scenes" dari rumus ABC. Kita akan buktikan rumus ini dari teknik melengkapkan kuadrat yang udah kita pelajari!

**Mulai dari bentuk umum:**

ax² + bx + c = 0 (a ≠ 0)

**Step 1: Bagi semua dengan a**

x² + (b/a)x + (c/a) = 0

**Step 2: Pindahkan konstanta**

x² + (b/a)x = -c/a

**Step 3: Lengkapkan kuadrat**

Tambahkan (b/2a)² ke kedua ruas:

x² + (b/a)x + (b/2a)² = -c/a + (b/2a)²

**Step 4: Sederhanakan ruas kanan**

x² + (b/a)x + (b/2a)² = -c/a + b²/4a²

Samakan penyebut:

= (-4ac + b²)/4a²

= (b² - 4ac)/4a²

**Step 5: Faktorkan ruas kiri**

(x + b/2a)² = (b² - 4ac)/4a²

**Step 6: Akarkan kedua ruas**

x + b/2a = ±√[(b² - 4ac)/4a²]

x + b/2a = ±√(b² - 4ac)/(2a)

**Step 7: Selesaikan untuk x**

x = -b/2a ± √(b² - 4ac)/(2a)

x = [-b ± √(b² - 4ac)]/(2a)

**TADAAA! Itulah Rumus ABC!** 🎉

### **Rumus ABC: Formula Emas**

**x = [-b ± √(b² - 4ac)] / (2a)**

Komponen-komponennya:
- **a** = koefisien x²
- **b** = koefisien x
- **c** = konstanta
- **±** = artinya ada dua kemungkinan (+ dan -)

Yang menghasilkan dua akar:
- **x₁ = [-b + √(b² - 4ac)] / (2a)**
- **x₂ = [-b - √(b² - 4ac)] / (2a)**

### **Diskriminan (D): Si Penentu Nasib**

Bagian **b² - 4ac** di dalam akar disebut **Diskriminan** (dilambangkan **D**).

**D = b² - 4ac**

Ini adalah bagian PALING PENTING karena diskriminan menentukan:
1. **Jenis akar** persamaan
2. **Banyaknya akar**
3. **Karakteristik grafik parabola**

### **Syarat dan Jenis Akar Berdasarkan Diskriminan**

**KONDISI 1: D > 0 (Diskriminan Positif)**

Karakteristik:
- Persamaan punya **2 akar real berbeda**
- Grafik parabola **memotong sumbu x di 2 titik**

Sub-kondisi:
- **D > 0 dan D = bilangan kuadrat sempurna** → 2 akar **rasional** berbeda
  - Contoh: D = 25, maka √25 = 5 (rasional)
  
- **D > 0 dan D ≠ bilangan kuadrat sempurna** → 2 akar **irasional** berbeda
  - Contoh: D = 7, maka √7 (irasional)

**KONDISI 2: D = 0 (Diskriminan Nol)**

Karakteristik:
- Persamaan punya **2 akar real kembar** (sama)
- Grafik parabola **menyentuh sumbu x di 1 titik** (titik puncak)
- Akarnya selalu **rasional**
- x₁ = x₂ = -b/(2a)

**KONDISI 3: D < 0 (Diskriminan Negatif)**

Karakteristik:
- Persamaan **tidak punya akar real**
- Akarnya **imajiner** (kompleks)
- Grafik parabola **tidak memotong sumbu x**

### **Tabel Ringkasan Diskriminan**

| **Diskriminan** | **Jenis Akar** | **Grafik Parabola** |
|-----------------|----------------|---------------------|
| D > 0 (kuadrat sempurna) | 2 akar rasional berbeda | Memotong sumbu x di 2 titik |
| D > 0 (bukan kuadrat sempurna) | 2 akar irasional berbeda | Memotong sumbu x di 2 titik |
| D = 0 | 2 akar real kembar (rasional) | Menyentuh sumbu x di 1 titik |
| D < 0 | Tidak ada akar real (imajiner) | Tidak memotong sumbu x |

### **Contoh Penerapan Rumus ABC**

**Contoh 1: Akar Rasional Berbeda**

Selesaikan: x² - 7x + 12 = 0

**Identifikasi koefisien:**
- a = 1, b = -7, c = 12

**Hitung diskriminan:**
- D = b² - 4ac
- D = (-7)² - 4(1)(12)
- D = 49 - 48
- D = 1 > 0 ✅

Karena D = 1 (kuadrat sempurna), maka ada 2 akar rasional berbeda.

**Gunakan rumus ABC:**

x = [-(-7) ± √1] / (2·1)

x = [7 ± 1] / 2

**x₁ = (7 + 1)/2 = 8/2 = 4**

**x₂ = (7 - 1)/2 = 6/2 = 3**

**Jawaban: x = 3 atau x = 4** ✅

**Contoh 2: Akar Irasional Berbeda**

Selesaikan: x² + 4x + 1 = 0

**Identifikasi:**
- a = 1, b = 4, c = 1

**Diskriminan:**
- D = 4² - 4(1)(1)
- D = 16 - 4
- D = 12 > 0 ✅

Karena D = 12 (bukan kuadrat sempurna), ada 2 akar irasional.

**Rumus ABC:**

x = [-4 ± √12] / 2

x = [-4 ± 2√3] / 2

x = -2 ± √3

**x₁ = -2 + √3**

**x₂ = -2 - √3**

**Jawaban: x = -2 ± √3** ✅

**Contoh 3: Akar Kembar**

Selesaikan: x² - 6x + 9 = 0

**Identifikasi:**
- a = 1, b = -6, c = 9

**Diskriminan:**
- D = (-6)² - 4(1)(9)
- D = 36 - 36
- D = 0 ✅

Karena D = 0, ada akar kembar.

**Rumus ABC:**

x = [-(-6) ± √0] / 2

x = 6/2

**x = 3** (akar kembar)

**Jawaban: x = 3** ✅

**Contoh 4: Tidak Ada Akar Real**

Selesaikan: x² + 2x + 5 = 0

**Identifikasi:**
- a = 1, b = 2, c = 5

**Diskriminan:**
- D = 2² - 4(1)(5)
- D = 4 - 20
- D = -16 < 0 ❌

Karena D < 0, **tidak ada akar real**.

**Jawaban: Tidak ada penyelesaian real** (atau x ∈ bilangan kompleks)

**Contoh 5: Koefisien Bukan 1**

Selesaikan: 2x² - 5x + 2 = 0

**Identifikasi:**
- a = 2, b = -5, c = 2

**Diskriminan:**
- D = (-5)² - 4(2)(2)
- D = 25 - 16
- D = 9 > 0 ✅ (kuadrat sempurna)

**Rumus ABC:**

x = [-(-5) ± √9] / (2·2)

x = [5 ± 3] / 4

**x₁ = (5 + 3)/4 = 8/4 = 2**

**x₂ = (5 - 3)/4 = 2/4 = 1/2**

**Jawaban: x = 2 atau x = 1/2** ✅

### **Efisiensi Penggunaan Rumus ABC**

**KAPAN PAKAI Rumus ABC?**

✅ **PAKAI** kalau:
- Persamaan susah difaktorkan
- Koefisien dalam bentuk desimal atau pecahan
- Butuh jawaban cepat dan pasti
- Diminta nilai eksak (tidak boleh dibulatkan)
- Soal minta analisis diskriminan

❌ **JANGAN PAKAI** kalau:
- Bisa difaktorkan dengan mudah (lebih cepat)
- Cuma diminta jenis akar (cukup cek diskriminan)
- Koefisien a sangat besar (risiko salah hitung)

### **🎯 TIPS JITU UTBK:**

**1. Cek Diskriminan Dulu!**

Sebelum pakai rumus, hitung D untuk tahu jenis akarnya. Kadang soal cuma nanya jenis akar, jadi nggak perlu hitung sampai akarnya!

**2. Perhatikan Tanda b**

Kesalahan paling sering: lupa kalau b negatif!
- Kalau b = -5, maka -b = +5 ✅
- Jangan jadi -b = -5 ❌

**3. Sederhanakan Bentuk Akar**

- √12 = 2√3 ✅ (lebih sederhana)
- Jangan biarkan √12 aja ❌

**4. Hati-hati dengan Pembilang Bersuku Dua**

- x = (7 ± 3)/2 → x = 10/2 atau 4/2 ✅
- JANGAN: x = 7/2 ± 3 ❌ (salah urutan operasi!)

**5. Double Check dengan Substitusi**

Kalau masih ada waktu, cek jawaban dengan memasukkan ke persamaan awal!

### **⚠️ JEBAKAN UMUM di UTBK:**

**Jebakan 1: Salah Hitung Diskriminan**

b² - 4ac, BUKAN b - 4ac atau 4ac - b²!

**Jebakan 2: Lupa Kurung di Rumus**

- ✅ Benar: x = [-b ± √D] / (2a) → pembagi 2a untuk SEMUA
- ❌ Salah: x = -b ± √D / 2a → hanya akar yang dibagi

**Jebakan 3: Salah Identifikasi Koefisien**

Persamaan: 3 - 2x - x² = 0

Harus diubah dulu ke bentuk standar: -x² - 2x + 3 = 0

- a = -1 (jangan lupa tanda minus!)
- b = -2
- c = 3

**Jebakan 4: Terkecoh Soal "Tidak Ada Akar"**

Kalau D < 0, jawaban bukan "salah" atau "error", tapi "tidak ada akar real"!

**Jebakan 5: Akar Kembar Ditulis Dua Kali**

Kalau D = 0 dan x = 3, jawaban cukup "x = 3", BUKAN "x = 3 atau x = 3"

### **🔥 STRATEGI KHUSUS UTBK:**

**Untuk Soal Pilihan Ganda:**

1. **Eliminasi pakai diskriminan** terlebih dahulu
2. **Cek pilihan jawaban** - kadang bisa substitusi langsung!
3. **Perhatikan bentuk jawaban** - kalau ada √, kemungkinan akar irasional
4. **Jangan buang waktu** - kalau stuck, skip dulu!

**Untuk Soal Analisis:**

Kalau diminta:
- "Jenis akar" → cukup hitung D
- "Jumlah akar" → pakai rumus Vieta (materi berikutnya)
- "Akar terbesar" → hitung kedua akar, pilih yang lebih besar
- "Nilai diskriminan" → hitung D aja

### **💡 INSIGHT PENTING:**

**Mengapa Rumus ABC Selalu Berhasil?**

Karena rumus ini diturunkan dari prinsip melengkapkan kuadrat yang PASTI bisa dilakukan untuk semua persamaan kuadrat, tanpa peduli bentuk koefisiennya!

**Hubungan dengan Grafik:**

- D > 0 → grafik "menembus" sumbu x
- D = 0 → grafik "mencium" sumbu x
- D < 0 → grafik "melayang" di atas/bawah sumbu x

**Aplikasi di Dunia Nyata:**

Rumus ABC dipakai di:
- Fisika (gerak parabola)
- Ekonomi (analisis titik impas)
- Teknik (perhitungan struktur)
- Komputer (algoritma grafis)
