### **Rumus Vieta: The Power Duo**

Untuk persamaan kuadrat **ax² + bx + c = 0** dengan akar-akar x₁ dan x₂:

**RUMUS 1: Jumlah Akar**

**x₁ + x₂ = -b/a**

**RUMUS 2: Hasil Kali Akar**

**x₁ × x₂ = c/a**

**Pembuktian Rumus Vieta:**

Dari rumus ABC, kita tahu:

x₁ = [-b + √(b² - 4ac)] / (2a)

x₂ = [-b - √(b² - 4ac)] / (2a)

**Untuk Jumlah:**

x₁ + x₂ = {[-b + √D] + [-b - √D]} / (2a)

x₁ + x₂ = (-b - b) / (2a)

x₁ + x₂ = **-2b / (2a) = -b/a** ✅

**Untuk Hasil Kali:**

x₁ × x₂ = {[-b + √D] / (2a)} × {[-b - √D] / (2a)}

x₁ × x₂ = [(-b)² - (√D)²] / (4a²)

x₁ × x₂ = (b² - D) / (4a²)

Ingat: D = b² - 4ac, jadi b² - D = b² - (b² - 4ac) = 4ac

x₁ × x₂ = 4ac / (4a²)

x₁ × x₂ = **c/a** ✅

### **Penerapan Rumus Vieta: Level Basic**

**Contoh 1: Mencari Jumlah dan Hasil Kali Akar**

Tentukan jumlah dan hasil kali akar dari: x² - 7x + 10 = 0

**Penyelesaian:**

Identifikasi: a = 1, b = -7, c = 10

**Jumlah akar:**
- x₁ + x₂ = -b/a = -(-7)/1 = **7** ✅

**Hasil kali akar:**
- x₁ × x₂ = c/a = 10/1 = **10** ✅

**Cek dengan mencari akarnya:**
- x² - 7x + 10 = (x - 2)(x - 5) = 0
- x₁ = 2, x₂ = 5
- Jumlah: 2 + 5 = 7 ✅
- Kali: 2 × 5 = 10 ✅

**Contoh 2: Koefisien a Bukan 1**

Tentukan jumlah dan hasil kali akar dari: 2x² + 6x - 8 = 0

**Penyelesaian:**

a = 2, b = 6, c = -8

**Jumlah:**
- x₁ + x₂ = -6/2 = **-3** ✅

**Hasil kali:**
- x₁ × x₂ = -8/2 = **-4** ✅

**Insight:** Perhatikan! Hasil kali negatif berarti satu akar positif, satu negatif!

### **Menyusun Persamaan Kuadrat Baru**

Kalau kita tahu x₁ dan x₂, kita bisa menyusun persamaan kuadratnya!

**RUMUS STANDAR:**

Persamaan dengan akar x₁ dan x₂ adalah:

**x² - (x₁ + x₂)x + (x₁ × x₂) = 0**

Atau dalam bentuk koefisien:

**x² - (jumlah akar)x + (hasil kali akar) = 0**

**Contoh 3: Menyusun dari Akar yang Diketahui**

Susun persamaan kuadrat yang akar-akarnya 3 dan 5!

**Penyelesaian:**

x₁ = 3, x₂ = 5

Jumlah: 3 + 5 = 8
Kali: 3 × 5 = 15

**Persamaan: x² - 8x + 15 = 0** ✅

**Cek:**
- (x - 3)(x - 5) = x² - 5x - 3x + 15 = x² - 8x + 15 ✅

**Contoh 4: Akar Berbentuk Pecahan**

Susun persamaan kuadrat dengan akar 1/2 dan -3!

**Penyelesaian:**

Jumlah: 1/2 + (-3) = 1/2 - 3 = -5/2

Kali: (1/2) × (-3) = -3/2

**Persamaan: x² - (-5/2)x + (-3/2) = 0**

**x² + (5/2)x - 3/2 = 0**

Kalikan dengan 2 untuk eliminasi pecahan:

**2x² + 5x - 3 = 0** ✅

### **Hubungan Akar dengan Koefisien: Advanced Level**

**Contoh 5: Mencari Nilai Lain dari Akar**

Diketahui x² - 5x + 6 = 0 dengan akar x₁ dan x₂. Tentukan:
a) x₁² + x₂²
b) 1/x₁ + 1/x₂
c) (x₁ - x₂)²

**Penyelesaian:**

Dari persamaan: a = 1, b = -5, c = 6

x₁ + x₂ = 5
x₁ × x₂ = 6

**a) x₁² + x₂² = ?**

Gunakan identitas: (x₁ + x₂)² = x₁² + 2x₁x₂ + x₂²

Maka: x₁² + x₂² = (x₁ + x₂)² - 2x₁x₂

x₁² + x₂² = (5)² - 2(6)

x₁² + x₂² = 25 - 12 = **13** ✅

**b) 1/x₁ + 1/x₂ = ?**

Samakan penyebut: 1/x₁ + 1/x₂ = (x₂ + x₁)/(x₁x₂)

= (x₁ + x₂)/(x₁ × x₂)

= 5/6 ✅

**c) (x₁ - x₂)² = ?**

Gunakan: (x₁ - x₂)² = (x₁ + x₂)² - 4x₁x₂

= (5)² - 4(6)

= 25 - 24 = **1** ✅

Atau bisa juga pakai diskriminan:

(x₁ - x₂)² = D/a² = (b² - 4ac)/a²

= (25 - 24)/1 = **1** ✅

**Contoh 6: Persamaan Kuadrat dengan Syarat**

Tentukan nilai m agar persamaan x² - 2mx + 9 = 0 memiliki akar kembar!

**Penyelesaian:**

Akar kembar terjadi jika D = 0

D = b² - 4ac = 0

(-2m)² - 4(1)(9) = 0

4m² - 36 = 0

4m² = 36

m² = 9

**m = ±3** ✅

### **Aplikasi Rumus Vieta dalam Soal UTBK**

**Tipe Soal 1: Hubungan Akar Baru**

Jika x₁ dan x₂ adalah akar dari x² - 5x + 3 = 0, tentukan persamaan kuadrat baru yang akar-akarnya (x₁ + 2) dan (x₂ + 2)!

**Penyelesaian:**

Dari persamaan awal:
- x₁ + x₂ = 5
- x₁ × x₂ = 3

Akar baru: α = x₁ + 2, β = x₂ + 2

**Jumlah akar baru:**
α + β = (x₁ + 2) + (x₂ + 2)
= x₁ + x₂ + 4
= 5 + 4 = **9**

**Hasil kali akar baru:**
α × β = (x₁ + 2)(x₂ + 2)
= x₁x₂ + 2x₁ + 2x₂ + 4
= x₁x₂ + 2(x₁ + x₂) + 4
= 3 + 2(5) + 4
= 3 + 10 + 4 = **17**

**Persamaan baru: x² - 9x + 17 = 0** ✅

**Tipe Soal 2: Akar Berlipat**

Jika akar-akar x² - 4x + 1 = 0 adalah x₁ dan x₂, tentukan persamaan baru yang akar-akarnya 2x₁ dan 2x₂!

**Penyelesaian:**

x₁ + x₂ = 4
x₁ × x₂ = 1

Akar baru: α = 2x₁, β = 2x₂

**Jumlah:**
α + β = 2x₁ + 2x₂ = 2(x₁ + x₂) = 2(4) = **8**

**Hasil kali:**
α × β = (2x₁)(2x₂) = 4x₁x₂ = 4(1) = **4**

**Persamaan baru: x² - 8x + 4 = 0** ✅

**Tipe Soal 3: Akar Resiprokal (Kebalikan)**

Persamaan kuadrat yang akar-akarnya kebalikan dari akar x² - 6x + 2 = 0 adalah...

**Penyelesaian:**

x₁ + x₂ = 6
x₁ × x₂ = 2

Akar baru: α = 1/x₁, β = 1/x₂

**Jumlah:**
α + β = 1/x₁ + 1/x₂ = (x₁ + x₂)/(x₁x₂) = 6/2 = **3**

**Hasil kali:**
α × β = (1/x₁)(1/x₂) = 1/(x₁x₂) = 1/2

**Persamaan baru: x² - 3x + 1/2 = 0**

Atau kalikan 2: **2x² - 6x + 1 = 0** ✅

**Shortcut:** Kalau akar-akarnya kebalikan, tinggal tukar koefisien a dan c!

x² - 6x + 2 = 0 → **2x² - 6x + 1 = 0** ✅

### **Formula Penting untuk Kombinasi Akar**

**1. Kuadrat Jumlah:**
x₁² + x₂² = (x₁ + x₂)² - 2x₁x₂

**2. Kuadrat Selisih:**
(x₁ - x₂)² = (x₁ + x₂)² - 4x₁x₂ = D/a²

**3. Kubik Jumlah:**
x₁³ + x₂³ = (x₁ + x₂)³ - 3x₁x₂(x₁ + x₂)

**4. Jumlah Kebalikan:**
1/x₁ + 1/x₂ = (x₁ + x₂)/(x₁x₂)

**5. Hasil Kali Kebalikan:**
(1/x₁)(1/x₂) = 1/(x₁x₂)

### **🎯 TIPS JITU UTBK:**

**1. Hafalkan Rumus Vieta!**

Ini WAJIB! x₁ + x₂ = -b/a dan x₁ × x₂ = c/a

**2. Identifikasi Pola Soal**

- Kalau diminta "jumlah" atau "hasil kali" → langsung pakai Vieta!
- Kalau diminta "susun persamaan" → pakai x² - (jumlah)x + (kali) = 0

**3. Untuk Akar Baru, Cari Pola!**

- Akar + k → jumlah tambah 2k
- Akar × k → hasil kali dikali k²
- 1/akar → tukar a dan c

**4. Jangan Hitung Akar Kalau Nggak Perlu!**

Kalau soal cuma minta jumlah/hasil kali, JANGAN hitung akarnya! Buang waktu!

**5. Cek Logika Jawaban**

- Jumlah akar negatif → salah satu atau kedua akar negatif
- Hasil kali akar negatif → satu positif, satu negatif
- Hasil kali akar positif → kedua akar bertanda sama

### **⚠️ JEBAKAN UMUM di UTBK:**

**Jebakan 1: Lupa Tanda Minus**

x₁ + x₂ = -b/a, BUKAN b/a!

**Jebakan 2: Salah Bagi**

Kalau a ≠ 1, HARUS dibagi dengan a!

Contoh: 2x² - 6x + 4 = 0
- x₁ + x₂ = -(-6)/2 = 3 ✅
- BUKAN = -(-6)/1 = 6 ❌

**Jebakan 3: Akar Baru - Lupa Ekspansi**

(x₁ + 2)(x₂ + 2) ≠ x₁x₂ + 4!

Harus ekspansi penuh: x₁x₂ + 2x₁ + 2x₂ + 4

**Jebakan 4: Tukar Posisi**

Persamaan baru: x² - (JUMLAH)x + (KALI) = 0

BUKAN: x² - (KALI)x + (JUMLAH) = 0 ❌

**Jebakan 5: Akar Resiprokal - Salah Rumus**

1/x₁ + 1/x₂ = (x₁ + x₂)/(x₁x₂) ✅

BUKAN = 1/(x₁ + x₂) ❌
