## **Materi 1.1.1: Pengenalan Aljabar dan Sifat-sifat Operasi** *(GRATIS)*

### 🎯 **Apa Sih Aljabar Itu?**

Bayangin kamu lagi belanja di minimarket. Kamu beli 3 bungkus mie instan dan 2 botol air mineral. Terus kasirnya bilang, "Total harganya x + y rupiah." Nah, **x** dan **y** ini adalah representasi dari harga mie dan air yang belum kamu tahu pastinya. Itulah esensi dari aljabar—**menggunakan huruf untuk mewakili angka yang belum diketahui!**

Aljabar adalah bahasa matematika yang memungkinkan kita untuk:
- Menyederhanakan masalah rumit jadi lebih ringkas
- Menemukan nilai yang belum diketahui
- Membuat pola dan rumus yang universal

Di SNBT, aljabar ini bukan cuma "x + y = berapa", tapi juga tentang **bagaimana kamu berpikir logis dan sistematis** dalam menyelesaikan masalah!

---

### 📚 **Komponen Dasar Aljabar: The Holy Trinity**

Sebelum masuk lebih dalam, kamu harus kenal dulu tiga "tokoh utama" dalam aljabar:

#### **1. Variabel (Variable)**
Ini adalah **huruf yang mewakili bilangan yang belum diketahui**. Biasanya pakai huruf seperti x, y, z, a, b, atau huruf lainnya.

**Contoh:**
- Dalam ekspresi `3x + 5`, **x** adalah variabel
- Dalam `2y - 7`, **y** adalah variabel

**💡 Tips SNBT:** Variabel itu kayak kotak kosong yang bisa diisi angka apa aja. Jangan langsung panik kalau lihat huruf! Anggap aja dia "tamu undangan" yang akan terungkap identitasnya nanti.

#### **2. Konstanta (Constant)**
Ini adalah **bilangan tetap** yang nilainya sudah jelas. Gak berubah-ubah!

**Contoh:**
- Dalam ekspresi `3x + 5`, angka **5** adalah konstanta
- Dalam `2y - 7`, angka **-7** adalah konstanta
- Angka seperti 10, -3, 0.5, π (pi) juga konstanta

#### **3. Koefisien (Coefficient)**
Ini adalah **angka yang mengalikan variabel**. Koefisien menunjukkan "berapa banyak" variabel itu ada.

**Contoh:**
- Dalam `3x`, angka **3** adalah koefisien dari x
- Dalam `-5y`, angka **-5** adalah koefisien dari y
- Dalam `x` (tanpa angka di depan), koefisiennya adalah **1** (karena x = 1x)

**🎯 Jebakan SNBT:** Hati-hati sama variabel yang "sendirian" kayak `x` atau `y`. Koefisiennya tetap 1, bukan 0! Kalau koefisiennya 0, variabel itu hilang: `0x = 0`.

---

### 🔥 **Suku dan Bentuk Aljabar**

Sekarang kita naik level! Dalam aljabar, ada yang namanya **suku** (term). Suku adalah bagian dari bentuk aljabar yang dipisahkan oleh tanda **+** atau **-**.

**Contoh:**
- `3x + 5y - 2` → Punya **3 suku**: 3x, 5y, dan -2
- `7a - 4b + c + 9` → Punya **4 suku**: 7a, -4b, c, dan 9

**Jenis-jenis bentuk aljabar berdasarkan jumlah suku:**
1. **Monomial** (1 suku): `3x`, `5y²`, `-7`
2. **Binomial** (2 suku): `2x + 3`, `5a - 4b`
3. **Trinomial** (3 suku): `x² + 2x + 1`, `3a + 2b - 5c`
4. **Polinomial** (banyak suku): `x³ + 2x² - 5x + 7`

**💡 Tips SNBT:** Kalau soal bilang "bentuk aljabar dengan 3 suku", berarti mereka minta trinomial. Gampang kan?

### ⚡ **Sifat-sifat Operasi Aljabar: The Power Rules**

Nah, ini bagian yang sering dilupakan tapi SUPER PENTING di SNBT! Sifat-sifat ini adalah "hukum dasar" yang berlaku di dunia aljabar. Kayak hukum gravitasi tapi untuk matematika.

#### **1. Sifat Komutatif (Commutative Property)**
**"Urutan boleh ditukar, hasilnya tetap sama!"**

**Penjumlahan:**
```
a + b = b + a
```
Contoh: `3 + 5 = 5 + 3 = 8`
Dalam aljabar: `x + y = y + x`

**Perkalian:**
```
a × b = b × a
```
Contoh: `4 × 6 = 6 × 4 = 24`
Dalam aljabar: `xy = yx` atau `3x = x · 3`

**❌ PERHATIAN:** Sifat komutatif **TIDAK berlaku** untuk pengurangan dan pembagian!
- `5 - 3 ≠ 3 - 5` (5-3=2, tapi 3-5=-2)
- `6 ÷ 2 ≠ 2 ÷ 6` (6÷2=3, tapi 2÷6=⅓)

**🎯 Jebakan SNBT:** Soal kadang nyelipin pertanyaan kayak "Apakah a - b = b - a?" Jawabannya: **TIDAK!** Hati-hati jangan ketipu!

---

#### **2. Sifat Asosiatif (Associative Property)**
**"Pengelompokan boleh diubah, hasilnya tetap sama!"**

**Penjumlahan:**
```
(a + b) + c = a + (b + c)
```
Contoh: `(2 + 3) + 4 = 2 + (3 + 4) = 9`

**Perkalian:**
```
(a × b) × c = a × (b × c)
```
Contoh: `(2 × 3) × 4 = 2 × (3 × 4) = 24`

**❌ PERHATIAN:** Seperti komutatif, sifat asosiatif juga **TIDAK berlaku** untuk pengurangan dan pembagian!

**💡 Tips SNBT:** Sifat asosiatif berguna banget buat nyederhanain perhitungan. Misal: `5 + 47 + 5` → lebih gampang kalau dijadiin `(5 + 5) + 47 = 10 + 47 = 57` daripada `5 + 47` terus baru `+ 5`.

---

#### **3. Sifat Distributif (Distributive Property)**
**"Perkalian dapat dibagikan ke penjumlahan/pengurangan!"**

Ini adalah sifat **PALING PENTING** dan **PALING SERING MUNCUL** di SNBT!

**Rumus:**
```
a(b + c) = ab + ac
a(b - c) = ab - ac
```

**Contoh angka:**
```
3(4 + 5) = 3·4 + 3·5 = 12 + 15 = 27
```

**Contoh aljabar:**
```
2(x + 3) = 2x + 6
5(2a - 4) = 10a - 20
-3(x + 2y) = -3x - 6y
```

**🔥 Aplikasi Advanced:**
Distributif juga berlaku untuk dua kurung:
```
(a + b)(c + d) = ac + ad + bc + bd
```

Contoh:
```
(x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6
```

**🎯 Jebakan SNBT #1:** Hati-hati dengan tanda! Kalau ada minus di depan kurung:
```
-(x + 5) = -x - 5  (BUKAN -x + 5!)
-(2a - 3b) = -2a + 3b
```
Tanda di dalam kurung **SEMUA kebalik** kalau didistribusiin dengan minus!

**🎯 Jebakan SNBT #2:** Soal suka kasih bentuk kayak gini:
```
3(x + 2) - 2(x - 1) = ?
```
Jangan buru-buru langsung kurangin! Distributif dulu:
```
= 3x + 6 - 2x + 2
= x + 8
```

### 🎮 **Operasi Aljabar: The Core Gameplay**

Sekarang kita masuk ke bagian yang **action-packed**: operasi aljabar! Ini adalah skill yang harus kamu kuasai 100% buat ngelewatin SNBT.

---

#### **A. Penjumlahan dan Pengurangan Bentuk Aljabar**

**Prinsip Utama: "Yang sejenis dijumlahkan, yang beda didiamkan!"**

**Apa itu "sejenis"?**
Suku-suku aljabar dikatakan sejenis kalau:
1. Variabelnya **sama**
2. Pangkat variabelnya **sama**

**Contoh suku sejenis:**
- `3x` dan `5x` → sejenis (sama-sama x)
- `2x²` dan `-7x²` → sejenis (sama-sama x²)
- `4xy` dan `6xy` → sejenis (sama-sama xy)

**Contoh suku TIDAK sejenis:**
- `3x` dan `5y` → beda variabel
- `2x²` dan `5x` → beda pangkat
- `4xy` dan `4x²y` → beda pangkat

**Cara Operasi:**
1. Identifikasi suku-suku sejenis
2. Jumlahkan/kurangkan **koefisiennya** saja
3. Variabelnya tetap sama

**Contoh 1:**
```
3x + 5x = (3 + 5)x = 8x
```

**Contoh 2:**
```
7a - 4a + 2a = (7 - 4 + 2)a = 5a
```

**Contoh 3 (Mix):**
```
2x + 3y + 5x - y
= (2x + 5x) + (3y - y)
= 7x + 2y
```

**Contoh 4 (Advanced):**
```
3x² + 2x + 5x² - 4x + 7
= (3x² + 5x²) + (2x - 4x) + 7
= 8x² - 2x + 7
```

**🎯 Jebakan SNBT:** Soal suka kasih bentuk yang "acak-acakan" buat bikin kamu bingung:
```
5x - 3y + 2z - 4x + y - 2z + 3x
```
Jangan panik! Kelompokin dulu yang sejenis:
```
= (5x - 4x + 3x) + (-3y + y) + (2z - 2z)
= 4x - 2y + 0
= 4x - 2y
```

**💡 Tips SNBT:** Kalau lagi ujian, tulis yang sejenis dengan **warna pulpen berbeda** di kertas coret (atau minimal kelompokin dulu). Ini bakal bantu kamu gak kehilangan suku!

---

#### **B. Perkalian Bentuk Aljabar**

Perkalian aljabar itu kayak evolusi dari penjumlahan. Ada beberapa kasus yang perlu kamu kuasai:

**Kasus 1: Perkalian Konstanta dengan Bentuk Aljabar**
```
3 × 5x = 15x
-2 × 3y = -6y
4 × (2a + 3b) = 8a + 12b  (pakai distributif!)
```

**Kasus 2: Perkalian Variabel dengan Variabel**
Kalau variabelnya sama, pangkatnya **dijumlahkan**:
```
x × x = x²
x² × x³ = x⁵
2x × 3x = 6x²
```

**Mengapa pangkatnya dijumlahkan?**
Karena:
```
x² × x³ = (x·x) × (x·x·x) = x·x·x·x·x = x⁵
```

**Kasus 3: Perkalian Suku dengan Suku (Binomial)**
Gunakan **FOIL Method** (First, Outer, Inner, Last):

```
(a + b)(c + d) = ac + ad + bc + bd
     ↓    ↓    ↓    ↓
  First Outer Inner Last
```

**Contoh:**
```
(x + 3)(x + 5)
= x·x + x·5 + 3·x + 3·5
= x² + 5x + 3x + 15
= x² + 8x + 15
```

**Contoh dengan minus:**
```
(2x - 3)(x + 4)
= 2x·x + 2x·4 + (-3)·x + (-3)·4
= 2x² + 8x - 3x - 12
= 2x² + 5x - 12
```

**🔥 Pola Khusus yang WAJIB Dihafal:**

1. **Kuadrat Jumlah:**
```
(a + b)² = a² + 2ab + b²
```
Contoh: `(x + 3)² = x² + 6x + 9`

2. **Kuadrat Selisih:**
```
(a - b)² = a² - 2ab + b²
```
Contoh: `(x - 5)² = x² - 10x + 25`

3. **Selisih Kuadrat:**
```
(a + b)(a - b) = a² - b²
```
Contoh: `(x + 7)(x - 7) = x² - 49`

**🎯 Jebakan SNBT #1:** Soal sering kasih `(x + 5)²` dan banyak siswa langsung tulis `x² + 25`. **INI SALAH BESAR!**
Yang benar:
```
(x + 5)² = x² + 10x + 25
```
Jangan lupa suku tengah `2ab`-nya!

**🎯 Jebakan SNBT #2:** Hati-hati dengan tanda:
```
(x - 3)² ≠ x² - 9
Yang benar: (x - 3)² = x² - 6x + 9
```

**💡 Tips SNBT:** Kalau lihat pola `(sesuatu + sesuatu)(sesuatu - sesuatu)` → langsung inget selisih kuadrat! Ini shortcut paling ampuh.

---

#### **C. Pembagian Bentuk Aljabar**

Pembagian adalah kebalikan dari perkalian. Prinsipnya:

**Kasus 1: Pembagian dengan Konstanta**
```
6x ÷ 3 = 2x
15y ÷ 5 = 3y
-12a ÷ 4 = -3a
```

**Kasus 2: Pembagian Variabel dengan Variabel**
Kalau variabelnya sama, pangkatnya **dikurangkan**:
```
x⁵ ÷ x² = x³
6x⁴ ÷ 2x = 3x³
15x³y² ÷ 3xy = 5x²y
```

**Mengapa pangkatnya dikurangkan?**
Karena:
```
x⁵/x² = (x·x·x·x·x)/(x·x) = x³
```

**Kasus 3: Pembagian Bentuk Aljabar dengan Bentuk Aljabar**
```
(6x² + 9x) ÷ 3x = 6x²/3x + 9x/3x = 2x + 3
```

**🎯 Jebakan SNBT:** Jangan bagi hanya satu suku!
```
❌ SALAH: (6x² + 9x) ÷ 3x = 2x² + 3x
✅ BENAR: (6x² + 9x) ÷ 3x = 2x + 3
```
**SETIAP suku** harus dibagi!

### 🛡️ **Penggunaan Tanda Kurung dalam Ekspresi Aljabar**

Tanda kurung itu kayak "tembok pemisah" yang menunjukkan operasi mana yang harus dikerjakan duluan. Di matematika, ada **aturan prioritas operasi** yang disingkat **PEMDAS/BODMAS**:

1. **P**arentheses / **B**rackets (Kurung)
2. **E**xponents / **O**rders (Pangkat)
3. **M**ultiplication & **D**ivision (Perkalian & Pembagian - dari kiri)
4. **A**ddition & **S**ubtraction (Penjumlahan & Pengurangan - dari kiri)

**Contoh:**
```
3 + 2 × 5 = 3 + 10 = 13  (perkalian dulu!)
(3 + 2) × 5 = 5 × 5 = 25  (kurung dulu!)
```

**Dalam Aljabar:**
```
2x + 3(x + 4)
= 2x + 3x + 12  (distributif kurung dulu)
= 5x + 12
```

**Kurung Bertingkat:**
Kalau ada kurung dalam kurung, kerjakan **dari dalam ke luar**:
```
2[3(x + 2) - 4]
= 2[3x + 6 - 4]  (kerjakan kurung dalam)
= 2[3x + 2]
= 6x + 4  (distributif kurung luar)
```

**🎯 Jebakan SNBT:** Soal suka bikin bentuk yang rumit dengan banyak kurung:
```
5 - 2[3 - (x + 1)]
```
Kerjakan dari dalam:
```
= 5 - 2[3 - x - 1]
= 5 - 2[2 - x]
= 5 - 4 + 2x
= 1 + 2x
```

**💡 Tips SNBT:** Kalau bingung dengan kurung, **tulis ulang** setiap langkah. Jangan loncat-loncat karena satu kesalahan kecil bisa bikin jawaban salah total!

### 🧩 **Penyederhanaan Bentuk Aljabar Sederhana**

Penyederhanaan adalah proses membuat bentuk aljabar jadi **lebih ringkas** dan **lebih mudah dipahami**. Ini adalah skill yang **SANGAT PENTING** di SNBT karena bentuk yang lebih sederhana lebih gampang dihitung.

**Langkah-langkah Penyederhanaan:**

1. **Buka semua kurung** (kalau ada)
2. **Kelompokkan suku sejenis**
3. **Operasikan suku sejenis**
4. **Tulis jawaban dalam bentuk paling sederhana**

**Contoh 1:**
```
Sederhanakan: 3(2x + 5) + 4(x - 2)

Langkah 1 - Buka kurung:
= 6x + 15 + 4x - 8

Langkah 2 & 3 - Kelompokkan dan operasikan:
= (6x + 4x) + (15 - 8)
= 10x + 7
```

**Contoh 2:**
```
Sederhanakan: 5x - 2(3x - 4) + 7

Langkah 1:
= 5x - 6x + 8 + 7

Langkah 2 & 3:
= (5x - 6x) + (8 + 7)
= -x + 15
```

**Contoh 3 (Advanced):**
```
Sederhanakan: (x + 3)² - (x - 2)(x + 2)

Langkah 1 - Gunakan pola khusus:
= (x² + 6x + 9) - (x² - 4)

Langkah 2 - Buka kurung (ingat tanda!):
= x² + 6x + 9 - x² + 4

Langkah 3:
= (x² - x²) + 6x + (9 + 4)
= 6x + 13
```

**🎯 Jebakan SNBT #1:** Hati-hati dengan **tanda minus di depan kurung**!
```
❌ SALAH: 5 - (2x + 3) = 5 - 2x + 3
✅ BENAR: 5 - (2x + 3) = 5 - 2x - 3 = 2 - 2x
```

**🎯 Jebakan SNBT #2:** Jangan langsung "coret-coret" suku yang kelihatannya sama:
```
❌ SALAH: x² + 2x - x² = 2x²
✅ BENAR: x² + 2x - x² = 2x
```
x² dan -x² saling menghilangkan jadi 0!

## **Materi 1.1.2: Operasi Pecahan Aljabar**

### 🎯 **Pecahan Aljabar: Gabungan Dua Dunia!**

Kalau di materi sebelumnya kamu udah kenalan sama aljabar, sekarang saatnya kenalin dia ke **pecahan**! Bayangin pecahan aljabar itu kayak smoothie—campuran dua bahan (pembilang dan penyebut) yang harus kamu blend dengan benar biar hasilnya enak!

Pecahan aljabar adalah bentuk **pembagian** antara dua bentuk aljabar, di mana pembilang dan/atau penyebut mengandung variabel.

**Bentuk umum:**
```
p(x)
----
q(x)
```

Di mana:
- `p(x)` = pembilang (numerator)
- `q(x)` = penyebut (denominator)
- `q(x) ≠ 0` ← **SUPER PENTING!**

---

### 🚨 **Konsep Pecahan Aljabar dan Syarat Penyebutnya**

**Aturan Emas Pecahan:**
> **PENYEBUT TIDAK BOLEH NOL!**

Kenapa? Karena **pembagian dengan nol itu tidak terdefinisi** dalam matematika. Ini kayak kamu mau bagi kue ke 0 orang—gak masuk akal kan?

**Contoh:**
```
   x + 3
   -----
   x - 2
```

Syarat: `x - 2 ≠ 0`, jadi `x ≠ 2`

**Contoh 2:**
```
     2x
   -------
   x² - 9
```

Syarat: `x² - 9 ≠ 0`
→ `(x + 3)(x - 3) ≠ 0`
→ `x ≠ -3` dan `x ≠ 3`

**🎯 Jebakan SNBT:** Soal sering tanya "Nilai x yang memenuhi adalah..." terus kasih pilihan yang **bikin penyebut nol**. Ini jebakan! Nilai itu **TIDAK MEMENUHI** karena bikin pecahan gak terdefinisi!

---

### 🔧 **Penyederhanaan Pecahan Aljabar dengan Faktorisasi**

Seperti pecahan biasa, pecahan aljabar bisa disederhanakan dengan **membagi pembilang dan penyebut dengan faktor persekutuan**.

**Langkah-langkah:**
1. **Faktorkan** pembilang dan penyebut
2. **Coret** faktor yang sama
3. **Tulis** hasil penyederhanaan

**Contoh 1: Sederhana**
```
  6x        6·x       3
  --- = --------- = ---
  8x        8·x       4
  
(Asumsi x ≠ 0)
```

**Contoh 2: Menggunakan Faktorisasi**
```
  x² - 4        (x + 2)(x - 2)       x + 2
  ------- = ------------------- = ---------
  x² - 2x      x(x - 2)              x

(Asumsi x ≠ 0, x ≠ 2)
```

**Contoh 3: Advanced**
```
  x² + 5x + 6      (x + 2)(x + 3)       x + 3
  ----------- = ----------------- = ---------
  x² + 4x + 4      (x + 2)(x + 2)       x + 2

(Asumsi x ≠ -2)
```

**🔥 Teknik Faktorisasi yang Sering Muncul:**

1. **Faktor Persekutuan:**
   ```
   3x + 6     3(x + 2)     3
   ------ = --------- = -----
   x + 2       x + 2       1
   ```

2. **Selisih Dua Kuadrat:**
   ```
   x² - 25      (x + 5)(x - 5)      x + 5
   ------- = ----------------- = ---------
   x² - 5x      x(x - 5)            x
   ```

3. **Trinomial Kuadrat:**
   ```
   x² - 7x + 12     (x - 3)(x - 4)     x - 3
   ------------ = ----------------- = -------
   x² - 6x + 8      (x - 2)(x - 4)     x - 2
   ```

**🎯 Jebakan SNBT #1:** **JANGAN coret sembarangan!**
```
❌ SALAH:
  x + 5       5
  ----- = ----- 
  x + 3       3
  
(Kamu gak bisa coret x yang dijumlahkan!)
```

```
✅ Baru boleh coret kalau dalam bentuk PERKALIAN:
  x(x + 5)      x + 5
  -------- = ---------
  x(x + 3)      x + 3
```

**🎯 Jebakan SNBT #2:** Hati-hati dengan tanda!
```
  x - 5        x - 5        -1
  ----- = ------------- = -----
  5 - x      -(x - 5)       1

(Karena 5 - x = -(x - 5))
```

**💡 Tips SNBT:** Kalau lihat penyebut dan pembilang yang "hampir sama" tapi kebalik, coba keluarkan tanda minus!

---

### ➕➖ **Penjumlahan dan Pengurangan Pecahan Aljabar**

Prinsipnya **SAMA PERSIS** kayak pecahan biasa:
1. Samakan penyebut (cari KPK)
2. Jumlahkan/kurangkan pembilang
3. Sederhanakan hasil

**Kasus 1: Penyebut Sudah Sama**
```
  3        5        3 + 5       8
----- + ----- = --------- = ---------
x + 2   x + 2      x + 2       x + 2
```

**Kasus 2: Penyebut Berbeda (Sederhana)**
```
  2       3
----- + ---
  x       y

KPK dari x dan y adalah xy, jadi:

  2·y     3·x      2y + 3x
= ----- + ----- = ----------
  x·y     y·x         xy
```

**Kasus 3: Penyebut Berbeda (Dengan Faktorisasi)**
```
    1         2
--------- + -------
(x + 1)     (x - 1)

KPK = (x + 1)(x - 1), jadi:

  1·(x - 1)       2·(x + 1)
= ----------- + -------------
  (x+1)(x-1)     (x-1)(x+1)

  (x - 1) + 2(x + 1)
= -------------------
    (x + 1)(x - 1)

  x - 1 + 2x + 2
= ----------------
   (x + 1)(x - 1)

     3x + 1
= ---------------
  (x + 1)(x - 1)
```

**Contoh 4: Advanced (KPK Kompleks)**
```
    3           2
--------- - ---------
x² - 4      x² - 4x + 4

Faktorkan penyebut:
= (x + 2)(x - 2)  dan  (x - 2)²

KPK = (x + 2)(x - 2)²

      3·(x - 2)              2·(x + 2)
= ----------------- - ---------------------
  (x+2)(x-2)(x-2)      (x-2)(x-2)(x+2)

  3(x - 2) - 2(x + 2)
= ---------------------
   (x+2)(x-2)²

  3x - 6 - 2x - 4
= -----------------
   (x+2)(x-2)²

      x - 10
= ---------------
  (x+2)(x-2)²
```

**🎯 Jebakan SNBT #1:** Saat mengalikan silang, JANGAN lupa tanda kurung!
```
❌ SALAH:
  1       2        1·x-1 + 2·x+1
----- + ----- = -----------------
x + 1   x - 1     (x+1)(x-1)

✅ BENAR:
  1       2        1·(x-1) + 2·(x+1)
----- + ----- = ---------------------
x + 1   x - 1       (x+1)(x-1)
```

**🎯 Jebakan SNBT #2:** Hati-hati saat **PENGURANGAN**!
```
  5       3        5·y - 3·x      5y - 3x
--- - --- = -------------- = -----------
  x     y           xy              xy

BUKAN: (5 - 3)(y + x) ← INI SALAH TOTAL!
```

**💡 Tips SNBT:** Kalau penyebutnya udah dalam bentuk faktor, **JANGAN dikalikan jadi bentuk baku**. Lebih enak tetap dalam bentuk faktor buat nyari KPK!

---

### ✖️➗ **Perkalian dan Pembagian Pecahan Aljabar**

**A. PERKALIAN**

Perkalian pecahan aljabar jauh lebih **gampang** daripada penjumlahan!

**Rumus:**
```
a     c      a·c
- × --- = -------
b     d      b·d
```

**Langkah:**
1. Faktorkan (kalau bisa)
2. Coret faktor yang sama
3. Kalikan pembilang dengan pembilang, penyebut dengan penyebut

**Contoh 1:**
```
  x        x + 2         x(x + 2)
----- × --------- = ---------------
x + 2      x + 3      (x+2)(x+3)

                       x
                  = -------
                     x + 3
```

**Contoh 2:**
```
  x² - 9       x + 1
--------- × ---------
  x + 1      x² + 3x

  (x+3)(x-3)     x + 1
= ---------- × ---------
    x + 1       x(x+3)

  (x-3)
= -----
    x
```

**Contoh 3: Multiple Fractions**
```
  x² - 4      x + 3        2
--------- × ------- × -------
x² + 5x + 6   x - 2      x + 2

  (x+2)(x-2)    x + 3          2
= ---------- × --------- × -------
  (x+2)(x+3)    x - 2       x + 2

         2
= -----------
     x + 2
```

**🔥 Shortcut:** Coret **SEBELUM** mengalikan! Ini bakal menghemat waktu dan mengurangi kemungkinan error.

---

**B. PEMBAGIAN**

Pembagian = Perkalian dengan **kebalikan** (reciprocal)!

**Rumus:**
```
a     c      a     d      a·d
- ÷ --- = - × --- = -------
b     d      b     c      b·c
```

**Caranya:**
1. **Balik** pecahan yang kedua
2. **Ubah** pembagian jadi perkalian
3. Lanjutkan seperti perkalian biasa

**Contoh 1:**
```
  x        x + 2        x         x + 3
----- ÷ --------- = ------- × ---------
x + 3      x + 3      x + 3       x + 2

                        x
                  = ---------
                      x + 2
```

**Contoh 2:**
```
  x² - 1       x - 1
--------- ÷ ---------
  x + 2        x + 2

  (x+1)(x-1)     x + 2
= ---------- × ---------
     x + 2       x - 1

           x + 1
= -------------------
          1

= x + 1
```

**Contoh 3: Advanced**
```
  x² + 4x + 4      x + 2
------------- ÷ ---------
   x² - 9         x² - 3x

  (x+2)²        x(x-3)
= -------- × -----------
  (x+3)(x-3)    x + 2

   (x+2)·x
= ----------
    x + 3

   x² + 2x
= ---------
    x + 3
```

**🎯 Jebakan SNBT:** Jangan lupa **BALIK yang KEDUA**, bukan yang pertama!
```
❌ SALAH: a/b ÷ c/d = b/a × c/d
✅ BENAR: a/b ÷ c/d = a/b × d/c
```

---

### 📝 **Penyelesaian Soal Aplikasi Pecahan Aljabar**

Di SNBT, pecahan aljabar sering muncul dalam **soal cerita** atau **soal gabungan**. Berikut tipe-tipe soal yang sering keluar:

**Tipe 1: Penyederhanaan Kompleks**
```
Sederhanakan:
    1           1
--------- - ---------
x(x + 1)    (x+1)(x+2)

Jawab:
KPK = x(x+1)(x+2)

  (x+2) - x
= -----------
  x(x+1)(x+2)

     2
= -----------
  x(x+1)(x+2)
```

**Tipe 2: Operasi Campuran**
```
   x + 1      x - 1         2
  ------- + ------- × ---------
   x - 1      x + 2       x + 1

Kerjakan perkalian dulu:

       (x-1)·2
= ... + --------
       (x+2)(x+1)

(Lanjutkan dengan samakan penyebut...)
```

**Tipe 3: Soal "Nilai yang Memenuhi"**
```
Pecahan  2x + 1
         ------  terdefinisi untuk x = ...
         x² - 4

Jawab:
Syarat: x² - 4 ≠ 0
→ (x+2)(x-2) ≠ 0
→ x ≠ -2 dan x ≠ 2

Jadi nilai yang TIDAK memenuhi: x = -2 atau x = 2
```

**Tipe 4: Mencari Nilai Variabel**
```
Jika  x + 3     5
      ----- = -----, maka x = ...
      x - 1     2

Cross multiply:
2(x + 3) = 5(x - 1)
2x + 6 = 5x - 5
6 + 5 = 5x - 2x
11 = 3x
x = 11/3
```

**🎯 Jebakan SNBT #1:** Soal suka kasih "nilai x yang memenuhi" padahal yang ditanya "nilai x yang TIDAK memenuhi". Baca teliti!

**🎯 Jebakan SNBT #2:** Setelah dapat nilai x, **CEK KEMBALI** apakah nilai itu bikin penyebut nol. Kalau iya, nilai itu **bukan solusi**!

---

### 🎓 **Ringkasan Materi 1.1.2**

**Checklist yang Harus Kamu Kuasai:**
- ✅ Syarat penyebut ≠ 0
- ✅ Faktorisasi untuk penyederhanaan
- ✅ Penjumlahan/pengurangan → samakan penyebut (KPK)
- ✅ Perkalian → langsung kalikan, coret yang sama
- ✅ Pembagian → balik yang kedua, ubah jadi perkalian
- ✅ Hati-hati dengan tanda (terutama saat pengurangan!)

**Time Management SNBT:**
- Soal pecahan aljabar sederhana: **2-3 menit**
- Soal pecahan aljabar kompleks: **3-5 menit**
- Kalau lebih dari 5 menit stuck, **skip** dan balik lagi!

## **Materi 1.1.3: Eksponen dan Bentuk Akar**

### 🚀 **Welcome to the Power Zone!**

Bayangin kamu punya mesin pengali super cepat. Daripada nulis `2 × 2 × 2 × 2 × 2`, kamu cukup tulis `2⁵`. Itulah **eksponen**—cara pintar matematika buat nulis perkalian berulang!

Dan bentuk akar? Itu adalah "teman sejati" eksponen yang bekerja **kebalikannya**. Kalau eksponen itu perkalian berulang, akar itu **mencari angka yang kalau dikalikan berulang hasilnya angka itu**.

---

### ⚡ **Sifat-sifat Bilangan Berpangkat (Eksponen)**

**Definisi:**
```
aⁿ = a × a × a × ... × a  (sebanyak n kali)
```

Di mana:
- `a` = bilangan pokok (base)
- `n` = pangkat/eksponen (exponent)

**Contoh:**
- `3⁴ = 3 × 3 × 3 × 3 = 81`
- `2⁵ = 2 × 2 × 2 × 2 × 2 = 32`
- `10³ = 10 × 10 × 10 = 1000`

---

### 🔥 **Sifat-Sifat Eksponen yang WAJIB Dihafal!**

Ini adalah **hukum fundamental** yang berlaku untuk semua bilangan berpangkat:

**Sifat 1: Perkalian dengan Basis Sama**
```
aᵐ × aⁿ = aᵐ⁺ⁿ
```
Pangkatnya **DIJUMLAHKAN**!

**Contoh:**
```
2³ × 2⁴ = 2³⁺⁴ = 2⁷ = 128

x² × x⁵ = x²⁺⁵ = x⁷
```

**Penjelasan:**
```
2³ × 2⁴ = (2·2·2) × (2·2·2·2) = 2⁷
```

---

**Sifat 2: Pembagian dengan Basis Sama**
```
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
```
Pangkatnya **DIKURANGKAN**!

**Contoh:**
```
2⁵ ÷ 2² = 2⁵⁻² = 2³ = 8

x⁷ ÷ x³ = x⁷⁻³ = x⁴
```

---

**Sifat 3: Pangkat dari Pangkat**
```
(aᵐ)ⁿ = aᵐˣⁿ
```
Pangkatnya **DIKALIKAN**!

**Contoh:**
```
(2³)² = 2³ˣ² = 2⁶ = 64

(x²)⁵ = x²ˣ⁵ = x¹⁰
```

**Penjelasan:**
```
(2³)² = 2³ × 2³ = 2³⁺³ = 2⁶
```

---

**Sifat 4: Pangkat dari Perkalian**
```
(ab)ⁿ = aⁿ × bⁿ
```

**Contoh:**
```
(2 × 3)² = 2² × 3² = 4 × 9 = 36

(xy)³ = x³y³
```

---

**Sifat 5: Pangkat dari Pembagian**
```
(a/b)ⁿ = aⁿ/bⁿ
```

**Contoh:**
```
(2/3)² = 2²/3² = 4/9

(x/y)⁴ = x⁴/y⁴
```

---

**Sifat 6: Pangkat Nol**
```
a⁰ = 1  (untuk a ≠ 0)
```

**Contoh:**
```
5⁰ = 1
100⁰ = 1
x⁰ = 1  (asumsi x ≠ 0)
```

**Mengapa?**
```
a³ ÷ a³ = a³⁻³ = a⁰
Tapi juga: a³ ÷ a³ = 1
Jadi: a⁰ = 1
```

**🎯 Jebakan SNBT:** `0⁰` itu **tidak terdefinisi** (undefined)! Jadi kalau ada soal tentang ini, hati-hati!

---

**Sifat 7: Pangkat Negatif**
```
a⁻ⁿ = 1/aⁿ
```

**Contoh:**
```
2⁻³ = 1/2³ = 1/8

x⁻² = 1/x²

3⁻¹ = 1/3
```

**Cara pikir:**
```
a² ÷ a⁵ = a²⁻⁵ = a⁻³
Tapi juga: a² ÷ a⁵ = (a·a)/(a·a·a·a·a) = 1/a³
Jadi: a⁻³ = 1/a³
```

---

**Sifat 8: Pangkat Pecahan (Akar)**
```
a^(1/n) = ⁿ√a

a^(m/n) = ⁿ√(aᵐ) = (ⁿ√a)ᵐ
```

**Contoh:**
```
4^(1/2) = √4 = 2

8^(1/3) = ³√8 = 2

16^(3/4) = ⁴√(16³) = ⁴√4096 = 8
atau: (⁴√16)³ = 2³ = 8
```

---

### 🎮 **Operasi pada Bilangan Berpangkat**

**Contoh 1: Kombinasi Sifat**
```
Sederhanakan: 2⁵ × 2³ ÷ 2⁴

= 2⁵⁺³⁻⁴
= 2⁴
= 16
```

**Contoh 2: Dengan Variabel**
```
Sederhanakan: (x³)² × x⁴ ÷ x⁷

= x⁶ × x⁴ ÷ x⁷
= x⁶⁺⁴⁻⁷
= x³
```

**Contoh 3: Pangkat Negatif**
```
Sederhanakan: 2⁻² × 2⁵

= 2⁻²⁺⁵
= 2³
= 8

Atau cara lain:
= (1/2²) × 2⁵
= 2⁵/2²
= 2³
= 8
```

**Contoh 4: Advanced**
```
Sederhanakan: (2x²y³)³ ÷ (4xy²)²

= (2³x⁶y⁹) ÷ (4²x²y⁴)
= (8x⁶y⁹) ÷ (16x²y⁴)
= (8/16) × x⁶⁻² × y⁹⁻⁴
= (1/2) × x⁴ × y⁵
= x⁴y⁵/2
```

**🎯 Jebakan SNBT #1:** Hati-hati dengan **basis negatif**!
```
(-2)⁴ = (-2)×(-2)×(-2)×(-2) = 16  (POSITIF)
-2⁴ = -(2×2×2×2) = -16  (NEGATIF)

Ada tanda kurung? Beda hasilnya!
```

**🎯 Jebakan SNBT #2:** Operasi penjumlahan/pengurangan **TIDAK bisa** langsung disederhanakan!
```
❌ SALAH: 2³ + 2⁴ = 2⁷
✅ BENAR: 2³ + 2⁴ = 8 + 16 = 24

(Sifat eksponen cuma berlaku buat perkalian/pembagian!)
```

**💡 Tips SNBT:** Kalau lihat soal dengan banyak sifat eksponen, **tulis semua langkah**. Satu kesalahan kecil bisa bikin domino error!

---

### 🌱 **Bentuk Akar dan Sifat-sifatnya**

**Definisi Akar:**
```
ⁿ√a = bilangan yang jika dipangkatkan n menghasilkan a

√a = ²√a  (akar kuadrat)
³√a = akar pangkat tiga
⁴√a = akar pangkat empat
...dan seterusnya
```

**Contoh:**
```
√9 = 3  (karena 3² = 9)
³√27 = 3  (karena 3³ = 27)
⁴√16 = 2  (karena 2⁴ = 16)
```

---

### 🔥 **Sifat-Sifat Bentuk Akar**

**Sifat 1: Akar dari Perkalian**
```
√(a × b) = √a × √b
```

**Contoh:**
```
√12 = √(4 × 3) = √4 × √3 = 2√3

√50 = √(25 × 2) = √25 × √2 = 5√2
```

---

**Sifat 2: Akar dari Pembagian**
```
√(a/b) = √a/√b
```

**Contoh:**
```
√(9/4) = √9/√4 = 3/2

√(16/25) = 4/5
```

---

**Sifat 3: Akar dari Akar**
```
ⁿ√(ᵐ√a) = ⁿˣᵐ√a
```

**Contoh:**
```
√(³√8) = ²ˣ³√8 = ⁶√8

³√(√64) = ⁶√64 = 2
```

---

**Sifat 4: Mengubah Akar ke Pangkat**
```
ⁿ√a = a^(1/n)

ⁿ√(aᵐ) = a^(m/n)
```

**Contoh:**
```
√x = x^(1/2)

³√(x²) = x^(2/3)
```

---

**Sifat 5: Menyederhanakan Akar**

Cari **faktor kuadrat sempurna** (untuk √) atau **faktor pangkat sempurna** (untuk akar lainnya):

```
√18 = √(9 × 2) = √9 × √2 = 3√2

√72 = √(36 × 2) = 6√2

³√54 = ³√(27 × 2) = ³√27 × ³√2 = 3³√2
```

**💡 Tips:** Hafal kuadrat sempurna!
- 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169, 196, 225...

---

### 🎨 **Merasionalkan Bentuk Akar**

**Merasionalkan** = menghilangkan bentuk akar dari **penyebut** pecahan.

**Kenapa penting?** Karena bentuk rasional lebih "cantik" dan lebih mudah dibandingkan!

---

**Kasus 1: Penyebut Bentuk √a**

**Cara:** Kalikan pembilang dan penyebut dengan √a

```
   1        1      √a       √a
------- = ----- × ---- = -------
  √a       √a     √a        a
```

**Contoh:**
```
   3        3      √2       3√2
----- = ----- × ---- = -----
  √2       √2     √2        2

   5        5      √3       5√3
----- = ----- × ---- = -----
  √3       √3     √3        3
```

---

**Kasus 2: Penyebut Bentuk a√b**

**Cara:** Kalikan dengan √b

```
    1         1       √b         √b
-------- = ------ × ---- = -----------
  a√b       a√b      √b        a·b
```

**Contoh:**
```
    2         2       √5         2√5
-------- = ------ × ---- = -----------
  3√5       3√5      √5        3·5

                               2√5
                          = -------
                               15
```

---

**Kasus 3: Penyebut Bentuk a + √b (PALING SERING DI SNBT!)**

**Cara:** Kalikan dengan **sekawan** (a - √b)

**Sekawan:**
- Sekawan dari `a + √b` adalah `a - √b`
- Sekawan dari `a - √b` adalah `a + √b`
- Sekawan dari `√a + √b` adalah `√a - √b`

**Rumus:**
```
(a + √b)(a - √b) = a² - b
```

**Contoh 1:**
```
      1 1         3 - √2
----------- = ---------- × ----------
  3 + √2        3 + √2      3 - √2

               3 - √2
          = -------------
            9 - 2

               3 - √2
          = ---------
                7
```

**Contoh 2:**
```
      4            4         2 + √3
----------- = ---------- × ----------
  2 - √3        2 - √3      2 + √3

               4(2 + √3)
          = ---------------
              4 - 3

          = 4(2 + √3)

          = 8 + 4√3
```

**Contoh 3: Advanced**
```
    √5 + 1          √5 + 1       √5 + 2
------------- = ------------ × ----------
  √5 - 2          √5 - 2        √5 + 2

                (√5+1)(√5+2)
            = -----------------
                  5 - 4

            = 5 + 2√5 + √5 + 2

            = 7 + 3√5
```

**🎯 Jebakan SNBT #1:** Jangan lupa **distribusi sempurna** saat mengalikan!
```
❌ SALAH:
(3 - √2)(3 + √2) = 9 - 2  (lupa suku tengah)

✅ BENAR:
(3 - √2)(3 + √2) = 9 - 3√2 + 3√2 - 2 = 9 - 2 = 7
```

Tapi karena ini pola selisih kuadrat, langsung aja:
```
(a + b)(a - b) = a² - b²
(3 + √2)(3 - √2) = 3² - (√2)² = 9 - 2 = 7
```

**🎯 Jebakan SNBT #2:** Hati-hati kalau ada **dua akar berbeda**!
```
Rasionalkan: 1/(√3 + √2)

Sekawannya: √3 - √2

     1          √3 - √2        √3 - √2
--------- × ------------ = --------------
√3 + √2      √3 - √2          3 - 2

                            = √3 - √2
```

---

### ➕➖✖️➗ **Operasi pada Bentuk Akar**

**A. PENJUMLAHAN DAN PENGURANGAN**

**Prinsip:** Hanya bisa dijumlahkan kalau **bentuk akarnya sama** (seperti suku sejenis!)

```
a√b + c√b = (a + c)√b
```

**Contoh 1:**
```
2√3 + 5√3 = 7√3
```

**Contoh 2:**
```
√2 + 3√2 - 5√2 = (1 + 3 - 5)√2 = -√2
```

**Contoh 3: Perlu Disederhanakan Dulu**
```
√8 + √18
= √(4×2) + √(9×2)
= 2√2 + 3√2
= 5√2
```

**Contoh 4: Mix**
```
2√12 - √27 + 3√3
= 2√(4×3) - √(9×3) + 3√3
= 2·2√3 - 3√3 + 3√3
= 4√3 - 3√3 + 3√3
= 4√3
```

**❌ TIDAK BISA:**
```
√2 + √3  (tidak bisa disederhanakan!)
√5 + 2√3  (tidak bisa dijumlahkan!)
```

---

**B. PERKALIAN**

Gunakan sifat: `√a × √b = √(ab)`

**Contoh 1:**
```
√2 × √3 = √6
```

**Contoh 2:**
```
2√3 × 5√2 = (2 × 5) × √(3 × 2) = 10√6
```

**Contoh 3:**
```
√5 × √5 = 5  (akar dikali sama sendiri = bilangan aslinya!)
```

**Contoh 4: Dengan Bentuk Campuran**
```
(2 + √3)(4 - √3)
= 2·4 + 2·(-√3) + √3·4 + √3·(-√3)
= 8 - 2√3 + 4√3 - 3
= 5 + 2√3
```

**Contoh 5: Pola Khusus**
```
(√a + √b)(√a - √b) = a - b

(√5 + √2)(√5 - √2) = 5 - 2 = 3
```

---

**C. PEMBAGIAN**

Gunakan sifat: `√a ÷ √b = √(a/b)`

**Contoh 1:**
```
√6 ÷ √2 = √(6/2) = √3
```

**Contoh 2:**
```
10√15 ÷ 5√3 = (10/5) × √(15/3) = 2√5
```

**Contoh 3: Perlu Rasionalisasi**
```
   √6            √6       √2       √12       2√3
------- = ---------- × ---- = ------ = ------
  √2           √2        √2        2         2

                                  = √3
```

**Eksponen - Hafal Sifat Ini:**
1. `aᵐ × aⁿ = aᵐ⁺ⁿ`
2. `aᵐ ÷ aⁿ = aᵐ⁻ⁿ`

4. `a⁰ = 1`
5. `a⁻ⁿ = 1/aⁿ`

2. `√(a/b) = √a/√b`
3. Rasionalisasi → kalikan sekawan!
4. Penjumlahan → hanya yang sejenis
5. Perkalian → langsung kalikan

**Time Management:**
- Soal eksponen sederhana: **1-2 menit**
- Soal akar dengan rasionalisasi: **2-3 menit**
- Soal kombinasi eksponen & akar: **3-4 menit**

### 🎯 **Faktorisasi: Seni Memecah Bentuk Aljabar!**

Bayangin kamu punya coklat batangan yang mau kamu bagi-bagi ke temen-temen. Daripada dalam bentuk utuh, kamu pecah jadi kotak-kotak kecil. Nah, **faktorisasi** itu kayak gitu—kita pecah bentuk aljabar jadi **perkalian faktor-faktor yang lebih sederhana**!

Kenapa penting? Karena:
- Mempermudah penyederhanaan pecahan aljabar
- Membantu menyelesaikan persamaan kuadrat
- Membuat operasi aljabar jadi lebih efisien
- **SERING BANGET KELUAR DI SNBT!**

---

### 🔢 **Faktor Persekutuan Terbesar (FPB) dalam Aljabar**

FPB adalah **faktor terbesar** yang bisa membagi semua suku dalam bentuk aljabar.

**Langkah mencari FPB:**
1. Cari FPB dari **koefisien** (angka)
2. Cari **variabel dengan pangkat terkecil**
3. Gabungkan keduanya

**Contoh 1:**
```
FPB dari 6x³ dan 9x²

Koefisien: FPB(6, 9) = 3
Variabel: x³ dan x² → pangkat terkecil = x²

FPB = 3x²
```

**Contoh 2:**
```
FPB dari 12x²y³ dan 18xy⁴

Koefisien: FPB(12, 18) = 6
Variabel x: x² dan x → x
Variabel y: y³ dan y⁴ → y³

FPB = 6xy³
```

---

### 🎨 **Faktorisasi Bentuk ax + ay**

Ini adalah bentuk faktorisasi **PALING DASAR**. Caranya: keluarkan **FPB**!

**Pola:**
```
ax + ay = a(x + y)
```

**Contoh 1:**
```
3x + 6 = 3(x + 2)
```

**Contoh 2:**
```
4x² + 8x = 4x(x + 2)
```

**Contoh 3:**
```
12x³y - 18x²y² = 6x²y(2x - 3y)
```

**Contoh 4: Lebih Kompleks**
```
5a²b + 10ab² - 15ab
= 5ab(a + 2b - 3)
```

**🎯 Jebakan SNBT:** Jangan lupa **semua suku** harus dibagi FPB!
```
❌ SALAH: 6x + 12 = 6(x + 2)  ← Kurang lengkap
✅ BENAR: 6x + 12 = 6(x + 2)  ← Ini udah bener

❌ SALAH: 4x² + 8x = 4(x² + 2x)  ← Masih bisa difaktorkan!
✅ BENAR: 4x² + 8x = 4x(x + 2)
```

**💡 Tips SNBT:** Setelah faktorisasi, **cek ulang** dengan cara mengalikan kembali. Hasilnya harus sama dengan bentuk awal!

---

### ⚡ **Faktorisasi Selisih Dua Kuadrat (a² - b²)**

Ini adalah **pola emas** faktorisasi! Harus hafal di luar kepala!

**Rumus:**
```
a² - b² = (a + b)(a - b)
```

**Kenapa?**
```
(a + b)(a - b) = a² - ab + ab - b² = a² - b²
```

**Contoh 1:**
```
x² - 9 = x² - 3² = (x + 3)(x - 3)
```

**Contoh 2:**
```
4x² - 25 = (2x)² - 5² = (2x + 5)(2x - 5)
```

**Contoh 3:**
```
9a² - 16b² = (3a)² - (4b)² = (3a + 4b)(3a - 4b)
```

**Contoh 4: Ada Koefisien**
```
2x² - 50 = 2(x² - 25) = 2(x + 5)(x - 5)
```

**Contoh 5: Pangkat Lebih Tinggi**
```
x⁴ - 16 = (x²)² - 4²
        = (x² + 4)(x² - 4)
        = (x² + 4)(x + 2)(x - 2)
```

**🎯 Jebakan SNBT #1:** **Hanya berlaku untuk SELISIH**, bukan jumlah!
```
❌: x² + 9 = (x + 3)(x + 3)  ← INI SALAH!
✅: x² + 9  (tidak bisa difaktorkan dengan bilangan real)

✅: x² - 9 = (x + 3)(x - 3)  ← Ini baru bener!
```

**🎯 Jebakan SNBT #2:** Cek apakah bisa difaktorkan lagi!
```
x⁴ - 1 = (x²)² - 1²
       = (x² + 1)(x² - 1)
       = (x² + 1)(x + 1)(x - 1)  ← Jangan lupa x² - 1 masih bisa!
```

---

### 💎 **Faktorisasi Trinomial Kuadrat Sempurna**

**Pola Kuadrat Sempurna:**
```
a² + 2ab + b² = (a + b)²
a² - 2ab + b² = (a - b)²
```

**Ciri-ciri kuadrat sempurna:**
1. Suku pertama dan ketiga adalah **kuadrat sempurna**
2. Suku tengah = **2 × √suku pertama × √suku ketiga**

**Contoh 1:**
```
x² + 6x + 9

Cek: √x² = x, √9 = 3
Suku tengah: 6x = 2·x·3 ✓

Jadi: (x + 3)²
```

**Contoh 2:**
```
4x² - 12x + 9

√4x² = 2x, √9 = 3
-12x = 2·2x·3·(-1) ✓

Jadi: (2x - 3)²
```

**Contoh 3:**
```
9a² + 30a + 25

√9a² = 3a, √25 = 5
30a = 2·3a·5 ✓

Jadi: (3a + 5)²
```

**🎯 Jebakan SNBT:** Kalau suku tengah **tidak sesuai**, bukan kuadrat sempurna!
```
x² + 5x + 4

Cek: √x² = x, √4 = 2
Seharusnya suku tengah = 2·x·2 = 4x
Tapi yang ada: 5x ✗

Jadi BUKAN kuadrat sempurna! (Pakai cara lain)
```

---

### 🚀 **Faktorisasi Bentuk ax² + bx + c**

Ini adalah **boss level** faktorisasi! Ada beberapa kasus:

---

**KASUS 1: a = 1 (bentuk x² + bx + c)**

**Pola:**
```
x² + bx + c = (x + p)(x + q)

Di mana:
- p + q = b
- p × q = c
```

**Langkah:**
1. Cari dua bilangan yang **dikalikan = c**
2. Dan **dijumlahkan = b**

**Contoh 1:**
```
x² + 5x + 6

Cari p dan q:
p × q = 6
p + q = 5

Pasangan faktor 6: (1,6), (2,3)
Yang jumlahnya 5: 2 dan 3 ✓

Jadi: (x + 2)(x + 3)
```

**Contoh 2:**
```
x² - 7x + 12

p × q = 12
p + q = -7

Cari yang negatif: (-3)×(-4) = 12, (-3)+(-4) = -7 ✓

Jadi: (x - 3)(x - 4)
```

**Contoh 3:**
```
x² + 2x - 15

p × q = -15
p + q = 2

Pasangan: (5)×(-3) = -15, 5+(-3) = 2 ✓

Jadi: (x + 5)(x - 3)
```

**💡 Tips:** Buat tabel faktor untuk mempermudah:
```
Faktor dari 12:
1×12, 2×6, 3×4
(-1)×(-12), (-2)×(-6), (-3)×(-4)
```

---

**KASUS 2: a ≠ 1 (bentuk ax² + bx + c)**

Ada dua metode: **AC Method** dan **Trial-Error**

**Metode AC (Recommended!):**

**Langkah:**
1. Kalikan a × c
2. Cari dua bilangan yang **dikalikan = ac** dan **dijumlahkan = b**
3. Pecah suku tengah
4. Faktorkan per kelompok

**Contoh 1:**
```
2x² + 7x + 3

a = 2, b = 7, c = 3
ac = 2 × 3 = 6

Cari p dan q:
p × q = 6
p + q = 7

Pasangan: 1 dan 6 ✓

Pecah suku tengah:
2x² + 7x + 3 = 2x² + x + 6x + 3

Faktorkan per kelompok:
= x(2x + 1) + 3(2x + 1)
= (2x + 1)(x + 3)
```

**Contoh 2:**
```
3x² - 10x + 8

ac = 3 × 8 = 24
Cari: p × q = 24, p + q = -10
Pasangan: -4 dan -6 ✓

3x² - 10x + 8 = 3x² - 4x - 6x + 8
              = x(3x - 4) - 2(3x - 4)
              = (3x - 4)(x - 2)
```

**Contoh 3:**
```
6x² + 11x - 10

ac = 6 × (-10) = -60
Cari: p × q = -60, p + q = 11
Pasangan: 15 dan -4 ✓

6x² + 11x - 10 = 6x² + 15x - 4x - 10
               = 3x(2x + 5) - 2(2x + 5)
               = (2x + 5)(3x - 2)
```

**🎯 Jebakan SNBT #1:** Saat memfaktorkan per kelompok, **faktor dalam kurung harus sama**!
```
❌ SALAH:
6x² + 15x - 4x - 10 = 3x(2x + 5) - 2(2x + 5)
                    = (2x + 5)(3x - 2) ✓

Kalau gak sama:
6x² + 15x - 4x - 10 = 3x(2x + 5) - 2(2x - 5)
                    ← Gak bisa dilanjutkan!
```

**🎯 Jebakan SNBT #2:** Selalu **cek ulang** dengan mengalikan!
```
Cek: (2x + 1)(x + 3)
= 2x² + 6x + x + 3
= 2x² + 7x + 3 ✓
```

### 🔥 **Perpangkatan Bentuk Aljabar (a + b)²**

Ini adalah **formula paling sering dipakai** di SNBT! Wajib hafal dan paham aplikasinya!

**Rumus Dasar:**

**1. Kuadrat Jumlah**
```
(a + b)² = a² + 2ab + b²
```

**Penjelasan:**
```
(a + b)² = (a + b)(a + b)
         = a² + ab + ab + b²
         = a² + 2ab + b²
```

**Contoh:**
```
(x + 3)² = x² + 2(x)(3) + 3²
         = x² + 6x + 9

(2x + 5)² = (2x)² + 2(2x)(5) + 5²
          = 4x² + 20x + 25
```

---

**2. Kuadrat Selisih**
```
(a - b)² = a² - 2ab + b²
```

**Contoh:**
```
(x - 4)² = x² - 2(x)(4) + 4²
         = x² - 8x + 16

(3x - 2)² = (3x)² - 2(3x)(2) + 2²
          = 9x² - 12x + 4
```

---

**3. Selisih Kuadrat (Review tapi PENTING!)**
```
(a + b)(a - b) = a² - b²
```

**Contoh:**
```
(x + 7)(x - 7) = x² - 49

(2x + 3)(2x - 3) = 4x² - 9
```

---

**4. Pola Lainnya yang Perlu Tahu:**

**Kuadrat Trinomial:**
```
(a + b + c)² = a² + b² + c² + 2ab + 2ac + 2bc
```

**Contoh:**
```
(x + 2 + y)² = x² + 4 + y² + 4x + 2xy + 4y
```

**Pangkat Tiga:**
```
(a + b)³ = a³ + 3a²b + 3ab² + b³
(a - b)³ = a³ - 3a²b + 3ab² - b³
```

**Contoh:**
```
(x + 2)³ = x³ + 3x²(2) + 3x(2²) + 2³
         = x³ + 6x² + 12x + 8
```

**🎯 Jebakan SNBT #1:** **JANGAN langsung kuadratkan tanpa rumus!**
```
❌ SALAH: (x + 5)² = x² + 25
✅ BENAR: (x + 5)² = x² + 10x + 25
```

**🎯 Jebakan SNBT #2:** Hati-hati dengan **tanda negatif**!
```
(-x + 3)² = (3 - x)² = 9 - 6x + x²  (BUKAN x² - 6x + 9)
```

**💡 Tips SNBT:** Kalau lihat soal seperti:
```
"Jika (x + 3)² = 16, maka nilai x² + 6x = ..."
```
Jangan expand! Langsung:
```
(x + 3)² = 16
x² + 6x + 9 = 16
x² + 6x = 7
```

### ⚡ **Perkalian Bentuk Aljabar Khusus**

Ada beberapa **pola perkalian** yang sering muncul dan bisa jadi shortcut!

---

**Pola 1: (x + a)(x + b)**
```
= x² + (a + b)x + ab
```

**Contoh:**
```
(x + 2)(x + 5) = x² + (2+5)x + 2·5
               = x² + 7x + 10
```

---

**Pola 2: (ax + b)(cx + d)**

Gunakan **FOIL** (First, Outer, Inner, Last):

```
= ac·x² + (ad + bc)x + bd
```

**Contoh:**
```
(2x + 3)(3x + 4)
= 2·3·x² + (2·4 + 3·3)x + 3·4
= 6x² + (8 + 9)x + 12
= 6x² + 17x + 12
```

---

**Pola 3: (a + b)(a + c)**
```
= a² + a(b + c) + bc
```

**Contoh:**
```
(x + 3)(x + 5) = x² + x(3 + 5) + 3·5
               = x² + 8x + 15
```

---

**Pola 4: Perkalian Tiga Faktor**

**Cara:** Kalikan dua faktor dulu, baru kalikan dengan faktor ketiga

**Contoh:**
```
(x + 1)(x + 2)(x + 3)

Langkah 1: (x + 1)(x + 2) = x² + 3x + 2

Langkah 2: (x² + 3x + 2)(x + 3)
         = x³ + 3x² + 3x² + 9x + 2x + 6
         = x³ + 6x² + 11x + 6
```

**💡 Tips:** Kalau ada pola **selisih kuadrat**, langsung pakai rumus!
```
(x + 2)(x - 2)(x² + 4)
= (x² - 4)(x² + 4)    ← Pakai selisih kuadrat dulu!
= x⁴ - 16
```

### ➗ **Pembagian Bentuk Aljabar dengan Bentuk Aljabar**

**Kasus 1: Pembagian Monomial dengan Monomial**
```
6x³ ÷ 2x = 3x²

12x²y³ ÷ 4xy² = 3xy
```

**Kasus 2: Pembagian Polinomial dengan Monomial**

Bagi **setiap suku** dengan pembagi!

```
(6x³ + 9x² - 3x) ÷ 3x
= 6x³/3x + 9x²/3x - 3x/3x
= 2x² + 3x - 1
```

**Contoh:**
```
(8x⁴ - 12x³ + 4x²) ÷ 4x²
= 8x⁴/4x² - 12x³/4x² + 4x²/4x²
= 2x² - 3x + 1
```

---

**Kasus 3: Pembagian Polinomial dengan Polinomial**

Gunakan **Pembagian Bersusun** (seperti pembagian bilangan biasa)!

**Contoh:**
```
(x² + 5x + 6) ÷ (x + 2)

     x + 3        ← Hasil bagi
   ________
x+2 | x² + 5x + 6
      x² + 2x     ← x(x+2)
      -------
          3x + 6
          3x + 6  ← 3(x+2)
          ------
              0   ← Sisa

Jadi: (x² + 5x + 6) ÷ (x + 2) = x + 3
```

**Contoh 2:**
```
(2x² + 7x + 3) ÷ (x + 3)

      2x + 1
   __________
x+3 | 2x² + 7x + 3
      2x² + 6x
      --------
            x + 3
            x + 3
            -----
               0

Jadi: (2x² + 7x + 3) ÷ (x + 3) = 2x + 1
```

**🎯 Jebakan SNBT:** Kalau ada **sisa**, tulis dalam bentuk:
```
Hasil = Hasil bagi + Sisa/Pembagi

(x² + 3x + 5) ÷ (x + 1) = (x + 2) + 3/(x+1)
```

### 📊 **Teorema Sisa dan Teorema Faktor**

Ini adalah **shortcut super powerful** untuk pembagian polinomial!

---

**A. TEOREMA SISA**

> Jika polinomial f(x) dibagi (x - a), maka **sisanya = f(a)**

**Artinya:** Gak perlu pembagian bersusun! Tinggal **substitusi x = a**!

**Contoh 1:**
```
f(x) = x² + 5x + 6 dibagi (x - 2), sisanya?

Sisa = f(2) = 2² + 5(2) + 6
            = 4 + 10 + 6
            = 20
```

**Contoh 2:**
```
f(x) = 2x³ - 3x² + x - 5 dibagi (x + 1), sisanya?

Dibagi (x + 1) = (x - (-1)), jadi a = -1

Sisa = f(-1) = 2(-1)³ - 3(-1)² + (-1) - 5
             = -2 - 3 - 1 - 5
             = -11
```

**Contoh 3: Pembagi bukan (x - a)**
```
f(x) = 3x² + 2x - 5 dibagi (2x - 1), sisanya?

(2x - 1) = 2(x - 1/2)

Jadi a = 1/2

Sisa = f(1/2) = 3(1/2)² + 2(1/2) - 5
              = 3/4 + 1 - 5
              = -13/4
```

**💡 Tips:** Kalau pembagi bentuk (ax - b), maka a = b/a

---

**B. TEOREMA FAKTOR**

> (x - a) adalah **faktor** dari f(x) jika dan hanya jika **f(a) = 0**

**Artinya:** Kalau f(a) = 0, maka (x - a) bisa membagi f(x) **habis** (tanpa sisa)!

**Contoh 1:**
```
Apakah (x - 2) faktor dari f(x) = x² - 5x + 6?

Cek: f(2) = 2² - 5(2) + 6
          = 4 - 10 + 6
          = 0 ✓

Ya! (x - 2) adalah faktor!

Bukti: x² - 5x + 6 = (x - 2)(x - 3)
```

**Contoh 2:**
```
Tentukan nilai a jika (x + 2) adalah faktor dari:
f(x) = x³ + ax² - x - 6

Karena (x + 2) faktor, maka f(-2) = 0:

(-2)³ + a(-2)² - (-2) - 6 = 0
-8 + 4a + 2 - 6 = 0
4a - 12 = 0
a = 3
```

**🎯 Jebakan SNBT:** Teorema faktor **hanya untuk menguji**, bukan untuk mencari hasil bagi!

### 🎮 **Horner untuk Pembagian Polinomial**

**Metode Horner** adalah cara **super cepat** untuk membagi polinomial tanpa pembagian bersusun!

**Langkah:**
1. Tulis koefisien polinomial
2. Tulis nilai a dari pembagi (x - a)
3. Turunkan koefisien pertama
4. Kalikan dengan a, jumlahkan dengan koefisien berikutnya
5. Ulangi sampai selesai
6. Angka terakhir = sisa

**Contoh 1:**
```
(2x³ + 3x² - 5x + 1) ÷ (x - 2)

Koefisien: 2, 3, -5, 1
Pembagi (x - 2), jadi a = 2

     2    3   -5    1
  2 |___________________
     |  4   14   18    ← kalikan & jumlahkan
     2  7    9   19    ← hasil

Hasil bagi: 2x² + 7x + 9
Sisa: 19
```

**Cara bacanya:**
```
Baris 1: Koefisien awal
Baris 2: Hasil kali dengan a
Baris 3: Hasil penjumlahan

2 → turun langsung = 2
2×2 = 4, tambah 3 = 7
7×2 = 14, tambah -5 = 9
9×2 = 18, tambah 1 = 19 (SISA)
```

**Contoh 2:**
```
(x⁴ - 3x² + 2) ÷ (x + 1)

Koefisien: 1, 0, -3, 0, 2  ← Ingat koef x³ dan x ada tapi nol!
Pembagi (x + 1) = (x - (-1)), jadi a = -1

     1   0  -3   0   2
 -1 |____________________
     | -1   1   2  -2
     1  -1  -2   2   0  ← SISA = 0, jadi habis dibagi!

Hasil: x³ - x² - 2x + 2
```

**💡 Tips SNBT:** Horner **JAUH LEBIH CEPAT** daripada pembagian bersusun! Tapi pastikan kamu **tidak lupa koefisien yang 0**!

**🎯 Jebakan SNBT:** Kalau ada pangkat yang "loncat", **tetap tulis koefisien 0**!
```
x⁴ + 2x² + 1  →  Koefisien: 1, 0, 2, 0, 1
                              x⁴ x³ x² x¹ x⁰
```
