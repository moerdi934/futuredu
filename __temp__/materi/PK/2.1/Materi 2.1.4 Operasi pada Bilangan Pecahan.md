## Materi 2.1.4: Operasi pada Bilangan Pecahan

### Pecahan: Small Numbers, Big Impact! 🎯

Pecahan itu kayak puzzle pieces - keliatan kecil tapi kalau salah pasang, rusak semua! Di UTBK, soal pecahan sering jadi "speed bump" yang bikin siswa kehilangan waktu berharga. Tapi tenang, setelah ini kamu bakal jago operasi pecahan dengan cepat dan akurat!

---

### Jenis-jenis Pecahan - Know Your Enemy!

#### **1. Pecahan Biasa**

Bentuk standar: **a/b** (a = pembilang, b = penyebut)

**Klasifikasi:**
- **Pecahan Murni:** Pembilang < Penyebut
  - 1/2, 3/4, 5/8, 7/10
  
- **Pecahan Tidak Murni:** Pembilang ≥ Penyebut
  - 5/3, 7/4, 9/2, 10/10

**Syarat Penyebut:**
- **TIDAK BOLEH NOL!** (b ≠ 0)
- Kalau b = 0, pecahan tidak terdefinisi (undefined)

---

#### **2. Pecahan Campuran**

Bentuk: **a b/c** (a = bilangan bulat, b/c = pecahan murni)

**Contoh:**
- 2½ (dua setengah)
- 3¾ (tiga tiga perempat)
- 5⅖ (lima dua perlima)

**Hubungan dengan Pecahan Biasa:**
```
a b/c = (a×c + b)/c
```

**Contoh Konversi:**
- 2½ = (2×2 + 1)/2 = 5/2
- 3¾ = (3×4 + 3)/4 = 15/4
- 1⅗ = (1×5 + 3)/5 = 8/5

**Sebaliknya (Pecahan Biasa ke Campuran):**
```
13/4 = 3¼
```
Cara: 13 ÷ 4 = 3 sisa 1, jadi 3 **1**/4

---

#### **3. Pecahan Desimal**

Pecahan yang ditulis dengan koma/titik desimal.

**Jenis:**
- **Desimal Berakhir:** 0.5, 0.25, 0.125, 1.75
- **Desimal Berulang:** 0.333..., 0.666..., 0.142857...

**Konversi Desimal ke Pecahan:**
- **0.5** = 5/10 = 1/2
- **0.25** = 25/100 = 1/4
- **0.125** = 125/1000 = 1/8
- **0.75** = 75/100 = 3/4

**Trik Cepat:**
- 1 angka setelah koma → bagi 10
- 2 angka setelah koma → bagi 100
- 3 angka setelah koma → bagi 1000

---

#### **4. Persen (%)**

Persen = per seratus = /100

**Konversi:**
- **50%** = 50/100 = 1/2
- **25%** = 25/100 = 1/4
- **75%** = 75/100 = 3/4
- **100%** = 100/100 = 1
- **200%** = 200/100 = 2

**Rumus Penting:**
```
Persen = (Bagian/Keseluruhan) × 100%
```

### Menyederhanakan Pecahan - Making It Simple!

**Aturan Emas:** Bagi pembilang dan penyebut dengan **FPB** mereka.

**Langkah-langkah:**
1. Cari FPB dari pembilang dan penyebut
2. Bagi keduanya dengan FPB
3. Ulangi sampai tidak bisa disederhanakan lagi

**Contoh 1:**
```
12/18 = ?
FPB(12, 18) = 6
12/18 = (12÷6)/(18÷6) = 2/3 ✓
```

**Contoh 2:**
```
24/36 = ?
FPB(24, 36) = 12
24/36 = (24÷12)/(36÷12) = 2/3 ✓
```

**Trik Cepat - Faktorisasi Prima:**
```
48/72 = (2⁴×3)/(2³×3²)
Coret yang sama: 2³ dan 3
= 2/3 ✓
```

**Pecahan Sudah Sederhana Kalau:**
- FPB(pembilang, penyebut) = 1
- Tidak ada faktor persekutuan lagi
- Contoh: 3/7, 5/8, 7/11

### Penjumlahan dan Pengurangan Pecahan

#### **Rule #1: Penyebut Harus Sama!**

**Kasus 1: Penyebut Sudah Sama**

Super gampang! Langsung jumlahkan/kurangkan pembilangnya.

```
a/c + b/c = (a+b)/c
a/c - b/c = (a-b)/c
```

**Contoh:**
```
2/7 + 3/7 = 5/7 ✓
5/9 - 2/9 = 3/9 = 1/3 ✓
```

---

**Kasus 2: Penyebut Berbeda**

**Langkah-langkah:**
1. Cari **KPK** dari penyebut
2. Ubah setiap pecahan ke penyebut KPK
3. Jumlahkan/kurangkan pembilangnya
4. Sederhanakan hasil

**Contoh 1: 1/4 + 2/3**
```
Step 1: KPK(4, 3) = 12
Step 2: 1/4 = 3/12; 2/3 = 8/12
Step 3: 3/12 + 8/12 = 11/12 ✓
```

**Contoh 2: 3/5 - 1/6**
```
KPK(5, 6) = 30
3/5 = 18/30; 1/6 = 5/30
18/30 - 5/30 = 13/30 ✓
```

---

**Trik Cepat: Butterfly Method / Cross Multiply**

Untuk penjumlahan **a/b + c/d**:
```
a/b + c/d = (a×d + b×c)/(b×d)
```

Visual:
```
  a     c       a×d + b×c
 ─── + ─── = ─────────────
  b     d          b×d
```

**Contoh:**
```
1/4 + 2/3 = (1×3 + 4×2)/(4×3) = (3+8)/12 = 11/12 ✓
```

**Warning:** Jangan lupa sederhanakan kalau perlu!

---

**Kasus 3: Pecahan Campuran**

**Cara 1: Ubah ke Pecahan Biasa Dulu**
```
2½ + 1¾ = 5/2 + 7/4
        = 10/4 + 7/4
        = 17/4
        = 4¼ ✓
```

**Cara 2: Pisahkan Bulat dan Pecahan**
```
2½ + 1¾ = (2 + 1) + (½ + ¾)
        = 3 + (2/4 + 3/4)
        = 3 + 5/4
        = 3 + 1¼
        = 4¼ ✓
```

**Pengurangan Campuran:**
```
3¾ - 1⅖
= 15/4 - 7/5
= 75/20 - 28/20
= 47/20
= 2 7/20 ✓
```

### Perkalian Pecahan - Easy Peasy!

**Aturan Super Simple:**
```
a/b × c/d = (a×c)/(b×d)
```

**Kali atas dengan atas, bawah dengan bawah. That's it!**

**Contoh 1:**
```
2/3 × 4/5 = 8/15 ✓
```

**Contoh 2:**
```
3/7 × 2/9 = 6/63 = 2/21 ✓
```

---

**Trik Pro: Sederhanakan SEBELUM Mengalikan!**

Ini adalah **SECRET WEAPON** yang bikin kamu 10x lebih cepat!

**Contoh:**
```
6/7 × 14/15 = ?
```

**Cara Lambat:**
```
= 84/105 = 4/5 (harus nyederhana lagi!)
```

**Cara Cepat (Cross Cancel):**
```
 6    14      
─── × ─── 
 7    15     

Coret 6 dan 15 (bagi 3): 2 dan 5
Coret 7 dan 14 (bagi 7): 1 dan 2

= 2×2 / 1×5 = 4/5 ✓ (langsung!)
```

**Visual:**
```
 ⁶⁄₃    ¹⁴⁄₇      2    2      4
─── × ─── = ─── × ─── = ─── ✓
 ⁷⁄₇    ¹⁵⁄₃      1    5      5
```

**Pro Tip:** Selalu cari yang bisa di-cancel dulu sebelum kalikan!

---

**Perkalian dengan Bilangan Bulat:**
```
Bilangan Bulat = n/1
```

**Contoh:**
```
3 × 2/5 = 3/1 × 2/5 = 6/5 = 1⅕ ✓
5 × 3/4 = 5/1 × 3/4 = 15/4 = 3¾ ✓
```

---

**Perkalian Pecahan Campuran:**

**Step 1: Ubah ke Pecahan Biasa**
```
2½ × 1¾ = 5/2 × 7/4 = 35/8 = 4⅜ ✓
```

### Pembagian Pecahan - Keep, Change, Flip!

**Aturan Emas:**
```
a/b ÷ c/d = a/b × d/c
```

**Pembagian = Kalikan dengan Kebalikan!**

**Mnemonik: KCF Method**
- **K**eep (pertahankan pecahan pertama)
- **C**hange (ubah bagi jadi kali)
- **F**lip (balik pecahan kedua)

---

**Contoh 1:**
```
2/3 ÷ 4/5 = 2/3 × 5/4 = 10/12 = 5/6 ✓
```

**Contoh 2:**
```
3/4 ÷ 2/5 = 3/4 × 5/2 = 15/8 = 1⅞ ✓
```

**Contoh 3:**
```
5/6 ÷ 3 = 5/6 ÷ 3/1 = 5/6 × 1/3 = 5/18 ✓
```

---

**Pembagian Pecahan Campuran:**

**Langkah:**
1. Ubah semua ke pecahan biasa
2. Balik pecahan kedua
3. Kalikan
4. Sederhanakan

**Contoh:**
```
2½ ÷ 1¼ = 5/2 ÷ 5/4
        = 5/2 × 4/5
        = 20/10
        = 2 ✓
```

---

**Why Does "Flip" Work?**

**Matematika di baliknya:**
```
a/b ÷ c/d = a/b × 1/(c/d) = a/b × d/c
```

Membagi dengan suatu bilangan = mengalikan dengan kebalikannya!

**Analogi:** 
Membagi kue dengan 1/2 = mengalikan dengan 2
(Karena 1 kue dibagi jadi setengah = dapat 2 potong)

### Mengubah Bentuk Pecahan - Master Converter!

#### **1. Pecahan Biasa ke Desimal**

**Cara:** Bagi pembilang dengan penyebut

**Contoh:**
```
1/4 = 1 ÷ 4 = 0.25 ✓
3/8 = 3 ÷ 8 = 0.375 ✓
2/3 = 2 ÷ 3 = 0.666... ✓
```

---

#### **2. Desimal ke Pecahan**

**Untuk Desimal Berakhir:**

**Rumus:**
```

(n = jumlah angka setelah koma)
```

**Contoh:**
```
0.5 = 5/10 = 1/2 ✓
0.25 = 25/100 = 1/4 ✓
0.125 = 125/1000 = 1/8 ✓
0.875 = 875/1000 = 7/8 ✓
```

Gunakan teknik yang sudah dipelajari di Materi 2.1.3!

**Contoh:**

### Aplikasi Pecahan dalam Masalah Sehari-hari

#### **1. Masalah Pembagian**

**Contoh:**
"Sebuah kue dipotong menjadi 12 bagian sama besar. Andi mengambil 3 potong, Budi mengambil 4 potong. Berapa bagian kue yang tersisa?"

**Solusi:**
```
Total = 12 bagian = 1 kue
Andi = 3/12 = 1/4
Budi = 4/12 = 1/3
Tersisa = 1 - 1/4 - 1/3
       = 12/12 - 3/12 - 4/12
       = 5/12 ✓
```

---

#### **2. Masalah Perbandingan**

**Contoh:**
"Perbandingan uang Ani dan Budi adalah 3:5. Jika total uang mereka Rp 800.000, berapa uang Ani?"

**Solusi:**
```
Bagian Ani = 3/(3+5) = 3/8
Uang Ani = 3/8 × 800.000 = 300.000 ✓
```

---

#### **3. Masalah Diskon**

**Contoh:**
"Harga baju Rp 200.000 mendapat diskon 25%. Berapa harga yang harus dibayar?"

**Solusi:**
```
Diskon = 25% × 200.000 = 1/4 × 200.000 = 50.000
Harga bayar = 200.000 - 50.000 = 150.000 ✓

ATAU

Harga bayar = 75% × 200.000 = 3/4 × 200.000 = 150.000 ✓
```

---

#### **4. Masalah Campuran**

**Contoh:**
"Sebuah tangki air terisi 3/4 penuh. Setelah digunakan 1/3 dari isi tangki, kemudian ditambah 1/6 dari kapasitas tangki. Berapa bagian tangki yang terisi sekarang?"

**Solusi:**
```
Awal = 3/4
Digunakan = 1/3 × 3/4 = 3/12 = 1/4
Sisa = 3/4 - 1/4 = 2/4 = 1/2
Ditambah = 1/6
Total = 1/2 + 1/6 = 3/6 + 1/6 = 4/6 = 2/3 ✓
```

### Tips & Trik UTBK - Pecahan Edition 🎯

**Tip #1: Hafal Tabel Konversi!**

Kalau penyebutnya sudah sama, jangan cari KPK lagi!

Untuk penjumlahan/pengurangan cepat, use cross multiply!

### Common Mistakes - Yang Sering Salah! ⚠️

**Mistake #1: KPK vs FPB**
- Penjumlahan/Pengurangan → KPK (penyebut)
- Menyederhanakan → FPB (pembilang & penyebut)

**Mistake #2: Cross Multiply Everything**
❌ Menggunakan butterfly method untuk perkalian
✓ Butterfly hanya untuk penjumlahan/pengurangan!

**Mistake #3: Tidak Cek Jawaban**
Selalu cek: apakah jawaban masuk akal?
Kalau 1/2 + 1/4 = 4/6, itu salah! (harusnya 3/4)

**Mistake #4: Operasi Campur Aduk**
Ingat urutan: kali/bagi dulu, baru tambah/kurang!
1/2 + 1/3 × 1/4 ≠ (1/2 + 1/3) × 1/4
