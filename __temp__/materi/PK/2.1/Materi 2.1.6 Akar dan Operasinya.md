## Materi 2.1.6: Akar dan Operasinya

### Welcome to the Root Zone! 🌱

Kalau bilangan berpangkat itu kayak naik ke atas, maka akar adalah kebalikannya - turun ke bawah mencari asal-usul! Akar adalah **inverse** (kebalikan) dari perpangkatan. Di UTBK, kemampuan operasi akar ini KRUSIAL banget, terutama dalam menyederhanakan ekspresi aljabar yang kompleks!

---

### Pengertian Akar

**Definisi:**
Akar pangkat n dari bilangan a adalah bilangan b sedemikian sehingga bⁿ = a.

**Notasi:**
```
ⁿ√a = b ↔ bⁿ = a
```

**Komponen:**
- **√** = simbol akar (radikal)
- **n** = indeks akar (pangkat)
- **a** = radikan (bilangan di dalam akar)
- **b** = hasil akar

---

### Jenis-jenis Akar

#### **1. Akar Kuadrat (n = 2)**

**Notasi:** √a (tanpa angka 2)

**Definisi:**
```
√a = b ↔ b² = a
```

**Contoh:**
```
√4 = 2 (karena 2² = 4)
√9 = 3 (karena 3² = 9)
√16 = 4 (karena 4² = 16)
√25 = 5 (karena 5² = 25)
```

**PENTING:** 
- √a selalu berarti akar kuadrat **POSITIF**!
- √4 = 2 (bukan ±2)
- Untuk ±, harus ditulis eksplisit: ±√4 = ±2

**Kuadrat Sempurna 1-20 (HAFAL!):**
```
√1=1, √4=2, √9=3, √16=4, √25=5, √36=6, √49=7, √64=8, √81=9, √100=10
√121=11, √144=12, √169=13, √196=14, √225=15, √256=16, √289=17, √324=18, √361=19, √400=20
```

---

#### **2. Akar Kubik (n = 3)**

**Notasi:** ³√a

**Definisi:**
```
³√a = b ↔ b³ = a
```

**Contoh:**
```
³√8 = 2 (karena 2³ = 8)
³√27 = 3 (karena 3³ = 27)
³√64 = 4 (karena 4³ = 64)
³√125 = 5 (karena 5³ = 125)
```

**Beda dengan Akar Kuadrat:**
Akar kubik bisa untuk bilangan negatif!
```
³√(-8) = -2 (karena (-2)³ = -8)
³√(-27) = -3 (karena (-3)³ = -27)
```

**Kubik Sempurna 1-10 (HAFAL!):**
```
³√1=1, ³√8=2, ³√27=3, ³√64=4, ³√125=5, ³√216=6, ³√343=7, ³√512=8, ³√729=9, ³√1000=10
```

---

#### **3. Akar Pangkat n**

**Notasi:** ⁿ√a

**Sifat Genap vs Ganjil:**

**n Genap (4, 6, 8, ...):**
- Hanya berlaku untuk a ≥ 0
- Hasil selalu positif
- ⁴√16 = 2 (bukan ±2)

**n Ganjil (3, 5, 7, ...):**
- Berlaku untuk semua bilangan real
- Tanda mengikuti radikan
- ⁵√(-32) = -2

### Hubungan Akar dengan Pangkat Pecahan

**Formula Konversi:**
```
ⁿ√a = a^(1/n)
ⁿ√(aᵐ) = a^(m/n)
```

**Contoh:**
```
√a = a^(1/2)
³√a = a^(1/3)
⁴√a = a^(1/4)

√(a³) = a^(3/2)
³√(a²) = a^(2/3)
⁴√(a⁵) = a^(5/4)
```

**Aplikasi:**
```
√8 = 8^(1/2) = (2³)^(1/2) = 2^(3/2) = 2√2
³√16 = 16^(1/3) = (2⁴)^(1/3) = 2^(4/3)
```

### Sifat-sifat Akar - The Foundation!

#### **Sifat 1: Akar dari Perkalian**

```
ⁿ√(a × b) = ⁿ√a × ⁿ√b
```

**Akar dari perkalian = perkalian dari akar**

**Contoh:**
```
√(4 × 9) = √4 × √9 = 2 × 3 = 6
√36 = 6 ✓

³√(8 × 27) = ³√8 × ³√27 = 2 × 3 = 6
³√216 = 6 ✓
```

**Aplikasi Menyederhanakan:**
```
√50 = √(25 × 2) = √25 × √2 = 5√2
√75 = √(25 × 3) = 5√3
√200 = √(100 × 2) = 10√2
```

---

#### **Sifat 2: Akar dari Pembagian**

```
ⁿ√(a/b) = ⁿ√a / ⁿ√b
```

**Akar dari pembagian = pembagian dari akar**

**Contoh:**
```
√(16/4) = √16 / √4 = 4/2 = 2
√4 = 2 ✓

√(9/25) = √9 / √25 = 3/5
```

---

#### **Sifat 3: Akar dari Akar**

```
ᵐ√(ⁿ√a) = ᵐⁿ√a
```

**Indeks dikalikan!**

**Contoh:**
```
√(³√8) = ⁶√8 = 8^(1/6)
³√(√64) = ⁶√64 = 2
```

**Dengan Pangkat:**
```
√(a^(1/3)) = a^(1/6)
```

---

#### **Sifat 4: Akar dengan Pangkat**

```
ⁿ√(aᵐ) = a^(m/n)
(ⁿ√a)ᵐ = a^(m/n)
```

**Contoh:**
```
√(4²) = √16 = 4
(√4)² = 2² = 4

³√(8²) = ³√64 = 4
(³√8)² = 2² = 4
```

---

#### **Sifat 5: Menyederhanakan Indeks**

```
ᵏⁿ√(aᵏᵐ) = ⁿ√(aᵐ)
```

**Bagi indeks dan pangkat dengan FPB!**

**Contoh:**
```
⁶√(a⁴) = ³√(a²) (bagi 6 dan 4 dengan 2)
⁴√(16) = ²√4 = 2
```

### Menyederhanakan Bentuk Akar - The Art of Simplification! 🎨

#### **Prinsip Dasar:**
Keluarkan faktor kuadrat sempurna (atau kubik sempurna untuk akar kubik) dari dalam akar!

#### **Langkah-langkah:**

**Step 1:** Faktorkan bilangan di dalam akar
**Step 2:** Identifikasi faktor kuadrat/kubik sempurna
**Step 3:** Keluarkan faktor sempurna dari akar
**Step 4:** Kalikan dengan koefisien (jika ada)

---

#### **Contoh Akar Kuadrat:**

**Contoh 1:** Sederhanakan √50
```
√50 = √(25 × 2)
    = √25 × √2
    = 5√2 ✓
```

**Contoh 2:** Sederhanakan √72
```
√72 = √(36 × 2)
    = 6√2 ✓

ATAU dengan faktorisasi prima:
√72 = √(2³ × 3²)
    = √(2² × 3² × 2)
    = 2 × 3 × √2
    = 6√2 ✓
```

**Contoh 3:** Sederhanakan √200
```
√200 = √(100 × 2)
     = 10√2 ✓
```

**Contoh 4:** Sederhanakan 3√48
```
3√48 = 3√(16 × 3)
     = 3 × 4√3
     = 12√3 ✓
```

---

#### **Contoh Akar Kubik:**

**Contoh 1:** Sederhanakan ³√54
```
³√54 = ³√(27 × 2)
     = ³√27 × ³√2
     = 3³√2 ✓
```

**Contoh 2:** Sederhanakan ³√128
```
³√128 = ³√(64 × 2)
      = 4³√2 ✓
```

---

#### **Trik Cepat - Faktorisasi Prima**

**Untuk Akar Kuadrat:**
Ambil pangkat genap, bagi 2, keluarkan dari akar!

```
√(2⁴ × 3² × 5) = 2² × 3 × √5 = 4 × 3√5 = 12√5
```

**Untuk Akar Kubik:**
Ambil pangkat kelipatan 3, bagi 3, keluarkan dari akar!

```
³√(2⁶ × 3³ × 5) = 2² × 3 × ³√5 = 4 × 3³√5 = 12³√5
```

### Operasi Penjumlahan & Pengurangan Bentuk Akar

#### **Aturan Emas:**
**Hanya bisa dijumlahkan/dikurangkan jika BENTUK AKARNYA SAMA!**

**Analogi:** Kayak variabel dalam aljabar!
```
2x + 3x = 5x ✓
2x + 3y = 2x + 3y (tidak bisa disederhanakan)
```

---

#### **Kasus 1: Bentuk Akar Sudah Sama**

**Langsung jumlahkan koefisiennya!**

**Contoh:**
```
2√3 + 5√3 = 7√3 ✓
8√5 - 3√5 = 5√5 ✓
√2 + 4√2 - 2√2 = 3√2 ✓
```

---

#### **Kasus 2: Bentuk Akar Berbeda (Tidak Bisa Dijumlahkan)**

**Contoh:**
```
√2 + √3 = √2 + √3 (tetap seperti ini!)
2√5 + 3√7 = 2√5 + 3√7 (tidak bisa disederhanakan!)
```

**JANGAN PERNAH:**
```
√2 + √3 ≠ √5 (INI SALAH BESAR!)
```

---

#### **Kasus 3: Sederhanakan Dulu, Baru Jumlahkan!**

**Ini yang sering muncul di UTBK!**

**Contoh 1:**
```
√8 + √18 = ?

Step 1: Sederhanakan
√8 = √(4×2) = 2√2
√18 = √(9×2) = 3√2

Step 2: Jumlahkan
2√2 + 3√2 = 5√2 ✓
```

**Contoh 2:**
```
√50 + √32 - √18 = ?

√50 = 5√2
√32 = 4√2
√18 = 3√2

5√2 + 4√2 - 3√2 = 6√2 ✓
```

**Contoh 3:**
```
2√12 + 3√27 - √75 = ?

2√12 = 2×2√3 = 4√3
3√27 = 3×3√3 = 9√3
√75 = 5√3

4√3 + 9√3 - 5√3 = 8√3 ✓
```

### Operasi Perkalian Bentuk Akar

#### **Aturan Dasar:**

```
√a × √b = √(a×b)
(a√b) × (c√d) = ac√(bd)
```

---

#### **Contoh Sederhana:**

```
√2 × √3 = √6 ✓
√5 × √5 = √25 = 5 ✓
√8 × √2 = √16 = 4 ✓
```

---

#### **Dengan Koefisien:**

```
2√3 × 4√5 = (2×4)√(3×5) = 8√15 ✓
3√2 × 5√2 = 15√4 = 15×2 = 30 ✓
```

---

#### **Perkalian Bentuk (a + √b)**

**Distributive Property Applies!**

**Contoh 1:**
```
√2(3 + √2) = 3√2 + √2×√2
           = 3√2 + 2 ✓
```

**Contoh 2:**
```
(√3 + √2)(√3 - √2) = ?

Gunakan (a+b)(a-b) = a² - b²
= (√3)² - (√2)²
= 3 - 2
= 1 ✓
```

**Contoh 3:**
```
(2 + √3)(1 + √3) = ?

FOIL method:
= 2×1 + 2×√3 + √3×1 + √3×√3
= 2 + 2√3 + √3 + 3
= 5 + 3√3 ✓
```

**Contoh 4:**
```
(√5 + √2)² = ?

= (√5)² + 2×√5×√2 + (√2)²
= 5 + 2√10 + 2
= 7 + 2√10 ✓
```

**JANGAN SALAH!**
```
(a + √b)² ≠ a² + b
(a + √b)² = a² + 2a√b + b ✓
```

### Merasionalkan Penyebut - The Ultimate Skill! 🥷

**Why?** Dalam matematika, bentuk dengan akar di penyebut dianggap "belum rapi".

#### **Tipe 1: Penyebut Bentuk √a**

**Rumus:** Kalikan dengan √a/√a

**Contoh 1:**
```
1/√2 = (1/√2) × (√2/√2)
     = √2/2 ✓
```

**Contoh 2:**
```
3/√5 = (3/√5) × (√5/√5)
     = 3√5/5 ✓
```

**Contoh 3:**
```
2/√3 = (2/√3) × (√3/√3)
     = 2√3/3 ✓
```

**Contoh 4:**
```
6/√12 = 6/(2√3)
      = 3/√3
      = 3√3/3
      = √3 ✓
```

---

#### **Tipe 2: Penyebut Bentuk a√b**

**Sederhanakan dulu, baru rasionalkan!**

**Contoh:**
```
12/(2√3) = 6/√3
         = 6√3/3
         = 2√3 ✓
```

---

#### **Tipe 3: Penyebut Bentuk (a + √b) atau (a - √b)**

**Gunakan SEKAWAN (Conjugate)!**

**Sekawan:**
- Sekawan (a + √b) adalah (a - √b)
- Sekawan (a - √b) adalah (a + √b)

**Why It Works:**
```
(a + √b)(a - √b) = a² - b (tidak ada akar!)
```

---

**Contoh 1:**
```
1/(2 + √3) = ?

Sekawan: (2 - √3)

= 1/(2+√3) × (2-√3)/(2-√3)
= (2-√3)/(4-3)
= (2-√3)/1
= 2 - √3 ✓
```

**Contoh 2:**
```
1/(√5 - 2) = ?

Sekawan: (√5 + 2)

= 1/(√5-2) × (√5+2)/(√5+2)
= (√5+2)/(5-4)
= √5 + 2 ✓
```

**Contoh 3:**
```
(3+√2)/(3-√2) = ?

Sekawan: (3+√2)

= (3+√2)²/(9-2)
= (9 + 6√2 + 2)/7
= (11 + 6√2)/7 ✓
```

**Contoh 4:**
```
√3/(√3 + 1) = ?

= √3/(√3+1) × (√3-1)/(√3-1)
= √3(√3-1)/(3-1)
= (3-√3)/2 ✓
```

**Contoh 5:**
```
2/(√5 + √3) = ?

Sekawan: (√5 - √3)

= 2/(√5+√3) × (√5-√3)/(√5-√3)
= 2(√5-√3)/(5-3)
= 2(√5-√3)/2
= √5 - √3 ✓
```

---

#### **Tipe 4: Penyebut Bentuk (√a + √b)**

**Sama, gunakan sekawan!**

**Contoh:**
```
1/(√7 + √2) = ?

= 1/(√7+√2) × (√7-√2)/(√7-√2)
= (√7-√2)/(7-2)
= (√7-√2)/5 ✓
```

### Common Mistakes - Yang Sering Salah! ⚠️

**Mistake #1: Distribusi Akar**
❌ √(a + b) = √a + √b
✓ √(a + b) ≠ √a + √b (tidak bisa dipecah!)

**Mistake #2: Sederhanakan Incomplete**
√48 = 4√3 ✗ (harusnya cek lagi!)
√48 = √(16×3) = 4√3 ✓

**Mistake #3: Lupa Koefisien**
2√3 × 3√2 = √6 ✗
2√3 × 3√2 = 6√6 ✓

**Mistake #4: Rasionalisasi Setengah-setengah**
Hasil masih ada akar di penyebut = belum selesai!

**Mistake #5: Operasi Campuran**
```
√2 + 3√2 × √2 ≠ 4√2 × √2
√2 + 3√2 × √2 = √2 + 6 (kali dulu!)
```
