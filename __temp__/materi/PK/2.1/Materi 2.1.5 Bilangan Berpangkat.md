### Pengertian Bilangan Berpangkat

**Definisi:**
Bilangan berpangkat adalah perkalian berulang dari bilangan yang sama.

**Bentuk Umum:**
```
aⁿ = a × a × a × ... × a (n kali)
```

**Komponen:**
- **a** = basis (bilangan pokok)
- **n** = eksponen (pangkat)
- **aⁿ** = hasil perpangkatan

**Contoh:**
```
2³ = 2 × 2 × 2 = 8
5² = 5 × 5 = 25
10⁴ = 10 × 10 × 10 × 10 = 10.000
```

---

### Jenis-jenis Pangkat

#### **1. Pangkat Bulat Positif**

Yang paling dasar dan paling sering dipakai.

**n = 1:** (Identitas)
```
a¹ = a
5¹ = 5
100¹ = 100
```

**n = 2:** (Kuadrat)
```
a² = a × a
3² = 9
7² = 49
```

**n = 3:** (Kubik)
```
a³ = a × a × a
2³ = 8
4³ = 64
```

**Hafal Pangkat 2 (1-20):**
```
1²=1, 2²=4, 3²=9, 4²=16, 5²=25, 6²=36, 7²=49, 8²=64, 9²=81, 10²=100
11²=121, 12²=144, 13²=169, 14²=196, 15²=225, 16²=256, 17²=289, 18²=324, 19²=361, 20²=400
```

**Hafal Pangkat 3 (1-10):**
```
1³=1, 2³=8, 3³=27, 4³=64, 5³=125, 6³=216, 7³=343, 8³=512, 9³=729, 10³=1000
```

---

#### **2. Pangkat Nol**

**Aturan Emas:**
```
a⁰ = 1 (untuk a ≠ 0)
```

**Contoh:**
```
5⁰ = 1
100⁰ = 1
(-3)⁰ = 1
(1/2)⁰ = 1
```

**Why?** Karena:
```
aⁿ/aⁿ = aⁿ⁻ⁿ = a⁰ = 1 ✓
```

**PENTING:** 0⁰ adalah **tidak terdefinisi** (undefined)!

---

#### **3. Pangkat Negatif**

**Aturan:**
```
a⁻ⁿ = 1/aⁿ
```

**Pangkat negatif = Kebalikan dari pangkat positif!**

**Contoh:**
```
2⁻³ = 1/2³ = 1/8
5⁻² = 1/5² = 1/25
10⁻¹ = 1/10 = 0.1
```

**Untuk Pecahan:**
```
(a/b)⁻ⁿ = (b/a)ⁿ
(2/3)⁻² = (3/2)² = 9/4
```

---

#### **4. Pangkat Pecahan (Akar)**

**Aturan:**
```
a^(1/n) = ⁿ√a (akar pangkat n dari a)
a^(m/n) = ⁿ√(aᵐ) = (ⁿ√a)ᵐ
```

**Contoh:**
```
4^(1/2) = √4 = 2
8^(1/3) = ³√8 = 2
27^(1/3) = ³√27 = 3
16^(3/4) = (⁴√16)³ = 2³ = 8
```

**Hubungan Akar dan Pangkat:**
```
√a = a^(1/2)
³√a = a^(1/3)
ⁿ√a = a^(1/n)
```

### Sifat-sifat Bilangan Berpangkat - The 7 Sacred Laws!

Ini adalah **HUKUM ALAM** dalam dunia pangkat. Wajib hafal!

#### **Sifat 1: Perkalian dengan Basis Sama**

```
aᵐ × aⁿ = a^(m+n)
```

**Pangkat dijumlahkan!**

**Contoh:**
```
2³ × 2⁴ = 2^(3+4) = 2⁷ = 128
x² × x³ = x⁵
5⁴ × 5² × 5 = 5⁷
```

**Jebakan:**
```
2³ × 3² ≠ 6⁵ (basis berbeda, tidak bisa!)
```

---

#### **Sifat 2: Pembagian dengan Basis Sama**

```
aᵐ / aⁿ = a^(m-n)
```

**Pangkat dikurangkan!**

**Contoh:**
```
2⁵ / 2² = 2^(5-2) = 2³ = 8
x⁷ / x³ = x⁴
10⁶ / 10² = 10⁴ = 10.000
```

**Special Case:**
```
aⁿ / aⁿ = a⁰ = 1
```

---

#### **Sifat 3: Pangkat dari Pangkat**

```
(aᵐ)ⁿ = a^(m×n)
```

**Pangkat dikalikan!**

**Contoh:**
```
(2³)² = 2^(3×2) = 2⁶ = 64
(x²)⁴ = x⁸
(5²)³ = 5⁶
```

**Jangan Salah!**
```
(2³)² ≠ 2^(3²) 
(2³)² = 2⁶= 64
2^(3²) = 2⁹ = 512
```

---

#### **Sifat 4: Perkalian Berpangkat**

```
(ab)ⁿ = aⁿ × bⁿ
```

**Distribusi pangkat ke semua faktor!**

**Contoh:**
```
(2 × 3)² = 2² × 3² = 4 × 9 = 36
(xy)³ = x³y³
(5a)² = 25a²
```

---

#### **Sifat 5: Pembagian Berpangkat**

```
(a/b)ⁿ = aⁿ/bⁿ
```

**Contoh:**
```
(2/3)² = 2²/3² = 4/9
(x/y)³ = x³/y³
(10/5)² = 10²/5² = 100/25 = 4
```

---

#### **Sifat 6: Pangkat Negatif**

```
a⁻ⁿ = 1/aⁿ
1/a⁻ⁿ = aⁿ
```

**Contoh:**
```
2⁻³ = 1/8
1/2⁻³ = 2³ = 8
(1/3)⁻² = 3² = 9
```

---

#### **Sifat 7: Pangkat Nol**

```
a⁰ = 1 (a ≠ 0)
```

**Contoh:**
```
999⁰ = 1
(x+y)⁰ = 1
```

### Operasi pada Bilangan Berpangkat

#### **1. Penjumlahan & Pengurangan**

**IMPORTANT:** Tidak ada sifat khusus untuk penjumlahan/pengurangan!

**Yang BISA disederhanakan:**
```
2x³ + 3x³ = 5x³ (basis dan pangkat sama)
```

**Yang TIDAK BISA disederhanakan:**
```
2³ + 2⁴ ≠ 2⁷ (tetap 8 + 16 = 24)
x² + x³ (tidak bisa disederhanakan!)
```

**Harus Hitung Dulu:**
```
3² + 2³ = 9 + 8 = 17
```

---

#### **2. Perkalian**

**Same Base:**
```
2³ × 2⁴ = 2⁷
```

**Different Base, Same Exponent:**
```
2³ × 3³ = (2×3)³ = 6³
```

**Different Base, Different Exponent:**
```
2³ × 3² = 8 × 9 = 72 (hitung manual)
```

---

#### **3. Pembagian**

**Same Base:**
```
2⁵ / 2² = 2³
```

**Different Base, Same Exponent:**
```
8³ / 2³ = (8/2)³ = 4³
```

---

#### **4. Perpangkatan Bertingkat**

**Urutan dari ATAS ke BAWAH!**

```
2^(3²) = 2⁹ = 512
(bukan (2³)² = 2⁶ = 64)
```

**Contoh:**
```
2^(2³) = 2⁸ = 256
3^(2²) = 3⁴ = 81
```

**Dengan Kurung:**
```
(2³)² = 2⁶ = 64
2^(3²) = 2⁹ = 512
```

### Notasi Ilmiah (Scientific Notation)

**Bentuk:**
```
a × 10ⁿ
dimana 1 ≤ a < 10, n ∈ bilangan bulat
```

**Kegunaan:** Menulis bilangan sangat besar atau sangat kecil.

#### **Bilangan Besar (n positif)**

**Contoh:**
```
300.000 = 3 × 10⁵
5.000.000 = 5 × 10⁶
6.750.000 = 6.75 × 10⁶
```

**Cara Menghitung n:**
Count berapa kali koma bergeser dari bilangan asli ke bentuk 1 ≤ a < 10.

```
300.000,0 → 3,00000 (koma geser 5 kali ke kiri)
= 3 × 10⁵
```

---

#### **Bilangan Kecil (n negatif)**

**Contoh:**
```
0.0003 = 3 × 10⁻⁴
0.00056 = 5.6 × 10⁻⁴
0.000000789 = 7.89 × 10⁻⁷
```

**Cara:**
```
0.0003 → 3,0 (koma geser 4 kali ke kanan)
= 3 × 10⁻⁴
```

---

#### **Operasi Notasi Ilmiah**

**Perkalian:**
```
(3 × 10⁴) × (2 × 10³) = 6 × 10⁷
```

**Pembagian:**
```
(6 × 10⁸) / (2 × 10³) = 3 × 10⁵
```

**Penjumlahan (samakan pangkat dulu!):**
```
(3 × 10⁴) + (2 × 10³)
= (3 × 10⁴) + (0.2 × 10⁴)
= 3.2 × 10⁴
```

### Aplikasi Bilangan Berpangkat

#### **1. Pertumbuhan Eksponensial**

**Rumus:**
```
A = P(1 + r)ⁿ
```
- A = jumlah akhir
- P = jumlah awal
- r = tingkat pertumbuhan
- n = waktu

**Contoh:** Populasi bakteri yang dobel setiap jam.
```
Awal: 100 bakteri
Setelah 5 jam: 100 × 2⁵ = 3.200 bakteri
```

---

#### **2. Peluruhan Eksponensial**

**Rumus:**
```
A = P(1 - r)ⁿ
```

**Contoh:** Nilai mobil yang menyusut 20% per tahun.
```
Harga awal: 200 juta
Setelah 3 tahun: 200 × (0.8)³ = 102.4 juta
```

---

#### **3. Bunga Majemuk**

**Rumus:**
```
A = P(1 + i)ⁿ
```

**Contoh:** Investasi 10 juta dengan bunga 10% per tahun.
```
Setelah 5 tahun: 10 × (1.1)⁵ ≈ 16.1 juta
```
